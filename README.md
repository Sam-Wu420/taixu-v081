# 太虚问道录 · 人界篇 v0.8

原创水墨修仙开放世界 RPG（单机、浏览器运行）。Canvas2D 画世界，WebGL2 / Three.js 0.187 做 HD2D 立体层：山门立板、地表深度、阴影、灵气雾、远景透视；人物、妖兽、建筑仍是手绘水墨贴图。

v0.8 是两条开发线的合并版：

- **HD2D 底座**（B 线）：三图世界（南荒 / 沧溟海 / 中州）、地形分块与后台绘制、P0–P11 修士生态与经济系统、宗门战争、万宝楼拍卖、洞府、衣橱、绝域、近战架势。
- **斗法篇章**（A 线）：斗法争锋（敌方修士储物袋、御器、护罩、遁光追杀、残血遁逃）、遁影惊雷（遁术、雷法、追猎）、元婴遁出、逆天四法、问道残卷观招偷学、37 宗门与人物原创化。

两份源码同出 v0.57，v0.8 将两边功能逐项并进同一套骨架；渲染底层沿用 B 线的 Three.js HD2D。

## 运行

```bash
npm i
npm run dev        # 本地开发：http://127.0.0.1:5202
npm run build      # 产出 dist/（静态站点，可直接部署）
npm run build:single   # 单文件构建（file:// 双击可玩，含 HD2D）
```

- **Windows 桌面版**：`cd desktop && npm i && npm run dist`（electron-builder，产物在 `desktop/release/`）。
- **安卓包**：先 `npm run build`，再 `node android/build-apk.mjs`（需要 JDK 17、Android SDK、Python）。
- **模组**：`.fmod` 外挂模组系统（接口五代），标题画面「模组」导入；模组平台见 `platform/`，模组制作说明见 `.claude/skills/taixu-mod/`。

## 世界

- **三图无缝**：南荒、沧溟海、中州，各自的地形、地貌、城镇与势力；海上行舟、下潜、上浮，绝域里灵力流失、只能贴海飞行。
- **活世界**：约 450 名有名有姓的修士与凡人，各有境界、宗门、性格、家小、恩怨与储物袋；会修炼、衰老、突破、陨落、互相斗法。神识范围内全行为模拟，神识外做粗略推演。
- **宗门**：37 宗门 + 12 座大宗门 HD 山门；声望、藏经阁、俸禄、任务、晋升、执法堂围剿；开宗立派与灭门战争。
- **经济**：坊市、丹药铺、法器阁、符箓斋按月换货；产地与价区影响价格与稀有度；万宝楼 NPC 真竞价拍卖；灵草只看数量、不计年份。
- **人界大事**：问仙大会、赤霄禁地、鸿家堡、魔道入侵、归墟殿、陨魔谷按年份推进，可参与、可改变结局。
- **江湖**：传闻会撒谎，托信可能是借刀；可以报假名号、卖假货、放假消息，信义会记账。
- **洞府与阵法**：灵脉开府、药园、禁制、聚灵阵、剑阵、困阵；阵道精熟度独立成长。

## 战斗

- **斗法争锋**：敌方修士有储物袋、御使法器、灵气护罩、遁光追击、残血亡命；斩杀后掉落其储物袋。境界差、护盾、元婴遁出、逆天四法全部生效；Boss 与精英豁免境界差门槛。
- **近战架势**：轻击连段、崩山击飞、上挑、下砸、定向慢动作，兵器决定招式形态。
- **法术与神通**：五品法术、熟练度改变形态；结丹化形七式、元婴出窍、神识锁定与追杀；问道残卷可偷学对手招式。
- **灵宠、傀儡、队友**：灵宠温养出战，结伴友人会化形、出窍、布阵、挡刀。

## HD2D 渲染

- Three.js 0.187 立体层：山门、牌楼、塔、树、人物的立板与分层深度；地形高度、阴影、灵气雾、地表深度拆分。
- Canvas2D 主体保持水墨笔触与手绘贴图，两种画法共存在同一镜头里；低画质档自动降级。
- 地形在后台线程分块生成，跨图时预取目的地。

## 原创化

人物、地名、宗门、法宝、事件已按 `src/data/rename.ts` 的对照表全量改名（例如主角苏寒、南荒、沧溟海、青霞谷、回春谷、问道残卷）。该表同时用于读档迁移；内部 id 全部保持英文，不影响存档与模组。除对照表本身外，仓库内不应再出现旧作专有名词。
