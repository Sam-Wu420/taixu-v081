# v0.63 · 灵力护盾（特效大修）

这一版只动「看得见、听得见」的东西和妖兽强度，剧情、存档格式都没变，v0.62 的存档直接能用。

## 一、新增：灵力护盾（炼气即有）

- **自带、自动**：炼气一层起就有，不占功法栏。遇敌自行升起（嗡——），脱战后淡去并补满。
- **随境界叠层**

  | 境界 | 名称 | 层数 | 每层可挡 | 外观 |
  |---|---|---|---|---|
  | 炼气 | 灵气罩 | 1（十层起 2） | 14% 气血 | 淡青薄罩 |
  | 筑基 | 青霄护罩 | 2（后期 3） | 13% | 青碧，绕四枚叶符 |
  | 结丹 | 金丹罡罩 | 3（后期 4） | 12% | 金罩，绕六枚符印，脚下生阵 |
  | 元婴 | 紫府灵罩 | 4（后期 5） | 11% | 紫罩，背现八卦，罩面走电 |
  | 化神 | 五色神光罩 | 5（后期 6） | 10% | 金木水火土各一层，足踏莲台，五色灵珠绕身 |

- **逐层碎裂**：受击先耗最外一层；一层耗尽便「叭」地碎开，余劲卸去四分之一再落到下一层。
  一记重击连破几层，就是「叭、叭、叭」——越靠外的层音越高；最后一层碎时另有一声闷响和一串碎落。
- **全挡住的一击**连同它附带的异常（灼烧、冰冻、定身……）一并化解。
- **战中重凝**：四息未受击后，每 2.6 息耗 3% 法力重凝一层。
- 声音全部是合成的（`world/lingdun.ts`），没有新增素材。

## 二、修复：御剑飞行时护盾留在地上（穿模）

原因：WebGL 路径下护盾分两层画——灵光在 GL 层（减了飞行高度 `st.lift`），护盾贴图在精灵层
（`combatfx.ts` 的 `drawCombatSprites`，**没减**）。所以一御剑，光跟着人上去了，贴图还在地面。
回春阵的环同样漏了。两处都已补上；新的灵力护盾从一开始就以「身体中心 − lift」为准。

## 三、移除：全部像素特效

`gfx/pixelfx.ts` 与 `vendor/pixelfx/` 整套删除（约 580 KB 源码）。原先用到它的地方：

- 四至十级妖兽的周身妖气、起手法阵、落招特效 → 全部改用 WebGL 粒子重画（`gl/beastgl.ts`）
- 宗门 / 灭宗大战里借用的阵纹（rune / holy / mana）→ 同样改为 WebGL（`beastfx.ts` 的 `sealFx`）

## 四、重做的特效

- **法宝灵焰**（玄霜冰焰、阴都尸火、三焰扇、九阳焚天炉、九幽冥灯、烈焰扇、紫阳兜）
  原先是一小撮火星，飞两百来步就散。现在是一条 480 步的焰流：三层焰芯光带 + 真实火焰贴图的火舌 +
  余烬 + 焰尾翻卷 + 地面映光；判定范围同步从 320 加到 480。各焰各有其形：
  冰焰飘寒晶、地结冰纹；尸火 / 冥灯拖鬼雾；三焰扇三色绞缠；九阳炉九阳连珠；烈焰扇火鸦齐飞。
- **宝鼎（归墟鼎等）**：鼎口垂下摄魂光锥，「青丝」是真的一根根弧线——缚住的敌人每个三根，
  另有十二根游丝在阵中游走；八卦 + 符环 + 漩涡铺地；收鼎时满阵灵光倒卷、光柱冲天。
- **大庚剑阵**：阵图加粗加亮（墨底、三重光环、八道剑光辐条）；剑与剑之间不再每帧乱闪随机弦，
  改成稳定的金弦剑笼 + 五芒大星；巨大的金色剑影贯穿全阵；狂暴段剑雨天降；
  收尾是一口百丈金剑自天穹贯入阵眼。
- **功法**：所有功法起手多一圈升腾的灵光；飞行中的法术按五行各带尾迹
  （火舌余烬 / 寒晶 / 电火 / 风丝 / 剑芒 / 水珠 / 落叶 / 鬼雾 / 碎石）——开局那几门也跟着受益。

## 五、四级以上妖兽加强

- **体魄**：气血每级 +12%（八级起再 +10%），妖力每级 +6%，皮甲每级 +5%。
  四级 ×1.12 气血 / ×1.06 攻；七级 ×1.48 / ×1.24；十级 ×1.94 / ×1.42。
- **新招**：四级起人人会一口「妖息」；五级起「妖踏」（跃起砸落，飞禽除外）；七级起「妖罡」（环身一震）。
  六级起各招调息缩短 12%。
- **特效**（按五行各不相同）
  - 周身：脚下本命色灵光 + 升腾的妖气；六级起背后两团妖焰；七级起脚下符阵；
    八级起妖丹绕身；九级起火环 + 顶上妖轮。
  - 起手：法阵由小张大，四周妖气向口中收拢。
  - 落招：火柱冲天 / 冰棱破土 / 三道天雷 / 毒沼冒泡 / 血漩血光 / 鬼手探出 / 龙卷 / 水柱 / 地刺 / 剑雨。

## 六、关于外部素材

查过 GitHub 上的开源特效资源。最合适、许可最干净的是 Kenney Particle Pack（CC0）——
本作图集里早已集成（`atlas.ts` 里 `K` 开头的那批格子），这一版把它们用得更足，**没有引入任何新的外部素材**。
非 MIT / CC0 的东西（GPL、CC-BY-NC、「仅供学习」之类）一概没用：能不能用取决于素材自己的许可证，
不是谁点头就行；免费开源也不等于不受约束。
