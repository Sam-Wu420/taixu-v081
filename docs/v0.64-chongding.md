# v0.64 · 境界重定（境界差距 · 追杀规矩 · 各有绝活）

这一版只回应三条反馈，剧情、存档格式都没变，v0.63 的存档直接能用（新字段自动补上）。

1. 「炼气打筑基怎么打都不掉血，只掉一两滴」——境界差距被定死了。
2. 「一上来就被结丹、筑基追上」——结丹不该追杀炼气，元婴更不该，除非迫不得已。
3. 「AI 修士的技能太单调」——按各自的宗门 / 散修身份加招。

特效只是顺手添了几处（见第四节），不是这一版的重点。

## 一、境界差距：不再定死

### 伤害门槛（`src/world/combat.ts` 的 `GAP_DEAL / GAP_TAKE`）

旧版不分境界，每差一个大境界：**打上去只剩 6%，挨打 ×3.2**。新版把差距交还给气血、攻防这些实打实的数值（筑基初期的气血本来就是炼气圆满的 1.8 倍、攻击 1.26 倍），这里只再添一道门槛，越往上越高：

| 门槛（较低一方 → 较高一方） | 低打高：伤害保留 | 高打低：伤害放大 | 旧版 |
|---|---|---|---|
| 凡人 → 炼气 | ×0.85 | ×1.10 | ×0.06 / ×3.2 |
| **炼气 → 筑基** | **×0.78** | **×1.18** | ×0.06 / ×3.2 |
| 筑基 → 结丹 | ×0.62 | ×1.35 | ×0.06 / ×3.2 |
| 结丹 → 元婴 | ×0.50 | ×1.50 | ×0.06 / ×3.2 |
| 元婴 → 化神 | ×0.42 | ×1.65 | ×0.06 / ×3.2 |

- **实测**（`tools/smoke-v064.ts`）：炼气十层一记 60 点的法术打在筑基初期（气血 650）身上，平均掉 **39 点**；旧版是 2～3 点。
- 跨两境把两道门槛相乘（炼气打结丹 0.78 × 0.62 ≈ 0.48）。加上数值本身差着六七倍，炼气对结丹仍然是打不动的——只是不再靠一个 0.0036 的系数硬性规定。
- 符箓借的是外力，门槛取平方根（炼气用符打筑基 ×0.88）。
- **这条规则是双向的，如实说明**：你高一境时也不再那么碾压——筑基打炼气 ×1.18（原 ×1.6），挨炼气一击 ×0.78（原 ×0.35）。老存档里的高境界角色清低境界的敌人，会比以前多掉些血。

### 其它跟着境界走的地方

| 项目 | 旧 | 新 |
|---|---|---|
| 威压迟滞（差一个大境界，被压者的移速） | 一律 ×0.28 | 按被压者境界：炼气 ×0.72 · 筑基 ×0.5 · 结丹 ×0.36 · 元婴 ×0.28 |
| 你被高境界敌人盯上时的减速 | 每境 22% | 头一境按你的境界 8%～20%（炼气 10%），第二境再加 20% |
| 飞剑被「法器格开」的几率 | 每高一境 +14%，上限 78% | 每高一境 +7%，上限 70% |
| 格开之后透过的伤害 | 10% | 炼气 / 筑基的法器格不干净：30%；结丹以上 15% |
| 修士瞬移闪避（只高你一境时的加成） | ×1.5 | ×1.2（高两境以上仍 ×1.5） |

差两个大境界以上的「镇压」（压在原地动弹不得）没有动。威压提示语也分了档：高一境是「并非不可一战，能战则战，不敌则走」，高两境以上才是「硬拼必死，速逃」。

## 二、追杀规矩：至多高你一个大境界

- **无名追兵**（露富被尾随、险地被神识扫中、斩了魔修引来同门、赏金客……）：来人**至多高你一个大境界**——筑基可以追杀炼气，结丹不会，元婴更不会。实测对炼气发起 3000 次，结丹 0 次。
- **炼气前中期**少有人惦记：八层以前被盯上的几率减半，来的也多是同阶（炼气一至四层时筑基只占约 16%，五至八层再多些，九层起照常）；追炼气的筑基多是初入筑基之辈。
- **筑基追炼气会托大**：不带全副家当（气血 ×1.35 → ×1.0，攻 ×1.1 → ×0.92，护体灵光 25% → 12%、碎后 32 息才重凝），遁光慢两成，甩掉之后不再燃血截杀，带帮手的几率 40% → 15%。
- **拦路的劫修 / 魔修 / 头目**同样至多高你一个大境界（凡人只会遇到炼气）。剧情首领、事件里指定了境界下限的不受此限。
- **不屑对小辈出手**：高出你两个大境界的修士（宗门镇守、过路老怪等）就算你走到他眼皮底下也只是冷冷一瞥——「哼，蝼蚁。」——并不动手。**你先动手，他便不客气了。**
- **真仇人**（你杀了他的亲族、师徒、伴侣……）若高出你两个大境界：自重身份，**先遣门下弟子 / 出灵石雇人来杀你**（来的人打着他那一派的旗号、用那一派的功法，同样至多高你一境）。遣来的人**接连两次失手**（被你杀了、甩了都算），他才「迫不得已」亲自出手——出手时会有提示。
- **宗门寻仇 / 围剿**：领队的师长至多高你一个大境界；高出两境的长老不再亲自下山围剿小辈。
- **算作「迫不得已 / 不得不来」的例外**：你应下了战书；你杀的是对方长老；你越两境杀了人；剧情首领；你先动的手。

## 三、AI 修士的招式：各有绝活

### 五种新的出招方式 + 两种附带效果（`src/world/foeskills.ts`）

| 方式 | 说明 |
|---|---|
| 齐发 `lines` | 数道光柱扇形齐出（一轮至多中一道） |
| 连爆 `march` | 一路炸过去：自身前起逐个向你推进（一轮至多中一记） |
| 追击 `track` | 每隔半息在你此刻的落脚处再落一记——站着不动会连吃几下 |
| 弹幕 `spiral` | 数臂弹幕边转边射 |
| 燃血 `fury` | 一段时间内出手更重（×1.25～1.35）、出招更勤，周身灵焰升腾，到点散功 |
| 吸取 `leech` | 命中你之后按他自身气血上限回补 6%～7% |
| 摄引 / 震退 `pull` | 命中后把你拖到他跟前，或把贴身的你推开 |

所有新招照旧先在地上亮预警，到点才结算，可以走位躲开。AI 也懂取舍：挨了打或血不多才燃血，血少时偏爱吸取，离得远才摄引、贴得近才震退。

### 每人多带一招

炼气修士从「招牌 + 2」变成「招牌 + 3」，筑基 +3 → +4，结丹以上 +4 → +5（精英再 +1）。同一门派的两个人，手里的招也不尽相同。

## 四、特效（顺手添的）

- **修士起手**：指间一点法诀灵光、脚下一圈本系光纹、几缕灵气上扬；大招更盛。
- **修士的招式落地**：地上再炸开一圈本系灵光。
- **燃血**：起手一圈气浪，期间周身灵焰不断升腾。
- **吸取**：一缕血气自你身上流向对方；**摄引 / 震退**：落脚处一圈光纹。

以上都只在你附近才画，百人会战不会因此变卡。

## 验证情况（如实说明）

- 类型检查通过（`tsc --noEmit` 零报错）；打包通过（`npm run build`）。
- `npx tsx tools/smoke-v064.ts` 无头冒烟 **30 项全过**：门槛数值、炼气打筑基的实际掉血、追兵与拦路者的境界上限、结丹不屑出手 / 你先动手才还击、仇家遣门下两次失手后才亲自来、各派招式数量与无重复、五种新招式与吸取 / 摄引 / 震退逐一实跑、十派修士围攻 15 秒无异常无 NaN。
- **没有在真实浏览器里试玩和目测**（打包环境没有显卡和浏览器）。所以：
  - 数值是按公式和无头模拟定的，**手感没有实机验证**——尤其「筑基追兵对炼气到底还压不压得住」。觉得还是太难或者太软，告诉我往哪边调。
  - 新添的特效复用的是已有的粒子事件，逻辑跑通了，**实际观感没看过**。
- 旧的 `tools/test-*.ts` 没有全量重跑（只改了 `test-suppress.ts` 里一条与新威压口径冲突的断言）；`test-demog.ts`、`test-pursuit.ts` 里若有按旧规则（结丹可追炼气）写的断言，现在会不过，属预期。
