## 一、通用的手法（每招都用）

1. **命中**：白色星形闪 + 3–6 条朝打击方向射出的冲击线，2–3 帧；蓝白色的「挥击带」（拳脚划过的一段弧光）1–2 帧；被打者整体闪白一帧、往后滑并在脚下拖一道土。轻、重、终结三档大小。
2. **冲刺 / 闪步**：起步脚下炸一团棕黄色尘土（向后喷）；人身后拖 3–4 个白色半透明的人形残影（同一姿势、越往后越淡）；一条青蓝色的速度带连到落点；到位那一下有个小冲击。中间几乎没有过渡帧——人直接「到了」。
3. **爆炸（四层）**：白核（1–2 帧）→ 橙黄火焰往外往上喷（带几根朝外的光刺）→ 暗红余烬火星（飘 0.5–1 秒）→ 灰褐烟尘（最后散，1 秒左右）。
4. **整屏白闪**：只在最重那一下，1 帧整屏偏白（不是纯白，画面还看得出轮廓），下一帧恢复。
5. **地面残留**：大招落地处留碎石块和焦黑裂纹，几秒后才淡。
6. **燃身状态**：进入火焰状态后，人物脚下和身侧一直有火苗往上蹿（贴着人物轮廓、跟着动），偶尔整身外描一圈亮边。
7. **节奏**：起手极短（2–4 帧，0.07–0.13 秒）→ 出手 → **命中顿帧**（被打者和出手者一起停 2–3 帧）→ 收招停一下（0.2–0.3 秒）再回站姿。连招每下之间 0.13–0.17 秒。

## 三、转阶段：赤阳罡（照「烈焰焚步」+「解放」）

- **入状态（37.4 起，视频里一直燃到 70 秒）**：他沉身一握拳，整个人外描一圈火亮边，之后脚下、身侧一直有火苗往上蹿（贴人物轮廓），走路、出招都带着。
- **解放（70.5–80.9）**：70.7 双拳在胸前收拢、身上火势加大 → **71.3 胸前一团亮紫白的光核** → 71.7 整屏压成暗紫红、他全身变成发光的赤红人形、火星往上飘 → 72.0–73.3 火势变成一人多高、他往前走着（像蓄势待发）→ **73.7 整屏白闪一帧，前方一团巨大的白光** → 74.0 前方一团暗红火海（四层爆炸里的火焰层和余烬层、铺满半屏）→ 74.3 他已经冲到对方身后、对方被打倒。招名叫「原子爆碎拳」。

## 六、给撼山客的落地方案（用户已同意）

- **第一阶段**：原有 24 招保留；一寸崩、金刚不坏、后发先至、缩地成寸、流星百裂、燕回 / 十方弹换成上面视频的动作；新增断脉腿、撞山靠、顶心膝、影踪连环踢。千钧坠的起手借「强袭重击」（下蹲 → 跳上天 → 空中一拳带火圈 → 斜着砸下来 → 四层爆炸 + 碎石）；落地后接视频「炼狱坠星腿」的光柱定位和全屏演出。
- **转阶段**：赤阳罡（解放演出 + 燃身）。
- **第二阶段**：赤焰回旋腿、燕旋、碎心踢、坠火踢、炎阳炮拳；觉醒大招霸皇蹴、逐日（和无极一击、一拳破界合用两分钟两次的名额）。
- **玩家能学的**：原来 7 招；撑到他进第二阶段再教撞山靠、赤焰回旋腿、炎阳炮拳和赤阳罡状态。
- 无极一击的动作模板就是「烈火强拳」。
