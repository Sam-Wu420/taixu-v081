# 撼山客与破坏系统 · 设计（2026-11-17 用户定稿）

用户的要求：做一个「超级帅超级炫酷」的体修中立 NPC，在世界里到处游荡、又要能被玩家发现；招式越酷越好，「让玩家一眼想玩」；顺带做破坏系统——野外、城镇可破坏，城镇要能恢复。方案是先讲给用户听、用户逐项点头的（「都按你推荐的来就行」）。这份文档是给做这件事的人（和子代理）看的定稿。

## 一、人物

- **撼山客 · 岳千钧**，原创人物。独行的体修大能，中立：不主动伤人，不属于任何宗门，在南荒到处走。
- **境界随玩家浮动**：始终比玩家高一截，玩家打不过他的全力；切磋时他压着打。从筑基到化神遇到他都有看头。
- **外形**：比常人高大一圈，赤膊缠拳布，残破道袍系在腰间，长发，腰挂酒葫芦。
- **平时的气场**：走路时地面微陷，落叶被推开，雨不沾身——远远一看就知道不是普通人。
- **三种遇法**：
  - 远远看他打别人（最常见，也是最好的招式展示）：路上撞见他一拳把妖王打穿山。
  - 切磋：上前搭话请教，他让三招，然后用全套连招把玩家打一遍，不致死。撑得越久奖励越好。
  - 惹他：玩家先动手或在他面前滥杀，他认真打，输了被打回城。
- **奖励**：切磋撑得越久，他传得越多。先开放六招给玩家学：一寸崩、震脚、燕回、十方弹、犁地、千钧坠；化神后再加一拳破界。学到的招接进近战的兵器谱（拳这一份）。

## 二、怎么被发现（四条线索一起用）

- **江湖传闻**：消息栏隔一阵报一条「有人在某地见一赤膊大汉一拳打断山梁」，带大致方位。
- **他留下的痕迹**：走过的地方有拳坑、断树、被犁开的沟。跟着痕迹能追上，痕迹越新越清楚。
- **动静**：他在附近打架时，远处就能看到冲击波的光、听到闷雷声，小地图边缘出现一个震动的标记。
- **见过一次之后**，世界地图上显示他最近一次被目击的位置。

## 三、画法（用户同意）

- **身体用现有的程序骨架动画**（`src/gfx/character.ts`），不用立起来的贴图。理由：玩家要学他的招（主角是骨架）；二十多招 × 关键姿势 × 朝向，贴图要三四百张且生成图保持不了一致；高速招式的残影、拖影、定格前后帧要从姿势插值；兵器、衣摆、影子、翻滚都现成。
- **贴图只用在**：对话立绘一张；终结技的定格特写两三张（出手那一瞬全屏切入半秒：拳头特写、眼神特写）。用 `node tools/codex-image.mjs` 生成（不要把配置里的密钥打印出来）。
- **图已经生成好入库了**（共约 620 KB）：立绘 `public/art/npc/yueqianjun.webp`（540×720）；定格特写 `public/art/cutin/yqj_fist.webp`（拳头迎面，1280×720）、`yqj_eyes.webp`（眼神，1280×576 宽幅）、`yqj_stomp.webp`（高空踩落，1280×720）。都是黑白水墨加一点熔金色，和「黑白闪」是一个调子。
- **黑白闪的冲击帧用代码画**（后期着色器加一个开关：重击命中那一瞬画面黑白反相定格一两帧）。
- 让骨架够帅靠：专属外形、夸张姿势（出拳拉长、收招压缩、高速拖影）、镜头（大招推近、跟着被打飞的人甩过去）、打击感（定格、震屏、黑白闪、地面变形、背后炸开）。
- 标准：之前「墨渊道君」Boss 演示的水平（`特效演示/`），全部手写程序特效。

## 四、招式（25 招）

**起手与位移**

| 缩地成寸 | 人消失，只剩一道线和落点的气爆，出现在对手背后 |

| 一寸崩 | 贴身零距离停半拍，一拳，力道从对手背后呈锥形炸出去，掀翻后面一片 |
| 拳压·开山 | 隔空一拳，直线上草伏、石裂、地面犁出一道沟 |
| 震脚 | 一脚踏地，地面成圈龟裂，周围的人全被震到半空 |

**终结技（带定格特写；r7-fx3d 起分海并进无极一击，不再单列）**

| 招 | 画面 |
|---|---|

## 五、破坏系统（三层）

- **野外，放开破坏**：树林成片倒，山石崩裂，地面留坑和沟，水面炸开。过一阵自己长回来（现有可破坏物就是这个机制），大坑留得久一些。
- **城镇，能坏但会修**：
  - 能坏的：摊位、旗杆、灯笼、栏杆、院墙、牌坊、屋顶瓦片。房子本体分「完好、破损、半塌」三档，不会彻底消失。
  - 店铺半塌期间掌柜在门口摆临时摊，照常买卖——游戏不会卡死。
  - 恢复：按游戏日自动修，小件一两天，房子十来天，能看到脚手架和工匠；玩家可以出灵石加急。
  - 后果：玩家在城里打坏东西，城主府或宗门记账，名声下降或要赔。撼山客打坏的不算玩家头上。
- **不能坏的**：传送阵、宗门大殿、主线要用的建筑。
- 破坏状态存进存档，读档后不会凭空复原。

## 六、先后与分工

1. **野外破坏**（不依赖近战在改的那两条线，先做）。
2. **他在世界里游荡、被发现**（传闻、痕迹、动静、目击位置、搭话与切磋入口；招式先用现有的敌人近战顶着）。
3. **招式**：要用到「近战定向」线新加的上挑、和「兵器」线的兵器谱框架，等那两条合并后做。25 招分两三批。
4. **城镇破坏与恢复**放最后（工作量最大：建筑画法、碰撞、NPC 行为、存档）。

## 七、要盯的

- **性能**：成片倒树、塌房碎块多，限数量；「40 敌连续施法」已经比收官前慢（交接文档第三节），边做边量。
- **无缝**：打上虚空、踢回世界都不许切画面、闪白、黑屏（黑白闪是一两帧的画面风格，不是遮幕）。
- **模组契约**（收官计划 G 节）：伤害走 `hitEnemy` / `hitPlayer`，`Enemy` 构造和 `shell` 约定不动，`SK_KINDS` 只增不改，不新增默认按键。
- **固定种子**：他的游荡、痕迹、破坏物的摆放都用自己的随机序列（按坐标 / 日子取哈希），日结算和布局生成的路径上 `Math.random` 一个不多取。
- **特效别糊画面**：用户反感云雾光晕挡视线；大招可以炸，但平时的痕迹、气场要克制。
