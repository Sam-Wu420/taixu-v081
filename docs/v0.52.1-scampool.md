# v0.52.1 · 天道：骗局有度——事件池权重与骗局概率只写一次（`world/scampool.ts`）

> 原文 2.3「频率控制：骗局占同类事件的 15–25%，让玩家保持怀疑但不至于草木皆兵」。验收时发现这条断言**一直是假绿**：`tools/test-renxin.ts` 在测试里另抄了一份 v0.49 时代的权重表，而 v0.50/v0.51 陆续把**美人局（escort）、渡劫局（tribul）、商队夹带（caravan）**加进了野外奇遇池——按真实代码算，凡人档骗局占比已到 **≈24.6%**（擦线），天道档 **≈27%**（越界），先礼后兵立威、劫修绕道后天道档更涨到 **≈30%**，测试却始终是绿的。

1. **纯函数模块 `src/world/scampool.ts`**（`hapPool` / `hapScamP` / `scamShare` / `rollHapKind`）：野外奇遇池权重与每类奇遇「是一场局」的概率只在这里写一次——`happen.spawn()` 抽签、`happen.buildHap()` 的 #1 合作探宝 / #3 借刀杀人 / #4 美人局 / #5 夺舍、`jianghu.armTribul()` 的 #9 渡劫局、`pianju.armCaravan()` 的 #11 商队夹带全部改读这份台账，测试也读这一份（与 `quota.ts` 同一个思路：数字一改，断言跟着变）；
2. **重新配平**（局的真假比例不动，只调可疑奇遇出现的频率）：**天骄 ≈13.9% · 凡人 ≈21.5% · 天道 ≈23.5%**——三档分化保留，天道档更凶但不出 25% 上限；
3. **劫修绕道不再抬高骗局比例**：先礼后兵翻脸打赢后劫修绕行，空出来的权重让给山中妖兽相争，而不是让骗局水涨船高；恶名在外招来赏金猎人时骗局占比不升反降；
4. **验证**：`tools/test-daoxin.ts` 新增**第十五节**（三档占比断言 · 绕道/恶名两种工况 · 十类奇遇全覆盖 · 用真实 `buildHap` 跑 1500 次蒙特卡洛与台账期望吻合），十五节全绿（含 v0.52 第十四节碑前香火）；`test-renxin` 第二节改读同一份台账；`test-tiandao` 四条节奏断言（凡人难度·苏寒式元婴仍在 250–320 岁）、`test-jianghu` / `test-market` / `test-living` / `test-relations` / `test-pacing` / `test-tiers` / `test-events` / `test-melee` 全绿；`tsc --noEmit` 通过；`npm run build` 重新打包 dist（双击 index.html 即玩）。
