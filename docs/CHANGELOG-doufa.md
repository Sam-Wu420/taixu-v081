## v0.71 · 斗法争锋

这一版只做两件事：**炼丹成丹率上调**，以及**敌方修士（AI）全面加强**。

### 一、炼丹：成丹率按丹方而定

v0.70 起灵草不计年份，原先靠「药龄」补上去的成丹率没了着落，各丹方只剩两三成的底子，太低。现在：

- 丹方底子 = `0.42 + 原基础成丹率 × 0.72`（上限 92%）
  - 聚气丹 60% → **85%**；回气丹 / 疗伤丹 70% → **92%**；黄龙丹 50% → **78%**
  - 筑基丹 20% → **56%**；降尘丹 25% → **60%**；九曲灵参丹 30% → **64%**；紫府玄元丹 22% → **58%**
- 境界高出丹方所需，每高一个大境界 **+6%**
- 熟能生巧：每炼一炉 **+0.4%**，至多 +12%
- 灵泉水 +5%、「丹道圣手」+25% 照旧；总上限 97%；炼器（成器率）不变

实现见 `src/world/cultivation.ts` 的 `checkRecipe`。

### 二、敌方修士（AI）

**1. 修了「太慢」的 bug（最要紧）**

- 根子：人修敌人一直用敌人表里的固定移速（140～230），而你的遁速随境界成长（筑基 300 / 结丹 440 / 元婴 610，御器再 ×1.8，催动遁光再 ×1.55）。妖兽在 v0.60 修过同样的问题，人修漏了。
- 现在修士身法与你**同一张境界遁速表**（`humanSpeed`）：追击、缠斗、逃跑、追杀结束后都按境界走。
- 追杀者贴身 700 丈内原先固定 200 的移速，改为按境界身法；帮手同理。
- 筑基以上的修士驾遁光时**不再被山水崖壁卡住**（此前追到水边就停，看着像跑得慢）。

**2. 遁光**

- 筑基以上：离得远（> 720 丈）催动遁光疾追；你也在飞遁时，他们**全力催动**（约等于你催动遁光的遁速）。
- 近身缠斗时仍驾着遁光走位出手（身法 ×1.3，你在飞遁时 ×1.8）。
- 炼气期不会飞遁，以轻身术 / 神行符疾行。
- **追杀者也会催动遁光**：你飞遁逃命或被拉开，他便全力催动一阵（遁速反超你约 4%），次数有限（2 + 境界 + 备战层数），法力不济后只能平飞——想甩掉，得熬过这几阵。

**3. 残血亡命遁逃**

- 触发血线上调（炼气两成、筑基二成二、结丹二成五），几率 80%～95%，几乎必逃。
- 逃时开遁光、撑护罩，筑基以上一路遁术接连施展；遁速比你平飞快约一成——**催动遁光才追得上**。
- 逃出一千五百丈便无影无踪，储物袋也就没了。

**4. 灵气护罩**

- 修士入战即撑起灵气护罩：炼气 10% / 筑基 16% / 结丹 22% / 元婴 28% 气血上限（盾类法器、心法另有加成）。
- 打碎后对方僵直 0.7 息；隔 12～22 息还能再凝（炼气 1 次、筑基结丹 2 次、元婴 3 次）。

**5. 储物袋（斩杀后尽数掉落）**

| 境界 | 灵石 | 法器件数 | 法器品阶 |
| --- | --- | --- | --- |
| 炼气 | 800 ～ 2,000 | 至多 3 件 | 零至一阶（后期偶有二阶） |
| 筑基 | 3,000 ～ 10,000 | 至多 5 件 | 一至三阶 |
| 结丹 | 12,000 ～ 40,000 | 至多 8 件 | 三至四阶（后期偶有一件寻常古宝） |
| 元婴 | 50,000 ～ 160,000 | 不设上限（8～12 件） | 三至五阶（偏好高阶，含寻常古宝）；**后期**另带 1～3 件镇派重宝 |
| 化神 | 200,000 ～ 600,000 | 不设上限 | 同上，重宝 2～4 件 |

- 另有丹药、符箓、材料、妖丹、灵药，偶有功法玉简。
- **绝不配给**：归墟鼎、云雷双翼、碧竹飞云剑、血色披风、太虚剑匣、周天星斗盘、九幽冥灯，以及一切六阶神物、名字带「鼎」的至宝、旧案人物的独门法宝。
- 魔器（阴 / 血属性）只有魔修才带；法器偏向与本宗心法同系，剑修爱剑。
- 死于旁人（NPC）之手的，储物袋被摸走一半。
- 凡人武者（黑狼帮、独霸山庄等）、尸傀、召唤出来的帮手、切磋对手不带储物袋。

**6. 御使法器**

储物袋里的法器会在斗法时逐件祭出，各有招式（照旧先在地上亮预警）：

飞剑三连斩 · 飞针扇面齐射 · 环 / 珠连环追击 · 宝镜光柱 · 砖 / 印 / 山镇压（晕眩）· 符宝激发 · 钟铃震荡（晕眩）· 索 / 网缚人（定身）· 扇 / 灵焰扫荡（留火）· 幡旗落雨 · 钵盂摄引 · 盾护体。
护甲加防、盾加厚护罩、靴 / 舟加身法。品阶越高威力越大。

**7. 宗门功法**

- 各派修士带的本宗招式更多：炼气 5、筑基 7、结丹 9、元婴 11 门（原 4 / 5 / 6 / 7），外加招牌、护体、回春、大招、天阶神通。
- 新增**本宗心法**（被动）：剑诀（攻、身法）、玄冰诀（气血、护罩）、离火诀 / 御雷诀（攻、出手更勤）、厚土诀（防、气血）、乘风诀（身法）、血煞功（攻）……入战时头顶亮出「宗门·心法」与法器件数。
- 新增**本宗秘传**（筑基一式、结丹再一式，共 26 式）：万剑朝宗、剑轮回旋、九霄神雷、天罗雷网、玄冰封界、三昧真火、血河滔天、摄魂夺魄、玄水缚龙……招式名前冠本宗名号。
- 修士出手更勤（炼气 ×0.92、筑基 ×0.85、结丹 ×0.72、元婴 ×0.62 间隔）；气血 / 攻 / 防各境界再上调。
