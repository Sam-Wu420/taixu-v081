# v0.51.2「天道」· 碑林图鉴

本补丁接在 v0.51.1 的转世幂等修复之后，为天道档补上最后一块“可读”的界面。

## 新增

- 标题画面新增「碑林」入口（有旧碑时出现，附带碑数）。
- 一屏可翻阅最近九座前世之碑：道号、道心档位、境界、享年、立碑处、凶手、生平摘录、《苏寒随笔》与遗物去向。
- 遗物一栏明确区分“仍在凶手处 / 已被取回”，与 `DaoxinSys` 的 `read / taken / legacy` 字段一一对应。
- 天道档提示不变：单档自动盖写、封死备份后门；碑是唯一的存档。

## 验收

- `tsc --noEmit` 通过。
- `tools/test-daoxin.ts` 十二节全绿（含转世幂等与天道备份后门）。
- 低内存路径重建 `dist/`，产物仍为双击 `index.html` 即可运行。
