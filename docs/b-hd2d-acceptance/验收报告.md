# B-HD2D 验收记录

## 最新百人与千人各 15 秒对照

2026-11-13，本机 Windows 11、i5-12600KF、RTX 3070，集成浏览器前台 1920 × 1080、DPR 1。双方各占一半，正常移动、施法和受击，气血设为 1000 万以维持人数。每组预热 5 秒后采样约 15 秒，每种人数各一轮。采用相同的自动画质设置，百人基线画质等级 4→4，本版 0→2，千人两版均为 4→4。等级越大削减越多，百人结果包含自动画质变化。

本版两组结束均保持全部人数，控制台 warning/error 为 0。长帧数量按实际采到的帧计数，千人本版每帧仍超过 50 ms。游戏单帧 dt 上限、受击停顿和慢动作会改变游戏推进速度，受击次数不能直接作为相同模拟时间的吞吐对照。JS 堆起止值分别为百人 643,634,493 / 548,638,075 字节，千人 583,075,572 / 695,662,026 字节，未测进程总内存与显存。

本轮保留 GPU 云海与台面缓存、平地特效快速路径、文字布局复用、64 单位战斗空间格、稳定图集槽和 CPU 双 Worker 人物绘制。64 单位网格与原 256 单位网格在固定种子真实战斗中获得相同的状态 SHA-256 和 2856 次伤害事件。

人物 Worker 的第一轮 GPU 光栅仍有纹理等待，千人上传约 34.60 ms/帧。改为 CPU OffscreenCanvas 后该阶段约 1.52 ms/帧，最终较大批次版约 2.95 ms/帧。最终平均画面年龄为百人约 52 ms、千人约 316 ms，主线程的位置更新保持逐帧。千人仍有约 137 名半透明或其他不适用人物直接绘制，约 19.87 ms/帧，约 5519 条伤害文字占 14.33 ms/帧。千人流畅性尚未达成。

Worker 采用原人物绘制函数。260 名真实角色的同姿态、九种动作、批次和衣发回传通过 Node 真实实现对照。浏览器 GPU OffscreenCanvas 的 36 组动作朝向中 35 组像素完全一致，另 1 组有少量边缘差异。最终 CPU 光栅版使用相同造型与动作，抗锯齿像素存在差异，已查看并排图。实际 GPU 图集中的上下方向、透明混色、稳定 key 换图和整图重建四组对照差值均为 0。

重构版的直接三角人物路线因缺少 B 版施法手部光效而未接入。神识边缘逐部件透明与整图透明在 GPU 对照中存在明显可见差异，本版保留原逐部件效果。Idle Colony 的共享动画帧和屏幕字体图集提供了后续优化方向，其原生 AI 与线程函数体未取得。

原始数据为 `battle-15-before.json` 与 `battle-15-after.json`。各轮采用 15 秒采样，不将早期 60 秒数据混入最新结果。下文保留此前版本的验收记录。

本记录对应 2026-11-13 的本机测量。以下原有四场景与首次访问数据中的“本版”指千人战斗优化前的 B 版；基线是本轮修改前的 B-HD2D（Git `15ca21d`）。该 B 版增加了建筑模型、地形高度、深度遮挡和景深等画面内容，比较数值时需要考虑渲染负载变化。

## 神识边缘透明立板回归

真实 WebGL 对照测试使用起伏地形和同一背景像素，将立板透明度从 0.039 调至 0.041。沿用最近物体深度计算神识时颜色最大通道变化为 44；使用地表深度时为 2，关闭神识时为 6。原有立板深度继续用于 FX 和几何遮挡，重新运行 45 组投影与前后遮挡测试通过，最大投影误差为 0.0006684 像素，GL 错误为 0。目标尺寸变化时，旧深度纹理和帧缓冲已释放，新目标有效。

这组测试复现并消除了透明立板边缘触发的神识颜色跳变。青霞谷近似位置开启默认神识和迷雾往返移动，并转镜约 180°，未观察到此前的整片颜色跳变，控制台错误为 0；复验路线与用户视频不完全相同。测试页面为 `tools/hd2d-check.html`，按钮“验证透明边缘与神识”同时保留旧深度与地表深度对照。`sense-rotate-after.jpg` 为一张实景截图，其余截图留在工作区 `tools/out/edge-flicker/`。
