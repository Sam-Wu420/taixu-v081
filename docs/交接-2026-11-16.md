## 四、这一轮新增的规矩和坑

- **每个工作副本的做法**：
  - 建：`git worktree add ../验证/<名> -b <名> main`，再把 `node_modules`、`dist-mods` 用目录联接接过去（`mklink /J`）。
  - 拆：先 `rmdir` 掉这两个联接，再 `git worktree remove --force`。不先拆联接会把主线的依赖删掉。
  - 拆之前把它的 `tools/out/<名>` 截图拷到主线的 `tools/out/`。
- **Vite 缓存**：`vite.config.ts` 里 `cacheDir: '.vite-cache'`，每个工作副本各用各的。几台开发服务器共用 `node_modules/.vite` 会出两份 React，页面报「Invalid hook call」。
- **端口**：5202 是主线，现在只有它开着。前几轮各条线用过 5213、5219、5241、5246，性能对照版用 5247，解包验证用 5248，用完都关了。
- **截图**：
  - `--eval`、`--step` 的脚本参数是**文件路径**，不是内联代码。
  - Git Bash 里先 `export MSYS_NO_PATHCONV=1`。
  - 一个新的 `try` 入口第一次拍常常没进场景（Vite 现编译那一块，页面重载），重拍一次就好。
  - 拼招那张要 `--wait=3`，入口在布置好后 0.4 秒就触发。
  - 试玩页已经加了 `<base href="/">`，头像不再是空的，上一份文档里「把 `./art` 改成 `/art`」那条不用了。
- **子代理的结论一定要在主线复核**，这一轮又错了几次：
  - 室内线没发现自己弄坏了 `test-sect-walk`（殿前月台成了真高台，点地走路卡在台沿）。它只跑了自己认为相关的测试。
  - 画面线的截图全是拉远拍的，近镜头下的毛病看不到。主线要自己拍默认镜头。
  - 世界线上一轮说「同伴已跟着降界」，补单测时发现是错的。
  - 两条线各自正常，合在一起出问题（光影把绝域洗平）。合并后要拍对方的入口。
- **限坡是按步长算的**：`surface.canTraverse` 用「这一步的高差 ÷ 步长」判陡。自己写寻路或通行判定时步子要碎（3 个单位一步），步子大了会把一道坎误判成能迈上去。
- **源文件是 CRLF**：用脚本打补丁时锚点要整段唯一匹配，换行按文件原样。
- **内存**：空闲只有 4 GB 左右。子代理一次只跑一两项测试。**内存紧时系统会把后台任务直接停掉**（这一轮被停过三次：批量实拍一次、性能测量两次），而且被停的任务不该自己重跑。所以长任务拆成十分钟以内的几段在前台跑：全量测试用 `--part=k/n`，实拍用 `--only=` 分批。
- **量性能时别同时跑别的**：同一份代码两次能差一成多。要比较就新旧交替量（`tools/shots-final/perf.mjs`），再用 CPU 采样对比找差在哪（`prof-diff.mjs`）；只看一边的数字下不了结论。
- **测试里自己拼的对象不走字段初始化**：`Object.create(Renderer.prototype)` 这种写法不会执行类里的字段默认值，新加的私有字段要么用到时再建，要么在测试里补上。
- **「提前算好」类的优化要想清楚什么会让结果过期**：地形方法会被模组按实例打补丁，测试里的假地形随时在变。
- **模组契约**：计划的 G 节有完整清单。动战斗、绘制列表、标题菜单、按键之前先读。新增的核心按键：近战架势（CapsLock / 鼠标中键）、更多功能（反斜杠）、灵舟（分号）、遁空（句号）。

## 五、用户这一轮定的事

- **全量测试和模组测试放到最后跑**（2026-11-16）：返工循环里每次合并只跑和改动相关的几项；全量 `run-suite` 和模组测试（`test-mymods`、实机冒烟）等所有返工都合完再跑一次。用户原话：「全量测试和mod测试最后再跑吧不然太浪费时间了」。
- **模组开发包单独成包**（2026-11-16）：按 B 版重新生成后单独打一个包；源码包不带 `fanren-modkit/game`。
- **不用的 Edge 要关**（2026-11-16）：截图留下的无头浏览器、没人用的开发服务器，自己关，不要拿内存不够当理由，也不要让用户去关。
- **虚空一拳打进世界**：追击一键完成，按一次就朝落点俯冲，途中仍是玩家在飞、随时能拐走。日常用的是界内版（御剑高空把人砸进海里或地上，任何战斗都能用），虚空版只是少数大战的名场面。用户没有选「不追也算赢」；我的理解是不追则对手带伤活在落点，这场不结算奖励。
- **按键要顺手**（2026-11-17）：用户说「现在的按键太反人类了」，点名 PageUp / PageDown 升降。定下来：升降用空格 / `C`，角色面板换到别的键。以后加按键先想手够不够得着（WASD 附近），别往 PageUp、分号这类远处放；不能用 Ctrl / Alt（浏览器里 Ctrl+W 关标签页）；字母键满了就让飞行 / 架势里用不上的键换个用途。
- **重击要能选方向**（2026-11-17）：不能固定一个方向。轻点＝飞向鼠标落点；按住＝放慢时间瞄准；空格 / `C` 选上挑 / 下砸。用户同意放慢时间。
- **近战要能用兵器**（2026-11-17）：拳头只是其中一种。第一批剑、重兵、长枪；兵器槽 + 本命飞剑可握；按键不变。分三步做（见第一节）。
- **Claude Code 的 Code Mode**：用户让打开，已设用户级环境变量 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`，下次启动生效。旧对话开着它能不能正常续上，没验证过。
