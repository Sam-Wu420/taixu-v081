### 1.1 万花筒接缝（4 张）——无缝化方法本身有问题

| 文件 | 问题 |
|---|---|
| `rock/rock_cave.png` | 画面里能看到**镜像对称的折线**：四块左右、上下对称的拼块，拼缝处纹理硬生生折回去 |
| `rock/rock_desert.png` | 同上，四个象限镜像对称，接缝清晰可见 |
| `liquid/liquid_lava.png` | 最明显。熔岩流纹在画面中心呈十字对称折返，中线上还有一道撕裂似的硬边 |
| `floor/floor_ice.png` | 冰纹呈四象限镜像，平铺后满地重复的「X」形图案 |

**原因**：NOTES 第二节写的流程是「2×2 镜像 quad → roll 半幅 → 中心 inpaint」。镜像拼接会产生对称轴，roll 只是把对称轴从边上挪到中间，inpaint 盖住了接缝线，**对称本身还在**。这正好违反任务书「看不出重复的图案中心」那一条。

**请换一种做法**（任选其一，都不要用镜像）：
1. 用生图模型自带的**平铺 / 无缝**选项（circular padding / tiling），直接出无缝图；
2. 或者：先正常出图，**位移半幅**（`roll`，不镜像），只在中间那道细十字缝上做小范围修补，再从原图回填纹理。

交付前请拼 3×3 用眼睛看一遍，不能看出任何对称轴或十字线。
