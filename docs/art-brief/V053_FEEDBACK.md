## 4. 程序自己处理，你不用管

- 阵旗等道具画得比规格大约 3 倍（旗高约 1000px），按 `person_px` 算旗子会有 4.7 个人高。程序统一按「旗高 ≈ 1.4 人」缩放，并自己从 alpha 算落地点，不再用 manifest 里的 `[0.5, 1.0]`。
- 几张物品图标底部有一圈淡淡的**白色残边**（`icon_zhenpan_1`、`icon_zhenpan_3`、`icon_mat_zhenyu`、`icon_mat_lingmo`、`zf_stake` 的符纸边缘），是白底抠图的残留，程序转换时收边。
- `ui_board` 外圈贴到了画布边缘，程序加边距。
- `zf_liangyi` 阴的一半用了深蓝，进游戏后会偏透明，可以接受。
