### 1. 重档 / 终档把人洗白 → 改了，被打的人每一张都看得见轮廓
找到的几个来源和改法（打击感开着时；`?hf=0` 照旧）：
- `gl/fx.ts` 的冲击环：立着的那种原来是「软边光环 + 白圈」，在人身上就是一整颗发白的柔光球；贴地的亮色环是一大片发白的光盘。现在两种都只留一圈细边。
- `gl/brawlgl.ts`：轰飞、破罡、坠界那一拳的 `F.flash`（加色大光团 + 2.4 强度的点光源）换成「一圈往外扩的亮边 + 一个很小的实芯」（`hitFlash`）；拳风的爆芒、轰飞的放射芒和镜头光、破罡的六角罩亮球压淡或不画。
- 自己的：重档的挥击弧光收小、偏到来手那一侧；终档的星芒小一号；终档的四层爆炸挪到被打的人身后 135、半径 90（白核约 50，不压在人身上）；扭曲冲击波收小到 220、挪到爆心。
- 看图：`三档-fist/sword/heavy/spear.png`（每张左到右 轻 / 重 / 终）。重档里人身上已没有柔光球；终档右边那团白是挪开的爆炸白核。拳脚重击时出手的人手上还有一团黄光，是原来就有的蓄劲光（bxcharge），没动。

### 2. 法术爆炸太平 → 地面光盘去掉，量放到立体部分
- 去掉：接管了的爆炸不再画 `drawVfx` 的地面光盘（ring 的大片 Glow、雷的地面光晕、金的地面金圈）、不再铺 `bakeSpawn` 的平面贴花（莲花、漩涡、六角…）、点光源从 R×2.2 / 强度 1.6+ 降到 R×0.8 / 0.9；冰霜印去掉那张星芒贴花，冰霜 / 毒斑的地面光再压暗缩小。地上只剩一圈接地的激波环（三维的，0.26 秒）。
- 加到立体的：紧跟着往上翻的第二团火（高一截、小一点，像烟柱 / 蘑菇头）、往外崩的立体碎块（火、魔是带火的红褐色）、大爆炸（威力 ≥ 1.2）再加一圈收小的扭曲冲击波；混战里（每秒已经好几个爆炸、场上 15 人以上）不加第二团和碎块（性能，见第 3 条）。
- 空间系：原来偏粉偏艳；试了几档蓝紫，加色的蓝紫叠在绿草地上一律变成青色，最后改成「压暗的焰 + 深靛的烟」（一团往里塌的暗影），和其他系同一水准。魔道改成暗红焰 + 墨黑烟（同一原因：蓝通道一高就发青）。木毒：绿焰 + 平面补一层紫色余烬（立体余烬里的紫被绿焰盖住）。
- 排查中发现的一个拍图问题：上一个爆炸的冰霜印 / 毒斑留在同一处，叠到下一张图里颜色是混的（之前那几张「青色」有一部分是它）；试玩页拍图时先清掉。
- 看图：`法术爆炸-总览.png`（火、冰、雷、木毒 / 魔、空间、金、土、风、法器三档冲击）。

### 3. 长帧 → 用 CDP 采样抓到、修了一处；修完交替量了两轮
- 工具：Edge 无头 + CDP `Profiler`（0.5 毫秒采样）跑「40 敌连续施法」，页面里同时记每帧间隔和游戏自己的分项计时（`__prof.spikes`），离线把连续的非空闲采样拼成「任务」，列每个长任务里最贵的函数和调用栈（`trace-new*.json / .ana.txt`）。

## 一、做了什么

把撼山客那套（参考视频 DNF 男散打的「通用做法」）推广到全游戏的出手：拳脚、剑 / 重兵 / 枪、法术、法器、妖兽招式、NPC 之间互殴。

### 1. 命中分三档（`src/world/hitfeel.ts`）

- 规则 `hfTier()`：
  - **终**：打死精英 / 首领；重击把人轰飞（重击 / 追击 / 收式 / 俯冲 / 冲撞这一下打完人在天上）；地、天阶法术打实（伤血 ≥ 8%）。0.4 秒里最多两次（大招扫中一群，只有头两个炸开，其余按「重」）。
  - **重**：暴击、打破护体灵光、破罡、近战的重击类（重击、砸地、追击、俯冲、冲撞、震地、拼招、连段收式、撞墙）、法器砸中（伤血 ≥ 3%）、玄阶以上法术或伤血 ≥ 12% 的法术、飞剑伤血 ≥ 15%、其余伤血 ≥ 18%。
  - **轻**：其余（普通攻击、轻击连段、小法术、飞剑擦伤）。
- 时序：命中当下只记一笔，照旧往 `fxq` 推 `'hit'` / `'phit'`（事件名、字段都没删，只加了 `tier / wk / lod / red` 几个可选字段）；这一帧战斗更新末尾（或画面那边先到时）统一定档——这时才知道有没有破罡、把人轰飞、打死。
- 每档做的事：
  - 轻：小号实心白星 + 2–3 条方向线、被打者闪白 1 帧、法术 / 法器 / NPC 互殴的单位顿帧 0–1 帧（伤血 ≥ 4% 才冻一帧）。
  - 重：大一号白星 + 4–6 条方向线 + 挥击弧光（剑是一道细长的斩光、枪不画弧）、闪白 2 帧、往后滑时脚下一路冒立体的尘团 + 平面的土粒、单位顿帧 0.045 秒、轻微震屏。
  - 终：四层立体爆炸（炸在被打的人身后，不把人吞掉）+ 一圈扭曲冲击波 + 0.15 秒慢放；打死的尸身顺着这一下的方向飞得更远（gore 的抛飞速度 ×1.7）。
- 近战框架自己的那几下（兵器谱里有顿帧）不再叠单位顿帧；撼山客的特殊招式（`p1fx.hit` 自己出星闪）跳过不重复画。
- 原来 `hitEnemy` 里法术暴击的**全局**顿帧拿掉了（改成单位顿帧；全局顿帧只留给近战的收尾一击，和 test-brawl 的约定一致）。
- 远处（离镜头 2200 以外）只做数值不出特效、不出声；1300 以外出轻量版。

### 2. 画面（`src/gl/hitfeelgl.ts`）

- 星：实心锯齿星（普通混合，亮草地上不被洗掉），描一圈边色；不走一路淡出的粒子，前 3–5 帧实打实地亮着再收。落在被打的人朝来手的那一面，大小压着（轻 22、重 31、终 40 世界单位）。
- 兵器各一套：拳脚黄边、方向线中等；剑青边、星沿刀路拉长、线细长；重兵橙边、线粗短、往外崩碎屑；枪一条从身后贯穿过去的长线；妖兽爪牙红边、重档三道爪痕；法术按系别取色。
- 你挨打：偏红的星和线，朝来向；人闪红。
- 方向线：外面一层边色的光、里面一道白芯；从星的边上起（几条加色的线叠在同一点，经过泛光会成一团白盘——实拍看过）。

### 3. 法术、法器的爆炸换成四层立体爆炸

`combatgl` 的 `spawnVfx` / `impactFx` 先问 `hfVfxSpawn` / `hfImpact`，换掉的有：

| 原来的画法 | 来源 | 现在 |
|---|---|---|
| `strike` 的 `F.explode`（火、雷、土、冰、金…） | 天降打击类法术（流火术、引雷术、天雷符、九天雷殛、万雷天牢、圣魔驭日、化形·雷鹏…）、敌人招式的地面危险区（foeskills 的火 / 雷 / 冰 / 土） | 四层立体爆炸 + 激波环 + 焦痕或冰霜印；火系地上只留一圈火（原来那根火柱和大光晕不画了），雷的闪电柱照旧 |
| `ring`（落点 / 自身爆发，fx 是会炸的那几种，半径 ≥ 50） | 炎爆术、玄冰封印、归墟鼎、山河破、黄沙百里、大五行擒仙手、化形·火凤 / 白虎 / 麒麟、掌心雷、金刚吼、天衍神识冲击、迷魂术、带范围的弹道落点、连携的火圈 | 同上（护身、增益、阵法的光圈不炸） |
| `flash`（弹道打中的一下，fx 是火球、冰锥、雷、藤、鬼火…） | 所有弹道法术、敌人的弹道 | 弹着点一小团立体爆炸（每秒最多 8 个，超出的照旧画平面的） |
| `impactFx` 二、三档（`combat.impact`） | 法器砸下（artacts）、神通落地（huaxing、heroacts）、大庚剑阵、雷遁等 | 二档：立体爆炸 + 激波环；三档：再加扭曲冲击波、焦痕 |

- 配色：火 fire、金 gold、水 / 冰 frost、空间 void 用三维模块原有的；木 / 毒（`hf_venom` 绿焰紫余烬）、雷（`hf_thunder` 白紫 + 平面电弧闪两三下）、魔道 / 鬼道（`hf_ink` 紫黑焰墨黑烟）、土（`hf_earth`）、风（`hf_wind`）是新配的，登记进 hsfx3d 的配色表（见第六节）。fx 的 dragon / crow 这类跨系的按颜色判（寒魄冰龙走冰、火鸦走火）。
- 按法术威力（半径）缩放；落地的留焦痕（火、雷、土、金、魔，4.5 秒）或冰霜印 / 毒斑 / 风痕（4.5 秒淡掉）。
- 每秒最多 7 个大爆炸 + 8 个弹着点小爆，超出的走原来平面的画法。

### 4. NPC 互殴

`npcHit` 原来就只在你看得见的近处出特效，这里在同一个分支里接上同一套（星、线、闪白、顿帧、声音），远处粗模拟不经过。特殊招式（撼山客）打的 NPC 跳过。

### 5. 音效（`src/world/audio.ts` 末尾独立一段 `hf()`，名字都带 hf 前缀，没加音频文件）

命中：`hfLight / hfHeavy / hfFin`，兵器 `hfSword(Heavy) / hfBlunt(Heavy) / hfSpear(Heavy)`，挨打 `hfHurt(Heavy)`；爆炸：`hfPop`（弹着点）+ 各系 `hfBoomFire / Gold / Frost / Venom / Thunder / Ink / Void / Earth / Wind`。
同一帧多次命中按「什么打的 × 几档」合并成一声（叠得多音量略大），一帧最多三种、重的先；同一种 45 毫秒内不重放；爆炸同一系 60 毫秒内只响一次。原来 `audio.dir.hit` 的流派质感层照旧调用（它取随机数，次序不能变）。

### 6. 性能预算、画质

- 上限：一帧最多 6 个闪白、3 个拖土；同时亮着的星 24 颗；冰霜印 12、电弧 8；一帧画了 10 下以后的命中只画星和一条线；立体爆炸限流见上。
- 画质：`hfLevel()`——没有立体场景、画质低档（设置「低」/ 自适应降到最低档）、光影关掉（`taixu.gfx=0`）都是轻量版：只有平面的星和线，不报立体特效，法术爆炸走原来的平面画法（`tools\out\r9-hitfeel\低画质-*.png`）。
- 立体特效的着色器开局就一帧编一种（原来只在撼山客在附近时预热），不等到头一回爆炸时在打斗里一口气编。
- 对照开关：网址 `?hf=0` 或 `localStorage taixu.hitfeel=0` 退回原来的画法。

## 四、没做到的、原因

- 上面的最长帧。
- 撼山客那批招式里的命中仍由 `p1fx` 自己画，这里只是跳过不重复，没有统一成同一套参数。
- 近战原有的拳风画法（`brawlgl` 的 bxhit：冲击环、爆芒）保留，打击感开着时把它的大点光源和爆芒压淡了；重击那一两帧被打的人仍会被照得发白（有一部分是原来就有的，`?hf=0` 对照里也有）。
- 妖兽的闪白是在它的立板上再盖一层白（canvas filter），人形的走 p1fx 的立板；镜头外的妖兽不会补闪。
- NPC 互殴的那张图星比较淡（那一刻打中的是轻档）；录像里有清楚的。
- 录像里火狼是前面「挨打」那段留下的，后半段和 NPC 混在一起打，画面比较乱。
- 空间（void）爆炸偏艳（粉 + 白），没细调；木 / 毒的紫色余烬不明显。魔道、木毒两张是最后改了配色和激波环颜色后重拍的，其余几系的图在那之前拍（激波环原来那种发青的画法只在魔道、木毒两系出现过）。
- 踩过的坑：三维模块的激波环颜色红通道低于 0.7 会换成另一种发青的画法；四层爆炸的配色某个通道超过 1.2，过曝后色调映射会把紫推成青。
- 试玩页拍图偶尔有一档没打出来（前一下把人轰飞了还没落地），重拍就好。
