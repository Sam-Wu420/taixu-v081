## 一、通用的手法（每招都用）

1. **镰刀刀光**：复仇者每一下挥镰都带一道**月牙形刀光**——视频里是青绿 / 金黄（武器自带的颜色）。我们改成：**紫黑芯、血红边、外缘一线白**，弧带真三维（`fx3d` 弧带），宽度是镰刃长的六成，1–2 帧最亮、3–4 帧淡出；刀光沿镰尖的轨迹，横扫是贴地的扁弧，劈砍是竖着的弧。
2. **魔气碎屑**：他身上一直往上飘**黑色的碎片 / 烟丝**（视频里人物肩头一直有黑色碎块冒起来）。我们画成紫黑的烟丝和碎片，人身少、半魔多、魔躯一大片。挂在立板上（bossthings 的辉光 + 玩法放的粒子）。
3. **出手卡帧**（照撼山客）：起手极短（2–3 帧，80–120 毫秒）→ 出手一帧到位（不插值，`hit` 段开头 60 毫秒拉伸 sx 1.2 / sy 0.88）→ **命中顿帧** 2–3 帧（80–120 毫秒）→ 收招帧停 200–300 毫秒 → 回站姿。
4. **命中**：被打者身上一团**紫红星形闪 + 3–5 条黑紫色冲击线**，1–2 帧；重击加一圈紫色冲击环（贴地）和整身闪白一帧。
5. **魔化的标志色**：视频里化魔后人物整体染成**亮紫 + 黑**，身上有**红色发光的符纹（像「卍 / 爪」形的红字）**飘在四周（见堕落之魂 6.6–7.1）。我们：半魔形态立板 `tint` 偏紫、`glow` 0.25；魔躯 `glow` 0.35，四周飘红色魔纹（用书法小字「魔」「噬」「劫」当符，三维小立板）。
6. **全屏演出**（大招、变身）：**整屏压暗成紫黑**、正中**一张巨大的人脸特写**（复仇者的脸，半透明、竖条的紫色光幕叠在上面，像屏风）——见 6.4–7.1。我们照这个做：压暗（`hsp2.show`）+ 竖条紫光幕 + 夜无赦的**半身像**（用 `yws_*_roar` 帧放大到半屏、透明度 0.55、往上慢漂），书法大字收尾。
7. **魔影（被动「魔影随身」）**：每次出手后，身后浮出一个**半透明的紫黑魔影**补一下（魔影是他自己的立板、染成紫黑、放大 1.3 倍、透明度 0.6），用 bossthings 的 `ghosts[]` 给。

## 二、人身的招

### 1. 堕魂诀（堕落之魂，自强化）· 人 · SK `01-duohun` 6–13 秒

**分解**（近景 `yws-ref/c01a`）：
- 5.9–6.1 站姿（镰杆斜扛、镰刃在身后脚边；身上冒黑碎屑）。
- **6.25 起手**：半蹲收身、镰横到胸前，身周一圈**红色光环**（竖着的圆，像结界）、红光从地面往上溢。（帧 `h_cast`，蓄 1 段）
- **6.4–7.1 全屏演出**：整屏压成紫黑、竖条紫色光幕铺满（左右两条亮边），正中一张巨大的人脸特写在吼；人物身上**一团红色十字准星形的光**（6.4–6.5）→ **6.6 头顶炸一团青白星光**、整个人变成**亮紫色的发光人形**、四周飘起一圈**红色符纹（爪形、竖着的红字）**→ 6.75–7.0 保持，符纹往外飘、闪。
- 7.1 光幕散，7.25 恢复站姿。
- 之后（8.5–12.5）一直带**紫色的魔焰外描**（贴人物轮廓往上蹿，8.5 起），中间换成金黄色火焰（11.5–12.0，那是另一个 buff，不做）。

**帧**：`h_idle` → `h_cast`（起手，120 毫秒）→ `h_roar`（演出中，800 毫秒，`glow` 1.2、`tint` 紫、`add` 紫）→ `h_idle`（200 毫秒）。整招约 1.1 秒。
**特效分层**：①脚下一圈竖着的红色光环（半径 0.6 身高，向外扩，3 帧）②压暗 + 竖条紫光幕（800 毫秒）③头顶青白星芒（1 帧最亮）④身周红色魔纹 8–10 个（往外飘 400 毫秒、闪烁）⑤之后常驻紫色魔焰外描（立板 `glow` 0.4、`glowCol` 紫，脚下紫烟）。
**镜头**：推近 1.15 倍，200 毫秒；不震。
**节奏**：起手 120 → 演出 800 → 收 200。
**魔化版**：魔躯不放这招（魔躯本来就全程带魔焰）；半魔放时光环和魔纹是紫红色、演出缩短到 500 毫秒。

### 2. 魂镰三式（镰刀精通·普攻）· 人 / 半魔 · SK `02-pugong` 13–20 秒

**分解**（近景 `yws-ref/c02a`、`c02b`）：站姿是**镰杆斜扛在身前、镰刃朝下拄在脚边**。三下：
- **第一式·撩**（13.75–14.6）：13.875 镰杆一抬、身子略侧（起手 1 帧）→ 14.0–14.6 **镰从下往前上撩**（镰刃从脚边划到身前上方），人几乎不动——普攻第一下动作很小。
- **第二式·斩**（14.75–15.25）：14.75 收镰到身后 → **14.875 跨步前冲、镰刃从身后上方往前下劈**（右臂伸直、镰刃落到身前地面）→ 15.0–15.125 **压低身子、镰刃贴地扫到身后**（弓步、斗篷甩开）。
- **第三式·回旋横扫**（15.25–16.0）：**15.375 镰高举过头、往身后甩出一道大弧**（青绿色月牙刀光在头顶，金色拖尾）→ **15.5 大跨步、镰刃平着往前扫出去**（整条手臂和镰杆伸直，刀光像一道往前的闪电，镰尖在一个身位外）→ 15.625 收镰回头顶 → **15.75 背过身、镰刃往身后地面一挂**（转身斩，刀光是竖着的月牙弧）→ 15.875–16.0 定在背身弓步 → 16.25 回站姿。
- 每下间隔约 125–250 毫秒，第三式最大，整套 2.3 秒。

**半魔版**：镰刃带紫黑魔焰（`b_*` 帧本来就画了魔焰），刀光加宽 1.3 倍、外缘一圈红；第二式 `h_slash` 后加一下**空斩**（见第 3 招）。

### 3. 魔气入体（化魔 / 半魔化）· 人→半魔 · SK `03-banmo` 20–40 秒（含**空斩**、**落魂锤**）

**分解**（近景 `yws-ref/c03a`–`c03i`）：
- **化魔（20.0–20.7）**：20.07 站姿 → 20.13 往后一仰、镰杆竖起（起手 1 帧）→ **20.2 身上一团蓝紫色的光炸开、四周喷红色碎血雾**（像血滴往外溅，半径一个身高），人张开双臂往后仰 → 20.27–20.33 保持（红雾往外散）→ 20.4 蓝紫光贴着身子往下流 → 20.47–20.73 回站姿。整段 0.6 秒。
- **半魔化（23.1–24.1）**：23.1 站姿 → **23.2 整个人变成黑色剪影、身周一个红色的光圈（竖着的圆，外红内暗）**→ 23.3 光圈收紧 → **23.4–23.5 整屏压暗，人物剪影变成通红、外描一圈白边**（像烧红的铁）→ **23.6 炸开：一团白紫的光芯、四周一大圈暗红的火烟往外推（半屏宽）**、黑色碎块往外飞 → 23.7 余烟 → 23.8 红影 → 23.9–24.1 剩一个**纯黑剪影 + 细红边**的人站着。之后视频里半魔状态一直是「黑剪影 + 红描边」。
- **空斩（25.0–26.1，半魔下的普攻派生）**：25.0 黑影弯腰、手上一点红光 → **25.1 一步冲到敌人面前**：身后拖一团巨大的**半透明黑影（他自己的轮廓放大 2 倍、像一头魔兽扑过来）**、脚下一大团往后喷的黄色尘土 → **25.2 一道血红色月牙刀光从上往下劈**（两层红弧 + 一层橙芯），敌人身上一团**紫白星形闪** → 25.3 第二道红弧，紫色星芒 → 25.4 黑影散、紫星 → 25.5–25.7 敌人倒地、他站在敌人身边 → 26.1 回站姿。冲刺距离约 3 个身位，40 毫秒内到位。
- **落魂锤（落凤锤，37.2–38.6）**：37.2 下蹲 → **37.3 跳起**（37.4 已经在一个身高半的空中，镰举在身后）→ 37.5–37.6 在最高点停一下（往前飘半个身位）→ **37.7 斜着往下扎，镰刃朝下，整把镰裹一条竖着的火焰柱（白芯、橙黄、外红，一个身高长）** → 37.8–38.0 往下扎到地面（三格，约 300 毫秒，斜线下落、离敌人越来越近）→ **38.1 落地爆：一团橙黄爆炸 + 灰黄尘土云往四周推（2 个身位宽）、紫白命中星** → 38.2–38.3 火往上喷、敌人被炸飞上天 → 38.4–38.6 他半蹲收势，地上留一块焦黑。
- 其余时间（26–37）是普攻在半魔下的样子：动作和第 2 招一样，人是黑剪影，刀光变成**橙红大月牙（两三层）**，每下脚下一团尘土。33.2–33.4 是一记**空斩**的重放：起步时人物整个外描一圈白边（闪白 1 帧）。

空斩（半魔普攻派生，id `kongzhan`）：`b_windup` 80（`wind`）→ `b_dash` 40（`snap` 前冲 320、残影 1）→ `b_slash` 120（`hit`）→ `b_slash` 120（`hit`，第二道弧）→ `b_idle` 260。
落魂锤（id `luohun`）：`b_charge` 100（下蹲 `wind`）→ `b_leap` 200（`arc` 离地 260、前冲 60）→ `b_leap` 200（悬停，前冲 120）→ `b_dive` 300（`in` 离地 0、前冲 300、`hit` 在段末落地那一刻，残影 0.8）→ `b_slam` 200（`hit`，`sy` 0.85、`shake` 6）→ `b_idle` 300。

**判定**：化魔是身周 200 的圆（推开，伤害小）；半魔化炸开那一下身周 360 的圆（击退）。空斩：冲刺路径上宽 80 的长条 + 落点前方 220。落魂锤：落点半径 260 的圆（击飞）。
**特效分层**：
- 化魔：①蓝紫光核在胸口（1 帧最亮）②红色血雾粒子往外溅 30–40 个（400 毫秒）③蓝紫光沿身体往下流（立板 `add` 衰减）。
