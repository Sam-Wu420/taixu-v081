# 太虚问道录 · 2D 同人（v0.57 · 模组接口五代）

> **怎么继续开发**：`npm i` 装依赖 → `npm run dev` 本地热更（Vite）→ `npm run build` 出 `dist/`（双击 `index.html` 即玩）。
> 桌面版：`cd desktop && npm i && npx electron-builder --win portable --x64`。
> 本仓库只放源码与美术资源；`dist/` 停在 v0.52.1 不再随版本更新，可玩的构建产物一律走 [Releases](https://github.com/qwasx/taixu-xiuxian-dev/releases)。

## v0.57 · 模组接口五代（v4 + v5）

目标不变：**除了标题画面，模组什么都能改**；这一版把「改」做成通用的口子，社区以后做新东西基本不用等游戏更新。

- **数据表全开放**（`api.data`）：43 张表一套方法读、改、加、删——境界、大瓶颈、灵根、功法、天赋、节奏（每秒天数、打坐倍速）、宗门、藏经阁、知交、节日、灵宠、阵法、阵盘、秘境、原设大事件、骗局几率、首领巢穴、衣橱、法宝外观……；删法术 / 物品 / 敌人只是撤出池子，旧存档不坏。
- **前置钩子**（`api.hook`）：伤害、修为、冲关成功率、用物品、商店货架与价格、野外刷怪、掉落、原版对话、配乐场景、音效、进地点、交谈——事前改写或取消。
- **自定义行为**：物品用法（原版物品也行）、法术施放 / 命中回调、`cast: 'custom'` 自定义出手、模组状态（每帧回调、到时回调）。
- **主角全开放**：境界、修为、寿元、灵根、功法、天赋、声望、忘法术；完整快照（背包、法术、修为……）。
- **界面全开放**：屏幕 HUD、原版面板里加段落（角色、储物袋、丹器、闭关、城镇）、替换原版面板、模组设置项（在「模组」面板里改）。
- **世界**：天气、跨图、读主线；知交的交谈也能加模组选项。
- v4：路边小站地点类型（茶寮 / 驿站）、`g.rest` 歇息、`g.tavern` 打听消息、`api.world.locations` 读地点。
- **云平台**：打包时预置模组坊地址，玩家打开「模组 → 模组平台」直接能浏览、安装；地址里的 `?sharecode=` 会带到每个请求上。
- 验收：`tools/test-mod5.ts`（47 项）+ 原有全部测试；浏览器里实测了 HUD、面板段落、面板替换、设置项、物品「使用」、自定义法术、云平台安装。

## v0.56 · 模组改原版（模组接口 v3）

目标：**除了标题画面，模组什么都能改。**

- **改原版（v2）**：
  - 改任何法术、物品、妖兽、丹方的字段（`api.content.patch.*`）；
  - 加丹方 / 器方；给任何敌人定专属招式（14 种招式，预警 ≥ 0.3 秒、威力 ≤ 6 会被夹紧）；加掉落；宗门藏经阁上架；
  - 两个模组改同一处时提示冲突；setup 半路出错时已做的改动全部撤销。
- **世界与人物（v3）**：
  - 新地点：城池、城镇、海岛自动有房子、坊市、客栈、居民；险地、秘地进去是对话；
  - 城镇面板、险地秘地加事务；有名有姓的 NPC（住处、外貌、专属开场、可收徒，随存档走）；与任何人交谈时加选项；
  - 多层对话树、开商店、任务栏（左侧 + 地图「任」字）；
  - 新事件：境界变化、进入地点、交谈、切磋结束、用物品、炼丹出炉、被打倒；
  - 新动作：好感、切磋、同行、加修为、回血、传送、指路。
- **画面、界面、声音（v3）**：
  - 右下角按钮、模组面板（声明式内容，游戏负责画）、快捷键；
  - 图片帧动画换图（妖兽、NPC、主角，原版的也行）；在世界里画东西（按遮挡排序）；
  - 特效、震屏、全屏闪光、慢动作、飘字；音效、换背景音乐。
- **高级权限**：manifest 写 `unsafe: true` 可拿到游戏内部；玩家启用时必须确认警告，模组更新后要重新确认，平台上标红。
- 示例模组：`mods/leize/`（v2 改原版）、`mods/xianzong/`（v3：青玄门北边的仙踪镇和云雾谷、云老道的两段任务、仙踪录面板、雾妖贴图）。
- 工具：`mod-try` 会实战检查专属招式、逐个进入新地点、和新 NPC 交谈、点按钮、渲染面板；`tools/test-mod3.ts` 是 v3 的验收测试。

## v0.55 · 外挂模组 · 模组坊

（v0.54.3 的山区性能改动经负责人实测更卡，已整版撤回；本版以 v0.54.2 为基础。）

- **游戏里的模组接口**（`src/mod/`）：
  - 一个模组 = 一个 `.fmod` 文件，里面有清单、入口代码和图片。
  - 启动时、建世界之前加载，按依赖排序。
  - 模组能做的事：
    - 加法术（自动生成卷轴，进掉落和坊市）、物品、妖兽（用游戏现成的程序画法，按等阶、地域自然刷新）；
    - 给法术、物品配图标；
    - 监听开局、每帧、每日、击杀；
    - 存自己的存档数据。
  - 模组对话会等开场剧情关掉再弹。
  - 出错隔离：setup 抛错只停这个模组；回调连续出错 20 次自动停用。
  - 新内容的 id 必须带「模组 id + 下划线」前缀。
- **模组面板**：标题画面 →「模组」。
  - 已安装：启用、停用、卸载、导入 `.fmod`。
  - 模组平台：填地址连接，浏览、搜索、排序，一键安装和更新。
  - 改动后点「重新载入」生效。
  - 打包时可用 `VITE_MOD_STORE` 预置平台地址。
- **示例模组**「青冥剑修」（`mods/qingming/`）：两门剑诀、两种物品、雷纹狼、开局对话、斩五头狼领奖。
- **打包工具**：`npx tsx tools/mod-pack.ts mods/<模组>`。写模组的说明在 `mods/README.md`，类型提示在 `mods/sdk/`。
- **模组坊**（`platform/`）：零依赖的 Node 服务 + 网页商店。
  - 功能：注册登录、发布 / 更新（id 认主、版本只升不降）、搜索、标签、详情、下载、评分、下架、管理员接口。
  - 部署：带 Dockerfile。说明见 `platform/README.md`。
- 测试：
  - `tools/test-mod.ts`（24 项）；
  - `platform/test/api.test.mjs`（31 项）；
  - 浏览器里实走了一遍「平台发布 → 游戏里连平台安装 → 重新载入 → 模组生效 → 学会模组法术」。

## v0.54.2 · 众修神通 · 阵法精熟

- **敌修也会神通**（`world/foeskills.ts` 的 `shenKit`、`world/npcshen.ts`）：
  - 结丹以上会灵力化形：一形（元婴与首领两形），按名字定下修哪一形，同一个人每次都一样。七形都改写成敌招：青龙一道直线、火凤圈里留火、白虎扑击破甲、玄武护体、雷鹏连环落雷、麒麟大圈震晕、魔猿扇面击飞。出招前地上照样亮预警，灵兽法相脚下带暗红煞气。
  - 元婴会元婴出窍：肉身就地盘坐（单独一个可打的目标，血是本体三成，不掉宝），元婴缩成尺许，出手 ×1.3、遁速 ×1.6，走不出肉身 900 像素，14 息后归窍。打破肉身：元婴震回、眩晕 2.5 息、折损两成气血。
- **同行友人也会**：结丹以上会化形助战，用的就是主角的化形实体，从友人身上起手，不含玄武。元婴友人会出窍：肉身成了敌人的仇恨目标，护光破了就退下调息。懂阵的友人（约三成，结丹以上全会）被围时布困阵、庚金剑阵，你伤重时布回春阵。友人布的阵不存档、不占你的阵数、你也收不走。
- **敌阵多了**：筑基敌修会困阵、迷踪阵、庚金剑阵，结丹以上再加地火阵、五雷阵。迷踪阵走到阵界会被雾兜回阵中；庚金、五雷是杀阵，剑雨雷火落在你脚下，可以直接冲出去。
- **每座阵的精熟**：每座阵各分初成 / 小成 / 大成 / 圆满（经验 0 / 8 / 25 / 60）。布一次 +2，阵中困敌也长。每级威力 +12%、半径 +6%、时长 +20%、阵眼 +25%、灵石 −8%；圆满时省一面阵旗。阵法盘里能看到当前精熟和进度。
- 测试：`tools/test-v0542.ts`。

## v0.54 · 社交不再只围着知交转：友人同行、可以走进去的秘境、热闹起来的人间

负责人提了四件事：
- 知交按钮改成「友」，可以邀朋友一起出去；
- 秘境不能再是一张纸，要能真的走进去，分小、中、大三级，有真有假；
- 宗门和散修不够活跃；
- 被追杀、被拦路时，劫修和妖兽都只打你，彼此却不打——不合理。

方案见 `docs/v0.54-plan.md`。

### 一、三方混战（`world/combat.ts`）
- `teamOf` 把没编派系的修士（劫修、追兵、散修）归 `@rogue`，没编派系的妖兽、鬼物归 `@wild`，两拨不再是一伙。
- 妖兽护领地：劫修、追兵、路过的修士闯进它的察觉范围，它会扑上去；动了凶性的妖兽见人就咬。
- 追兵被咬住会先甩开妖兽（仇恨权重 ×2.8）；劫修之间仍然同仇敌忾。被追杀时把追兵引进兽窝，可以坐收渔翁之利。

### 二、友（`world/friends.ts`、`ui/FriendsPanel.tsx`）
- 「缘 · 知交」按钮改为「**友 · 友人**」，H 键打开友人录，分同行、知交、知交、邀约四页。友人录完整保留，作为其中一页。
- **同行**：最多三人（含伴侣）。
  - 身边的知交可以当面邀请；不在身边的好友（好感 ≥ 40）可以传音相邀，按路程一到七日后赶到身边，也可能推辞。
  - 可以下令原地等候、跟上、散去；跟随逻辑读 `waitAt`。
- **T 键让同行者靠后**：同行者整天贴在身边，T 键先给秘境入口、阵眼、奇遇等，没有别的可交互才与同行者说话。
- **NPC 主动邀约**：好友每十几二十日传音一次。
  - 「同探秘境」：会合处现出一座小秘境，友人结伴一同进去。
  - 「被围求援」：赶到时现场有一场混战，解围后好感 +14、得一份谢礼。
  - **有真有假**：表面热络、心里另有打算的人约你，会合处可能埋着伏兵，开打时他也翻脸。境界高两层、神识外放、吃过亏的阅历、天衍诀或明清灵目，能在信里看出蹊跷。爽约要掉好感。

### 三、真秘境（`data/mijing.ts`、`data/mjrooms.ts`、`world/mijing.ts`、`ui/RealmHUD.tsx`）
- **独立场景，不刷新页面**：
  - 秘境坐标放在世界地图之外（`REALM_OX`），有自己的碰撞、底图（分块预烘焙：地面材质 + 岩体皴点 + 墙的立面）和幽暗光照。
  - 渲染走一条精简管线（`Renderer.renderRealm`），不画大地图的地表、山树、城镇、天气。
  - 战斗、法术、法宝、阵法、化形、元婴出窍照常可用，同行友人一同进去。
  - 秘境里不存档，存档记的是入口外的位置。
- **预制石室随机拼图**：
  - 30 种设计好的石室：环廊水池、十字厅、长廊石像、迷宫、熔岩深渊、群岛、宝库护城河、首领祭坛、过道岔路……
  - 每次随机挑选、旋转、镜像，门对门用三格宽的甬道接起来，再把正对的空门打通成回环。每一张都不一样，每一间都有设计。
  - 妖物出没点、宝匣、灵草、古碑、出口都在模板里预留了位置。
  - 9 种主题（洞府、古墓、冰窟、熔窟、妖林、沙城、海宫、大殿、赤霄禁地），各有地面、墙色、摆件、妖物和水池 / 熔岩 / 深渊。
- **三级**：
  - **小秘境**：野外的前人洞府多了「入府探查」；江湖传闻和友人相约也会生成。
  - **中秘境**：八处原设险地，有首领。首领一除，60 日后复原。
  - **大秘境**：赤霄禁地、归墟殿、封魔山、陨魔谷谷底，按原设节奏定期开启（赤霄禁地五年一开、只许筑基以下进入），多层。
- **玩法**：
  - 走进新的石室才惊动其中的妖物。
  - 宝库和部分首领室门前有禁制门，要用破禁之局或破禁符打开。
  - 首领伏诛后宝匣和出口亮起；多层秘境踏上古阵进入下一层。
  - 中、大秘境里有别家修士：一半见人就动手，一半你不惹他、他不惹你。
- **有真有假**：江湖传闻（地图标「秘？」）约三成是假的：到了要么是空山，要么是劫修设伏。

### 四、众生行（`world/zhongsheng.ts`）
- **宗门巡山**：大宗门左近常遇巡山弟子，是名册上的真人，能交谈、能结交。与该宗结了深仇的，他们一照面就动手。
- **散修猎妖**：一伙散修围着妖兽厮杀。你相助会分得一份灵石；你先动手，他们就翻脸。
- **斗法抢宝**：两伙修士为出土的宝物大打出手，胜者带宝离开；两边都倒下的话，宝物落地。
- **秘境人潮**：大秘境开启的日子，入口一带尽是赶去的修士。
- 这些人都「不冲你来」（`noP`）：不进自动锁定，你的同阵修士、灵宠、虫群也不打他们，除非你先动手。
- 散修人口上调：南荒 380、沧溟海 200、中州 500。`living.ts` 的人口上限同步调整，三年模拟每日结算 2.3ms。

### 一、宗门任务「指路」（`town.taskWhere()` 一个函数统一回答「去哪、多远」）

| 任务类 | 指向优先级 |
|---|---|
| 猎杀 / 除魔 | 已探明的目标怪（附距离）→ 妖兽巢（`lairMarks`）→ 已知凶地 / 秘境（`beastHome`，只指已探明）→ 按习性给方向（`beastRegion`：林深之处 / 雪线 / 荒野，八向 × 三档距离挑最贴合的）→ 回宗门打听 |

| 巡查 | 直接指要巡查的地点 |

大事记「眼下机缘」（每条带「指路」按钮，同样不关面板）、世界地图 / 小地图的青色「指」与黄色「任」。
另外世界地图上所有标记的名字改为**逐行避让**（`placedBoxes`），宗门四条任务挤在一处时不再糊成一团。

顺带修的一个真 bug：任务按钮原来 `disabled: p < t.need`，而 `taskProgress()` 在击杀数小于 `have` 时返回**负数**，

本地在 1440×900 / 390×844 / 844×390 / 2560×1440 四档都进得去、走得动、画面正常（亮度均值 64–86，黑暗像素 <5%），

## v0.52.8 · 流畅大修（软件渲染整帧 101ms → 61ms · 极简画质档 · 远景长卷删除）

玩家反馈「卡死了」，实测（Chromium + SwiftShader 纯 CPU 光栅、1440×900、无显卡加速的最坏情况）整帧 **101ms**，
逐层归因后发现：没有单一元凶——`drawImage` 合计 33 Mpix、每帧 2200 次路径操作（1461 stroke / 791 fill / 260 save+restore），
开销匀摊在「草丛 108 次贴图、神识圈一整张 2R×(2R) 巨图、云影迷雾层、倒影、炊烟、护山大阵」这些**纯氛围**上。
把所有 `draw*` 方法一起停掉只剩 1.1ms，逐个停掉却每个只「省」3~6ms（互相遮挡），证明瓶颈是**总填充量**而非某一个函数——所以这一版按「总量」下刀：

- **新增第 5 档「极简」**（`Renderer.LEVELS`）：世界层像素预算 0.78M（原最低 1.2M），并联动关掉倒影 / 山腰云 / 炊烟 / 护山大阵（`lowered >= 4`）、草丛按坐标散列抽稀（`thin` 2/4）、神识圈改描边版；
- **神识圈不再贴巨图**：`SenseFx.drawCheap()` 用「一圈宽描边渐变 + 两道墨线 + 四道刻痕」代替每帧混合一整张 2.18R 见方的大图，CPU 光栅下便宜一个数量级（原来的 11 Mpix 级合成就此消失）；高画质仍走预合成的 `drawPooled`（一帧两张 512 贴图）；
- **自适应画质可回落**：`adapt()` 原来只降不升——开局加载卡一下就被永久钉死在最低档，画面白白变糊；现在连着两次稳在 58 帧以上会升一档（`goodRun`，有回差），帧时烂到 25 帧以下时一次降两级（不再有开头十几秒的幻灯片）；
- **远景长卷整块删除**：`mood.drawBack` 里那三层 `far_mtn_*`（屏幕上方那排意境远山）每帧要做三次全屏清层 + 染色 + 雪线 + 贴回，对玩法零贡献，按玩家要求直接删掉（连带 `far_mtn_*.webp` 资源与设置项一起移除，省三次全屏合成）；
- **氛围层半速**：云影 / 未探迷雾整层降为 30fps 重画（`atmoStep`/`atmoSkipNow`），dt 折算保证云的漂移速度不变，镜头一动或天气非晴立刻恢复逐帧；
- **神识水墨裁到包围盒**：`drawMemory` 不再做两次整屏径向渐变（其中一次带 `saturation` 混合），只在神识圈罩住的那一圈开临时图层。

**结果**：同一台无显卡加速的机器，整帧 **101ms → 61ms（-40%）**，帧率 **9.9 → 16.5**；`tsc --noEmit` 通过；
1920×1080 / 1440×900 / 390×844 三档分辨率的冒烟测试无报错、画质档各自收敛；有显卡的机器走 WebGL 路径，这一版只多不少。

> **补丁**：`v0.52.3 / v0.52.4 / v0.52.7 → v0.52.8` 的差分补丁 0.7MB（三份基线各一份，执行器按 `index.html` 指纹认版本）。
> 执行器这一版加了**预检 + 原子落盘**：先把所有基线文件 SHA256 校验完再动手，新文件全部在内存里生成校验通过后才逐个 `rename` 落盘——
> 以前「某个文件对不上」会停在写到一半的状态（`index.html` 已换、新 js 没写），现在对不上就一个字节都不改。

## 第四十三步（v0.43）：活世界——众生各有储物袋、功法、门派、家小、恩仇与交游

> 这一版只做一件事：让人活过来。以前的 NPC 只在你身边才“演”，你一走就只剩一行数据；还动不动有人传音“被一伙劫修围住了”——那伙劫修是临时编出来的，你不去，他就被随机判死。现在每个人都在你看不见的地方照样过日子，找你的人也一定有来由。

- **每个人都有储物袋**（新 `src/world/living.ts`，`NpcData.bag`；灵石仍记在 `wealth`）：开局按境界、门派与当地坊市的产地规则配好丹药、灵草、材料、符箓、法器。采药猎妖得来的东西拿去坊市换灵石，再换丹药、玉简、法器；被劫、被杀，袋子就到了别人手里。
  - **你杀了谁，掉的就是他袋子里的东西**（外加一两枚他所习功法的玉简拓本），不再随机掉落；NPC 当街斗死了人，储物袋归胜者，散落一部分在地上；
  - 交易玉符卖给你的东西，也是他袋子里真有的。
- **每个人都有功法**（`gf` 主修心法 + `arts` 所习玉简）：宗门弟子修本宗心法（青霞心经、素女轮回功、天魔大法……），散修修长青功、五行诀之类；宗门藏经阁用贡献换、坊市花灵石买、师父传授、探宝所得。功法与法器让他打起来更难缠。
- **门派活了**：宗门弟子做差事攒贡献、领月俸，外门 → 内门 → 核心 → 执事 → 长老逐级晋升，执事、长老收徒传道；宗门论功行赏，赐下筑基丹 / 降尘丹；散修会拜入山门；残害同门者叛出师门，全宗追杀。
- **家庭**：结为伴侣 / 成亲（凡人嫁随夫居）、生儿育女（凡人多子，修士难有子嗣），新生儿随父姓、认得父母兄姊；年满十四测灵根，有灵根的拜入父母的宗门，没有的留在家乡务农、读书、学做买卖。人死了，亲人守丧，遗物由子女 / 伴侣 / 徒弟继承；**父母的血仇传给子女**。
- **仇恨**（`hate`：恨谁、多深、为什么；血仇几乎不会淡去）：被劫、亲人被杀、争灵草、当众落败都会记仇。打得过就去寻仇；打不过就请亲友助拳（贪财的要收钱）、闭关苦修，或躲着更强的仇家；旧怨随岁月淡去，也会被双方共同的朋友说和。杀了谁，他的亲人、伴侣、师徒结下血仇，一代代传下去。
- **社交**：采药猎妖时在同一处结识新朋友，朋友的朋友也成了朋友，意气相投的义结金兰；探亲访友时赠礼、接济灵石；财帛动人心——谁在遗府得了宝物、消息走漏，附近的贪狠之辈就会盯上他。
- **人人都有“眼下的打算”**（`plan`：做什么、去哪、找谁、为什么）：闭关、采药、猎妖、赶集、宗门差事、探亲访友、求结伴侣、寻仇、劫道、避祸、养伤、守丧、寻宝、传道、请人助拳、操持生计——
  - 神识之内照着走、照着说：头顶冒的话、交谈的开场都和他眼下的事有关（“道友可曾见过某某？……此仇非报不可”）；
  - **劫道、寻仇当着你的面发生**：劫匪追着肥羊走，追上了就动手（“留下储物袋，饶你不死！”），你可以插手；
  - 神识之外按天结算：实力、运气、帮手定胜负，结果写进「天下事」。
- **找你帮忙，一定有来由**（重写 `war.ts` 的散玉符）：
  - 删掉了约每月一封、凭空编造的“被一伙劫修围住”求救，以及随机的论道邀约；
  - 只有**真认识你**（相识且好感 ≥ 25，或结拜 / 师徒）、**真遇上了事**（被活世界里某个真实存在的人劫了、杀了亲人）的人，才会传来「求助」：谁、在哪、被谁（境界、门派、性子）、丢了什么、对方如今在哪一带落脚，写得清清楚楚；
  - 应下后地图上标出那人的实时行踪（「仇」字跟着他走）；杀了他，抢去的东西就在他袋里，委托人传讯致谢、奉上谢礼；
  - **不去也无妨**：没有惩罚，事情在活世界里自己往下走——他可能自己去报仇，可能请别人，也可能出事；
  - 同一时间最多一封求助在途，两封之间至少隔 25 天；认识你的人突破、成亲、添丁，会安静地送来请柬（不弹提示）。
- **察其根底**（交谈新选项）与**人脉录**：人物详情新增「眼下 · 门派 · 功法 · 家小 · 师承 · 交游 · 恩仇 · 储物袋 · 生平」；储物袋要修为高过他、或交情深厚才看得透。人脉录新增「天下事」页：活世界编年，可按类别筛选、只看相识之人。
- **打听消息**说的是真发生过的事；**出关**先听「世事变迁」：闭关这些年，你认识的人生了谁、娶了谁、死在谁手里。
- **性能与存档**：每日结算约 3 ms（含原有众生结算）；闭关十年一次补算约 2 秒；存档只多几个字段，旧存档自动补齐储物袋与功法。
- 新测试 `npx tsx tools/test-living.ts`：三年模拟（添丁、姻缘、劫案、仇杀、晋升、突破都在发生；灵石无负数、关系双向、人口稳定）、熟人被劫 → 指名道姓的求助 → 杀了劫匪 → 委托人致谢、存档往返、闭关十年补算与「世事变迁」。`tools/test-relations.ts` 照常全绿。

## 第四十一步（v0.41）：境界压制——神识之内，低一个大境界举步维艰，低两个以上被压在原地

- **规则**（新 `src/world/suppress.ts`，接入 `combat.ts`、`foemind.ts`、`foeskills.ts`、`pursuit.ts`、`npc.ts`）：

  - 城里的闲人：对你动了歹意的（劫道、追杀、逃窜）在神识内被压住；**神识外放**时威压全开，闲人、凡人也一并压住（被压住的御剑者会落回地面）。

  - 举步维艰：脚下一圈淡金威压纹缓缓旋转，头顶细碎光丝不断压落，身形微矮；

### 一、卡顿优化
- **地表缓存**：完整的地表着色器不再每帧全屏重算。它画进一张比屏幕大一圈的缓存（四周各留 1/4 长边的余量），每帧只采样一次。
  - 镜头靠近缓存边缘、缩放变化超过 7% 或换季时，才在后台缓冲里分 4–6 条、逐帧渐进重画，画完再与前台交换。
  - 重画会按镜头速度预判前进方向。瞬移或大幅缩放时一次画完。
  - 镜头静止时，地表几乎零开销。
- **水面动画拆出**：河水流纹、细水线、岸边白浪、海面焦散、弧形浪纹、碎金、浪花，改在后期着色器里每帧只算水面像素。
  - 缓存里只存静态底色与水面参数（河：沿程/横向坐标与水深；海：离岸距离/深浅）。
  - 沿程坐标按噪声周期（1920）取模，无接缝。
- **精灵后台生成**：山（单座约 40ms）与树（含 getImageData 回读）改到 Web Worker（OffscreenCanvas）里生成，以 ImageBitmap 零拷贝传回，主线程不再因新山新树进入视野而顿一下。
  - Worker 不可用（老浏览器、Node 测试）时，自动回退主线程生成。
  - Worker 内联打包，双击 index.html 也能用。
- **分辨率上限下调**：
  - 世界层默认 ≤1.5× 像素比，后期输出与世界层同分辨率；高分屏不再按 2× 跑整套后期。
  - 自动降档更积极：每 2.5 秒检查一次，低于约 48 帧就降一级（共 3 级：世界层像素比、地表缓存分辨率、特效档）。
- **F3 性能面板**：显示以下数据。还卡的话，按 F3 截图发我即可。
  - 最慢一帧、卡顿次数（>50ms）；
  - GPU 耗时（EXT_disjoint_timer_query_webgl2）；
  - 地表缓存尺寸与重画次数；
  - 后台精灵生成情况；
  - 自动降档级别。

## 第九步（v0.9）：WebGL 渲染 + 特效 + 打击感 + 境界压制
- **渲染管线**（`src/gl/`）：世界仍由 Canvas2D 代码绘制，再作为纹理交给 WebGL2：
  - `stage.ts`：一次全屏后期合成——冲击波扭曲、昼夜调色、**神识圈外记忆水墨**（边缘晕染墨丝流动）、云影/迷雾、雾/沙/闪电、纸纹、暗角、受伤血晕；

  - 特效画进 HDR 帧缓冲，三级降采样泛光（bloom）；柔和压高光，避免发白成团。

- **画质**：自动（持续掉帧时逐级降低世界层分辨率 → 关泛光 → 粒子减半），或手动 高/中/低；手机默认分辨率上限 1.5×。**F3** 显示帧率与耗时。

- **B 天空意象**：晨雾带（卯时）/ 暮霞（酉时）/ 昼间流云；夜里按月相出月（每月 10–20 日满月，其余蛾眉月）带月晕；深夜晴天淡入星汉。月与星画在不经调色的 UI 层，自己发光。雨天镜头前加第二层极淡斜雨幕。
- **C 烟岚**：湖雾的程序圆团换成水墨烟岚贴片（横条 / 团状，缓移 + 极慢旋转）；大山约一半横一条山腰云（云断山腰 = 高远）。
- **D 点景池**（`world/scenery.ts`）：烟雨湖（云梦泽）配远帆 + 夜里渔火 + 芦苇，碧落湖一片帆几丛芦苇，黑水泽只配芦苇（死寂也是意境），镜湖入冬换残荷，冬日 / 雪天城镇宗门旁探出一枝红梅；村落炊烟换成一缕直上的水墨炊烟，黄昏清晨最浓；雁阵每隔一阵横越镜头（秋天更勤）。
- **E 后处理**：宣纸纤维（overlay 约 5%）+ 淡墨洇染四角。
- **时辰色罩表**（`weather.ts` 的 `MOOD_MASK`，晨午暮夜 × 晴雨雪雾）：GL 模式并入后期着色器的 tint，Canvas 模式用 soft-light 罩整个世界层。
- **留白雾带**：镜头静止超过 10 秒、不在战斗、不在飞行时，屏幕边缘烟岚缓缓加浓——停下来看风景时画面自己"收"成一幅立轴；雾天常驻一半。
- **声音**（`ambience.ts`）：雁鸣、近帆时的橹声、卯时晨钟、酉时暮鼓（全合成）。
- 开关：`localStorage.fr_mood = '0'` 可关闭全部意境层。
- 验收：`node tools/moodshot.mjs`（晨-镜湖 / 暮-村落 / 夜-星汉渔火 / 雨-烟雨泽 / 静止雾带五张截图 + 意境层开关前后帧时间），SwiftShader 下帧时间差在 ±1ms 噪声内，无报错。
