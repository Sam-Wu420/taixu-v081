# 恩怨与江湖重做：受害者不再被追杀，NPC 更像活人

> 这个文件原来是夜无赦首领的计划。那份计划还在执行，已经另存到 `B-HD2D/docs/夜无赦-计划.md`。下面是新计划。

## Context

**玩家反馈**：「练气期被筑基金丹打劫就算了，为什么还一直寻仇，到哪里躲着都追杀，一直追个不停，我是受害者呀……不然都出不了村子」。

**用户的要求**：吸收 GTA6、荒野大镖客 2、鬼谷八荒的系统，让 NPC 更好。三套里各取什么，已经在对话里和用户说过：
- GTA6：目击者认人、通缉热度分级、甩开视线后继续搜捕、各地口碑、江湖信息流、NPC 自己执法；
- 荒野大镖客 2：荣誉与舆论、拦路交钱了事、躲风头；
- 鬼谷八荒：调停、赔礼化解、生死斗、NPC 主动来找你。

**探查结论**：代码里有七处直接造成「受害者被追杀」，都在 `B-HD2D/src/world/`：
1. `relations.ts` L205-210：你杀了人，他的亲族一律记成死仇（`grudge=2`），不看是不是自卫；他的好友在你自卫时也有一半会结仇。
2. `renxin.ts` L1106 / L1167：劫匪打倒你、搜走储物袋后，反而记恨你（`grudge 1`）。从此他见你必扑，新手保护也对他失效。
3. `relations.ts` L595 / L600：你饶了来劫你的人，或者向他要买命钱，都会被他记仇。
4. `relations.ts` L324-332：死仇每 25–70 天来一次，次数不封顶、永不淡化。`startHunt` L428 会把仇人直接搬到你所在的地图。追杀失败后（`pursuit.ts` L215），下一次反而来得更快、更强。
5. `fellows.ts` L320：劫修团伙追杀没设开始日，所以永不超时，粗模拟时还一直朝你所在的位置跑。
6. 劫道失败后没有冷却：你逃掉以后，下次被他神识察觉，还是有 50% 概率扑上来。
7. `war.ts` L401-405：仇人寄来战书，你不去赴约，就自动升级成血仇。

练气期本身也会被追杀：`pursuit.start` L131、`game.ts` L1124 的门槛都是 `realm>=1`。

## 第一批：修投诉，搭好骨架（先做）

### 1. 谁先动手谁理亏
- **记录先手**：给 `NpcData` 加 `assail?: { day; by: 'npc' | 'hero' }`，记下这段冲突是谁先动的手。打标记的地方：
  - `npc.ts` 接近玩家并转成敌人时（L848-856、`toEnemy`）；
  - `fellows.ambush`；
  - 仇人追杀（`startHunt` / `pursuit.start`）；
  - 你主动对 NPC 出手（`combat.hitEnemy` 打中一个还没敌对的 NPC，就记成 `hero` 先手）。
- **判定改用先手标记**：`npc.ts` L1187 原来用 `hostileTo` 推测「自卫」，改成看先手标记。
- **`onPlayerKill` 按先手分级**（照抄 `living.killed` 现成的 `selfDef` 分级）：
  - 对方先动手：
    - 亲族只结「旧怨」（`grudge 1`，热度低，不发起追杀，可以上门讨说法）；
    - 好友不结仇；
    - 宗门声望照旧只轻罚。
  - 你先动手：维持现在的血仇规则。
- **删掉受害者被记恨的几处**：
  - `renxin.ts` L1106 / L1167 劫匪的 `grudge`，改成「得手，心满意足」；
  - `relations.ts` L595 / L600 来劫你的人被饶、被要买命钱时的结仇，改成「怕了你」，并记一个冷却。

### 2. 热度、搜捕、降温（GTA 星级）
- **热度值**：`NpcData` 加 `heat?: 0–100`，加 `seen?: { day; x; y; map }`（最后一次看到你的时间和地点）。
  - 热度来源：结仇的轻重、你是否先手、有没有目击者。
  - 热度换算成 1–6 枚血印。
- **自然降温**：
  - 每天自然降一点，受害一方的仇降得快；
  - 换地图后，热度降得更快，仇人也不再跟着跨图；
  - 闭关、离开当地越久，热度降得越多；
  - 每次追杀扑空，热度降一档。连续三次扑空，对方就「认栽」：热度清零，仇降回旧怨。
- **`daily` 怎么用热度**：在 `relations.ts` L316-348 里：
  - 热度决定 `huntAt` 的间隔；
  - 低于阈值就不再主动追杀，只在路上偶遇时对峙；
  - 删掉 `startHunt` 里强行搬图那一行。
- **追杀失败改成降温**：`pursuit.ts` L215 不再缩短下次间隔，改成降热度、拉长间隔。
- **搜捕范围**：追杀者丢了视线后，去 `seen` 那个点附近搜一阵，地图上显示一圈「搜捕范围」，时限到了就离开。
  - `pursuit.ts`、`npc.ts` L669 的粗模拟，都改成朝 `seen` 走，不再朝你的实时位置走；
  - 守在城外等你也有时限，几天等不到就走。
- **几处顺手的修正**：
  - `fellows.ts` L320 补上 `huntStart`；
  - 战书不去，改成扣一点声望，并让对方嘲讽你一句，不再升级成血仇；
  - 劫道失败后，这个 NPC 记 30 天冷却，冷却内见了你不再扑。

### 3. 目击者与认人
- **谁算目击者**：打斗时，围观的 NPC（`npc.ts` `gatherWatchers` L1051）和神识范围内的活人。
- **认不出你的情况**：没有目击者，或者你敛息、蒙面，或者对方境界比你低、看不清你。这时仇恨记在「无名凶手」头上，不会有人追杀你。
- **认人看外貌**：认人用的是你当时的衣着、遁器、法宝。用衣橱换装、换遁器、服易容丹（新物品，坊市有卖）后，追杀者神识扫过你也认不出，热度照常降。
- **目击者也站在受害者这边**：你被劫的时候，如果有目击者，劫匪一方就理亏，他的亲友连「讨说法」都不会来。

### 4. 练气期保护与拦路交钱（荒野大镖客 2）
- **追杀门槛**：练气期不会被追杀，`pursuit.start` 和 `pursuitTriggers` 的门槛提到筑基。剧情和你先手的例外。
- **筑基以上劫练气期改成「拦路索财」**：在 `npc.ts` L1083-1090 的活人 NPC 劫道前，先弹一个对话，写法照 `happen.ts` L381 / `jianghu.ts` L683。三个选项：
  - 交出三成灵石：这事就算了，给他记冷却，不结仇；
  - 逃：有成功率，逃掉了不结仇；
  - 打：他先动手，你反杀算自卫。
- **对境界相近的人**：照旧直接开打，但先手记在他身上。

### 5. 组队：人多势众，队友是证人（`world/fellows.ts` 结伴队伍 + `relations.ts` 的同行者、护法）
- **劫道看整支队伍**：劫道判定按你们队伍的总实力算，带着同行者、护法、结伴队友时，劫修更少来惹。
- **队友是证人**：被劫时队友作证，劫匪一方理亏。
- **谁动手记谁头上**：队友杀的人记在队友头上，不会全算到你身上；你命令队友动手，算你先手。
- **队友的仇也会找来**：队友自己的仇家会来找他。你可以帮他打、调停，或者袖手旁观，你的选择会影响他对你的好感。
- **劫修团伙的仇**：劫修团伙（结伴作风「劫」）有了热度、降温和冷却，不再永久追杀。
- **队伍框**：队伍框里显示每个队友有没有被人盯上（小血印）。

### 6. 宗门：靠山与执法（`world/town.ts` 宗门身份、`relations.ts` 宗门声望与同盟、`zhongsheng.ts` 巡山）
- **宗门护短**：宗门弟子被高出一个大境界的人追杀时：
  - 在宗门附近：巡山弟子或长老赶来（照 `rel` 义兄、师父救援的写法）；
  - 在远处：事后宗门给对方送去「警告帖」，对方热度大降；不听警告的，宗门执法堂把他列为宗门仇敌，按宗门同盟关系传开。
- **宗门地界是避难所**：宗门地界算安全区，在宗门里闭关时热度降得最快。洞府附近也算半个安全区。
- **宗门执法也按先手算**：你先手杀害同门或别宗弟子，宗门照样追究。现有的执法队、围剿（`relations.ts` `siege`、以「奉」开头的结仇原因）保留，只是判定改成看先手。
- **新增宗门任务「缉凶」**：去抓劫修或者被通缉的恶人，用 `refreshTasks` 的任务池，赏贡献。

### 7. 看得见：热度血印、恩怨页、出村预警
- **热度血印**：屏幕上方显示血印，表示有人在找你（几枚就是几级热度）。手机布局要放得下。
- **人脉录加「恩怨」页**：在 `ui/ModalLayer.tsx` L398，原来那个叫「恩怨」的流水页改名「记事」，新的「恩怨」页列出：
  - 谁在找你、为什么、是谁先动手；
  - 热度几级、多久后会放弃；
  - 认不认得你；
  - 现在能用哪几种化解办法。
- **出村预警**：在 `game.ts` `pursuitTriggers` 里检测出城的那一刻，有热度的仇家在附近时，发一条预警：「东南三里外有人在等你」。高热度的走「急」级别，低热度的只进「讯」。柳三娘的密信从「付费预警」升级为「点名谁在等你」。

## 第二批：化解恩怨、各地口碑、江湖传音、宗门外交、队伍指令

- **宗门出面化解死仇**：用宗门贡献请长老出面调停。贡献够、长老境界压得住对方，死仇就能降成旧怨。
- **宗门之间的关系影响你**：同盟宗门的弟子路上帮你；敌对宗门的弟子会挑衅、盘查你，甚至动手。宗门之间开战时（`war.ts`），你按自己的身份被卷进去。
- **队伍指令**：手机和电脑都能对队友下令：掩护、包抄、护着我撤、别杀他。指令写在队伍框上。队友有自己的底线，你太狠，他会劝你，甚至离队。
- **化解恩怨**：在现有的 `parleyNode`、`mediator` 上扩充：
  - 赔礼；
  - 退还夺来的东西；
  - 托共同的好友调停；
  - 请宗门长辈出面（用宗门声望和师父关系）；
  - 立心魔誓；
  - 约一场「生死斗」了结，赢了恩怨两清。
- **报官反悬赏**：被劫以后，可以去坊市或宗门报案，把劫匪挂进 `happen` 的悬赏榜（`npcId` 字段已有），由执法弟子或赏金客去抓他。
- **各地口碑**：每个城镇一本账，在 `townwreck` 的 `TWCity.good` 基础上扩成通用口碑。
  - 口碑好：打招呼、给折扣、帮你躲追兵（「仙师进屋躲躲」）；
  - 口碑坏：见你就躲、报官、守卫盘查；
  - 口碑会随时间淡去，也会顺着商路传到邻城。
- **江湖传音**：一个信息流面板，数据用 `jianghu` 的 `Rumor`（`kind:'news'`）。你做的事会传开，被各地修士议论；求助、悬赏、组队这些支线也从这里接。原来的「神识中…」「江湖传闻…」小消息都收进这里。

## 第三批：NPC 自己的生活与执法、搭档、夺宝局

- **NPC 执法**：执法堂、巡察使去抓 NPC 恶徒（照 `pianju` 执法队的写法）；NPC 之间劫道会被目击、被报案、被通缉。
- **NPC 主动找你**：根据他自己的心愿，来求助、结伴、借钱、拜师、切磋。
- **搭档**：道侣或义兄弟做固定搭档，有自己的底线。你太狠，他会劝你、离开你，甚至反目。
- **夺宝局**：踩点 → 找帮手 → 动手 → 脱身，脱身时用上热度、易容和目击者这些机制。

## 验证

- **新测试** `tools/test-feud.ts`，覆盖这几种情况：
  1. 练气期被筑基劫道：交钱后 60 天内不再被这个人劫；
  2. 被劫后自卫反杀：劫匪亲族只结旧怨，不追杀；
  3. 你先手杀人：亲族结血仇，会追杀；
  4. 追杀扑空三次就认栽，热度清零；
  5. 换图后仇人不跟着跨图；
  6. 没有目击者，或者易容后，不会被认出；
  7. 守在城外等你的人到时限会离开；
  8. 出村时有预警；
  9. 战书不去不会升成血仇；
  10. 存读档后热度不丢；
  11. 带着队友时劫修更少来；队友作证后算自卫；队友杀的人记在队友头上；
  12. 宗门弟子在宗门附近被以大欺小时，有巡山弟子或长老来救；远处被追杀时，宗门发警告帖，对方热度下降；
  13. 「缉凶」宗门任务能接、能交。
