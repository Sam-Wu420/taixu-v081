# 邪修世界首领「噬魂魔尊 · 夜无赦」：照《复仇者》全套招式做修仙版

> 这个文件原来是「B 版收官计划」，那一轮已经全部做完，结果记在 `B-HD2D/docs/交接-2026-11-16.md`。下面是新计划。

## Context

用户给了一段 DNF「复仇者 / 惩戒者」技能演示：`C:\Users\10531\Downloads\复仇者.mp4`，5 分 7 秒，1280×720，没有字幕文件，招式名写在画面下方。用户要在 B 版（`重构v0.57\B-HD2D`）里照它做一个**邪修世界首领**，要求：

- **招式**：一招不落，动作要和复仇者一样帅；名字、技能名全部改成修仙版；特效越炫越好，要让人一眼想玩。
- **画法**：不用骨架模型，用贴图。每个状态、每个招式 1–3 帧，其余靠程序动画补；贴图用 MCP 生成，画风参考游戏现有画风和复仇者的动作。

用户已经定了：
- **出现方式**：周期降临，降临时全服公告。
- **形态**：随战斗推进变身，人形 → 半魔化 → 魔躯。觉醒大招只在魔化之后出。
- **奖励**：三样都要——掉落魂镰（新兵器种类）、能学到他的几招、高阶材料与法宝。
- **贴图**：按需生成，每招只画关键帧。

- **人身**：黑袍，持一柄巨大魂镰；

## 二、做法

### 第 0 步：参考视频逐帧拆解（主线做）

- 照撼山客那次的做法（`tools/out/ref-sanda/cut.mjs` 和 `docs/撼山客-参考视频动作分解.md`）：
  - 写 `tools/out/ref-avenger/cut.mjs`，按上表时间段逐招切；
  - 每段出 8–12 帧/秒的逐帧图和小片段，不进库。
- 写 `docs/夜无赦-参考视频动作分解.md`：每一招的关键姿势序列（起手、出手、收招）、节奏（每段多少毫秒）、特效分层（颜色、形状、几层）、镜头和全屏演出。这份是做贴图和招式的规格书。

### 第 1 步：贴图（美术线）

- **先定画风样张**：人身、半魔、魔躯各生成一张待机图，主线看图定稿后再批量生成。
  - 画风：游戏现有妖兽的「线稿 + 上色的暗黑奇幻概念画」，修仙魔修的造型；参考复仇者的剪影和比例（巨镰、披风、魔躯的角与翼）。
  - 提示词照 `重构v0.57\概念图\海渊\jobs.json` 的写法：透明底、`painterly highly detailed`、略俯侧视、`facing left`、不画字。
- **批量生成**：每招只画关键帧（起手、出手各一张，觉醒大招三张），能共用的姿势共用，约 80 张。
  - 用 `node tools/codex-image.mjs` 后台排队生成，多姿势的图用 `animated: true`。
  - 用 `tools/slice-sheet.mjs --max=640` 切，压成 webp，放 `src/assets/yewushe/`。
  - 帧对照表写在 `说明.md` 里，照 `src/assets/sea/说明.md` 的格式。
  - 包体预算 6 MB 以内。

### 第 2 步：首领的画法与程序动画

- **新写 `src/hd2d/bossthings.ts`**：照 `hd2d/seathings.ts` 的「单独贴图平面」做陆地版。
  - 去掉水线裁剪，`uA.w` 已经是现成的开关。
  - 立板在 GPU 上做挤压拉伸、翻转、旋转、闪白、调色、辉光。
  - 新加一个**残影池**：同一帧、透明度递减、沿冲刺方向拉长的立板。现有的残影只认人形骨架，这里要另写。
  - 接线照海兽：`render.ts` 每帧 `update(view)`；`combatfx.ts` 和 `gl/foegl.ts` 认 `seaHD` 那一类标记，跳过共享图集，这样首领不会被压糊。
- **新写 `src/world/yewushe-anim.ts`**：「招式 → 帧序列 + 程序姿态」表。
  - 每段写清用哪一帧、停多久、挤压量、前冲、旋转、残影。
  - 卡帧手感照撼山客：关键帧之间不插值，出手那一帧拉伸、顿帧，命中后直接切到收招帧。
  - 弧线、跃起、砸地的写法照 `seabeast.ts` 的 `leapStep` 和 `view()`。

### 第 3 步：首领本体与世界降临

- **新写 `src/world/yewushe.ts`**（`game.yewushe`）：
  - **周期降临**：结构照 `world/great.ts` 的大夺宝。
    - 每 200–320 游戏日一次；元婴以后更频繁。
    - 降临地点在陨魔谷外围、魔门六宗的赤土边缘，避开宗门的安全区。
    - 降临前一个月出江湖传闻（`g.news(...,'rumor')`）。
    - 降临那天天降血光：toast、全屏震、`g.news(...,'canon')`。
    - 地图上出「魔」字标记。持续 40 日不打就离开；打败后 1000 日内不再来。
  - **走近才生成**：走近 8000 内生成真身（`Enemy`，`shell = true`，由他自己驱动），离开就收起。照撼山客的做法。
  - **境界随玩家走**：比玩家高一个大境界，`blv >= 8`，这样首领血条和锁定大血条会自动挂上。
  - **形态机**：照 `world/hsp2.ts` 的半血换招表。
    - 开场是人身；
    - 气血七成时放「魔气入体」进半魔；
    - 四成时放「天魔降身 · 末劫」进魔躯：换贴图、换招表、全程霸体，并放一圈变身冲击波；
    - 觉醒大招只在魔躯时出，一场最多两次，用的是撼山客那套「大招名额」的写法。
  - **出招编排**：照 `hanshan.ts` 的 `direct / pickCombo`。
    - 节奏是「试探 → 连招 → 喘息 → 应对」，远近各一组连招表；
    - 「魔影随身」作为被动，每次出手时随机追加魔影追打。
  - **首领血条蓄力条**：大招前读条，写 `ultName` / `ultSrc`。

### 第 4 步：22 招（招式线，分三批）

- **框架**：每招一个 `SpecialMove`，用 `brawlmoves.ts` 的 `registerMove`，分别放在：
  - `world/yws-moves1.ts`：人身和半魔的招；
  - `yws-moves2.ts`：魔躯的招；
  - `yws-moves3.ts`：两个觉醒大招和极恶魔潮。
- **现成可用**：伤害、击飞、砸地、顿帧、镜头、破坏（`wreck`）。
- **特效**：一律真三维、越炫越好，用 `fx3dOf(game)` 全套：音障、冲击环、扭曲冲击波、火龙、四层爆炸、塌坑、地浪、立体火、弧带、光核、整屏变色。另外新增几种魔修特效：
  - 魂镰刀光：三维弧带，紫黑芯、血红边；
  - 冥狱石柱：从地里拔起的立体石柱；
  - 鬼门：立起的门框，加旋涡；
  - 魔触：分节带子，复用 seathings 的带子画法；
  - 魔翼：巨大的立体翼面。
- **全屏演出**：照撼山客。
  - 用 `impactfx.finisher`，书法大字写「弑」「劫」「灭」；
  - 用 `hsp2.show / scr` 做压黑、整屏变色、横贯光线；
  - 界面收起（`hsCine`）。
- **配音**：每招配合成音效，加在 `audio.ts` 里独立一段 `yws`。

### 第 5 步：奖励

- **魂镰（新兵器种类 `scythe`）**：
  - `WEAPONS` 加一类：七阶，`wpn_scythe_0..6`；
  - 近战招式表加一套镰刀连招，可以借用夜无赦的魂镰三式、回旋魂镰；
  - 刀光用镰的弧形；
  - 只有他掉，最高阶是他的本命魂镰。
- **能学的招**：回旋魂镰、劫轮、鬼门关、崩岳魔锤，照撼山客 `learn` 的写法。打赢以后在法术书里出现，能放进技能栏。
- **掉落**：高阶魔道材料、法宝、灵石。

### 第 6 步：试玩入口、测试、文档

- **试玩入口**：`try=yewushe`，参数如下。照 `tools/try-hanshan.ts` 的写法：清场、开阔地、木人桩。
  - `&move=<招>`：放单招；`&move=all`：轮着放；
  - `&form=human|half|demon`：指定形态；
  - `&at=spawn`：看降临公告。
- **测试**：新写 `tools/test-yewushe.ts`，照 `test-hsp2.ts` 的写法，覆盖：
  - 22 招都能放、都能收场；
  - 伤害走 `hitPlayer` / `npcHit`；
  - 招式路径上不取 `Math.random`；
  - 形态切换、大招名额；
  - 降临周期、选址、存读档；
  - 魂镰掉落、学招。
- **要改的共享文件**（只增不改）：
  - `hsmoves3gl.ts` 的 `hs3Post`：压暗时留色的高度写死成 175 人高，改成按单位贴图的高度，否则几丈高的魔躯只有脚下一截不被压暗；
  - `render.ts` 的 `fx3dFrame`：让 `near` 认夜无赦，提前编着色器，否则第一次放大招会卡；
  - `hsp2.ts` 的 `CINE_MOVES`：认他的大招；
  - `BossHUD`：读他的蓄力条。

## 三、分工与顺序

- 最多两个 Opus 子代理并行（以前定的规矩）。主线负责拆视频、看图把关、合并、测试、打包。
- **线一（画面）**：第 1 步贴图 → 第 2 步 `bossthings.ts` 与程序动画 → 第 5 步魂镰兵器。
- **线二（玩法）**：第 3 步首领本体与降临 → 第 4 步 22 招，分三批，每批交付一次。
  - 贴图没出来之前，先用占位剪影立板把招式逻辑和特效做通，贴图到了再换上。
- **每批交付后**：主线逐招截对照图（左边视频、右边游戏，同一时刻），看图，不过关就返工。
- **最后**：重打 Windows、安卓、源码三个包，更新交接文档。
