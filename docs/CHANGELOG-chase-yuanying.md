# 追杀修复 / 元婴加强（源码版）

## 1. 追杀系统：彻底修掉“追兵跟着玩家一起变慢”

### 根因

主追杀 `PursuitSys` 在近身 700 像素内会执行：

```
追击速度 = P.v - foeBase(e)
```

元婴同境追兵 `P.v` 约 1010，`foeBase(e)` 约 561–645。扣完只剩 365–449，而元婴后期玩家步行疾跑约 976、普通步行约 610。于是画面上追兵明明在御剑，实际却比玩家慢，永远咬不住。

活跃 NPC 的 `NpcWorld.huntSpeed()` 又是另一套速度公式，按玩家当前速度缩放，造成“玩家走得慢，追兵也慢”。

### 修复

- 新增 `src/world/chasespeed.ts`，作为两条追杀路径的唯一速度口径。
- 追兵遁速以**追兵自身境界**为保底，不再随玩家慢走而下降。
- 同境 / 高境追兵能咬住普通步行、疾跑与平飞；玩家催动遁光时，同境追兵会被拉开，高一大境仍能强追。
- 低境追兵不会被人为抬速去追高境玩家。
- `PursuitSys` 追杀头领的移动完全由追杀系统接管，`e.speed = 0`，不再和战斗 AI 双重移动，也不再扣 `foeBase`。
- 神识外 `coarse()` 的循迹也改用统一速度。
- 主追杀与活跃 NPC 追杀同时修复，避免只修一条路径。

## 2. 元婴人修加强

- 元婴（大境界 4）与化神人修的 NPC 获得专属“老怪底蕴”：气血、攻击、防御、护体灵光全面上调；小境界越高加成越高。
- 元婴追兵额外获得更高的气血 / 攻击 / 防御与更厚的护体灵光。
- 元婴 / 化神 NPC 装备保底：
  - 至少一面真正的护盾法器；
  - 至少一件鞋 / 飞行法器；
  - 至少一件护甲；
  - 至少三件可祭出的五阶古宝。
- 所有保底仍经过原有过滤：六阶、可升级、旧案归属、`BAN` 名单中的著名至宝绝不配给路人。云雷双翼、归墟鼎等仍然不会出现在随机 NPC 身上。

## 3. 法器使用 AI：不再“揣着法宝当摆设”

- 人修开场仍会优先祭出一件攻伐法器。
- 新增“法宝轮转”：结丹 / 元婴在战斗中每隔数息会再祭一件法器，优先换一件与上次不同的。
- 元婴法器冷却缩短，祭宝起手更快。
- `FoeAI.choose()` 对 `fq_*` 法器招式的偏好提高：炼气 1.3、结丹 1.5、元婴 1.9。
- 半血“法宝尽出”保留，并把所有剩余法器纳入轮转。
- 护盾类法宝不再是隐藏的减伤计时：祭出时会真正再凝一层可见护体灵光。

## 4. 验证结果

- `npx tsc --noEmit`：通过。
- `repro-pursuit-speed.ts`：
  - 元婴后期慢走：同境追兵快速咬住；
  - 元婴后期步行疾跑：同境追兵追上；
  - 元婴后期平飞不催遁光：同境追兵追上；
  - 玩家催动遁光：同境追兵无法保持追击，高一大境仍能强追。
- `repro-hunt-speed.ts`：活跃 NPC 追杀元婴后期玩家，约 1–2 秒追至 520 内并正常入战。
- `repro-artifact-use.ts`：
  - 元婴人修 60 秒内法器出手占比约 75%–85%；
  - 半血后每件法器都会用遍；
  - 随机元婴 / 化神 24 人配给检查：护盾、鞋 / 飞遁、护甲、至少三件古宝，全部通过。
