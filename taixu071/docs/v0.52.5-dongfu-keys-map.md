# v0.52.5 补丁说明 —— 洞府独立场景 · 黑屏修复 · 键位重排 · 地图找东西

基于 main 分支 v0.52.4（9c3cb50）。只改源码，`npm run build` 通过（tsc 零错误）。

## 一、进洞府黑屏（P0）

### 排查线索
旧版「进洞府」只是在大地图上原地弹一个对话框，主角 / 镜头纹丝不动。渲染器有一套「静止跳画」优化：
镜头、主角、敌人、粒子全都没变化时，连续 2 帧起整块跳过世界层绘制，GPU 沿用上一张纹理。
读档 / 回府符瞬移后的静止跳画和纹理状态残留是需要排查的一类风险；「在周围飞一会再回去」会打破静止判定。
此外，旧主循环的 `update / render` 没有异常兜底，一帧抛错可能导致 rAF 链中断，表现为黑屏或定格。
目前没有取得能稳定复现问题的玩家存档，尚不能确认这些是黑屏的唯一根因，需要实机验证。

### 修复
1. `render.ts` 新增 `resetStill()`：清掉静止跳画计数、`lastStillZ`、`stillCam`，并把 GL 的 `sceneUp` 置假强制下一帧完整重画重传。
   在 **读档、瞬移（teleport，含回府符）、出洞府、帧异常恢复** 四处调用。
2. `game.ts` 主循环 `update()` / `render()` 各自 try/catch：抛错时记录日志、显示提示、清淡出遮罩 / 顿帧 / 跳画状态，然后尝试继续下一帧；反复报错仍需要结合控制台排查。
3. 读档时额外清 `combat.fade`、`hitStop`、`slowT`、`inCave`——这些都会让画面发黑或定格。
4. **洞府改为独立场景**（见下），使用独立 2D 画布 + 贴图绘制，不复用 WebGL 世界层，以降低世界场景状态残留的影响。黑屏是否彻底修复仍需用问题存档实机验证。

## 二、洞府独立场景（新）
- 新文件 `src/ui/CaveScene.tsx` + `src/assets/cave/cave_interior.jpg`（AI 生成的石室长卷：灵泉瀑布、蒲团、丹炉、药园、石榻、洞门）。
- 按 T 走进洞府 → 淡入独立画面，像进一张小地图：WASD 走动（Shift / 开关疾行），走近物件按 T 互动，Esc 或「出洞府」离开，出来落在门口。
  - 洞门：出府　· 灵泉：泉边打坐（吃洞府灵气加成）　· 蒲团：打坐 / 闭关　· 丹炉：丹房 / 器炉　· 药园：打理药园　· 石榻：洞府事务（禁制 / 扩建 / 重炼古宝 / 灵宠……）
- **同行的红颜会在屋里踱步，走近按 I（或点她）交谈；随行灵宠趴在屋里，走近按 U（或点它）逗弄。**
- 场景里世界时间照常流转（打坐修炼有效），但主角禁制护身不吃战斗；界面类快捷键（地图 / 角色 / 储物袋 / 丹房 / 闭关 / 法术 / 红颜录……）照常可用。
- 手机：左下虚拟摇杆走动，点物件 / 人 / 宠直接互动，底部会浮出大按钮。

## 三、按键与操作（P0）
`src/core/keymap.ts`（键位表升级为 `fanren.keys.v2`，旧自定义键位作废一次）：
1. **鼠标左右键绑技能**：技能栏第 6 格 = 鼠标左键、第 7 格 = 鼠标右键。
   左键：神识内有敌人 / 已在战斗中 / 点到敌人 → 施放第 6 格（点到谁就锁谁）；没有敌人时仍是点地前往，手机不受影响。右键：直接施放第 7 格。
2. **技能键挪到左手**：默认 1–5 数字键 + 鼠标左右 + X + V，左手不离 WASD 能放完九格。九格全部可在设置里改键；技能栏角标与法术书提示随键位显示。
3. **走 / 跑切换键**：Shift 轻点 = 走 / 跑开关（御剑时 = 遁光加速开关），按住超过 0.35 秒视为临时疾行、松手即停，两种手感兼得。
   桌面右下新增「步 / 疾」指示按钮，手机原「疾行」按钮同步显示开关状态；`UIState` 新增 `run`。
4. **道侣 / 灵宠 / 事件分键**：T 只管奇遇、路人、机缘、城镇；**I = 与同行道侣交谈**，**U = 灵宠在旁则逗弄、否则打开名册**。
   `interact()` 里同行道侣不再参与 T 的最近目标竞争，灵宠候选移除。换装挪到 `,` 键。
   手机右侧栏在有道侣 / 灵宠时自动多出「侣」「宠」两个按钮。

## 四、找不到东西（P1）
1. **宗门任务目标**：猎杀 / 除魔任务，已探明区域里离你最近的目标怪在大地图与小地图上打醒目的金色「任」字（带圈），名字写「宗门任务：猎杀 xx（已 n/需 m）」。（`game.mapMarks()`）
2. **大地图放大后显示怪物名与境界**：缩放 >1.6 倍时，迷雾已解开区域内的怪物画成小点，任务目标金色带圈；>2.4 倍（任务目标任何倍率）显示「名字·境界」。（`Panels.tsx`）
3. **探过的地方不消失**：仙人洞府 / 遗骸 / 药王 / 兽巢等已探过的机缘改为灰色「✓」+「（已探）」留在地图上；灵脉、灵池等不消失的照旧。（`sites.marks()`）
4. **标记名字更早显示**：原先要放很大才出名字，现在 k>0.45 或缩放 >1.4 即显示；「任」「指」两类任何倍率都带名字。
