# 存档压缩（savezip）

从 v0.61 分支搬进 071 的一处小基建：`src/world/savezip.ts`。

## 为什么需要

localStorage 同源只有约 **5MB**，而「活世界」存档单份能长到 1MB 以上（四千名 NPC、迷雾、节点、宗门）。四个存档位 + 碑林很快顶满，玩家看到的是「本地存档失败」，而那个错误既没有解释、也救不回来。

JSON 里键名与 NPC 字段高度重复，压一遍能掉到 **1/4 左右**：实测 071 现在这份档明文 420KB，压完 105KB（25.1%）。

## 做法

- **纯同步**：`save()` / `load()` 都是同步接口，`CompressionStream` 那种异步的没法用；自己写一个 LZSS，无第三方依赖。
- **格式**：`'z1:' + 位流`。先 32 位原始字节数，再令牌流——`0` + 8 位字面量 / `1` + 16 位距离 + 8 位长度。
- **窗口与速度**：3 字节哈希表 + 链（匹配窗口 64KB、链深 32、单次最长 258），MB 级 JSON 也是毫秒级。
- **存储编码**：每个字节存成一个字符（码点 0–255）。localStorage 按字符计配额，1 字节 = 1 字符，所以压缩收益能 1:1 变成配额收益。

## 老档兼容

`unzipSave()` 对**没有 `z1:` 前缀的字符串原样返回**，所以：

- 升级前写下的明文档照常能读；
- 读到一次、下次自动存档写回时就换成压缩格式，不需要玩家做任何事；
- 存档码 / 万民卷宗里那份是**明文 JSON**（导出时先解压、导入时再压回去），因此换设备、跨版本都还能用。

## 接进哪些地方

| 位置 | 改动 |
|---|---|
| `game.save()` | `localStorage.setItem(key, zipSave(JSON.stringify(data)))` |
| `game.load()` | `JSON.parse(renameText(unzipSave(raw)))`——先解压，再做 v0.70 的人名 / 地名替换 |
| `Game.listSlots()` / `latestSlot()` | 同上，先 `unzipSave` 再解析元信息 |
| 存档码导出 / 导入（`CultPanels.tsx`） | 导出前 `unzipSave`（给明文），导入后 `zipSave` 再落盘 |
| 万民卷宗上传 / 取回（`CloudPanel.tsx`） | 上传前 `unzipSave`（卷宗里存明文，服务端自己 gzip），取回后 `zipSave` |
| `App.tsx` | `window.__unzipSave` 调试钩子：控制台里可以直接解一份压缩档来看 |

## 写不进存档时，话要说准

顺带补上了 `game.saveLastError` + `game.saveFailText()`（原先是 `catch { return false }`，面板只能笼统说「检查存储权限」）：

| 原因 | 判据 | 玩家看到的话 |
|---|---|---|
| `quota` | `QuotaExceededError` / `code 22` | 本地存储已满（约 5MB，四个存档位与碑林共用）——先导出存档码，再删掉用不着的存档位 |
| `denied` | `SecurityError` / `data_*` / `invalid_state` | 浏览器禁用了本站存储（无痕 / 隐私设置），请检查站点存储权限 |
| `serialize` | 其余异常 | 存档数据序列化出错（多半是模组塞进了不可序列化的东西） |

存档面板（导出 / 导入 / 手动存入某一格）、万民卷宗、自动存档都走这一份文案。**自动存档失败只提醒一次**（`saveWarned`），不会每二十秒弹一条；成功时 `saveLastError` 归零。

## 验证

- `npx tsx tools/test-savezip.ts`：9 项——8 组样本逐字往返、明文透传、空串、模拟 4000 NPC 的大档往返与压缩率（13.2%）、`z1:` 前缀、压缩后不含原文、200k 长串、多字节汉字。
- `npx tsx tools/test-sectpanel.tsx` 第九节：真存档写入后 `localStorage` 里是 `z1:` 串、解压回来 `hero/meta` 齐全、`listSlots()` 仍读得出「元婴初期 · 第 1 年」、`latestSlot()` 能挑出最近一份、`load()` 能直接读压缩档。
- 同文件第十节：把 `localStorage.setItem` 换成抛 `QuotaExceededError` / `SecurityError` / `TypeError`，分别得到 `quota` / `denied` / `serialize` 与对应的三句话；写成功时 `saveLastError` 归零。合计 **147 项全过**。
