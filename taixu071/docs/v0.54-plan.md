# v0.54 方案：社交（友）· 真秘境 · 活宗门 · 三方混战

负责人定下的方向：社交只做 **NPC**；按「混战 → 友 → 秘境 → 宗门与 NPC」的顺序做；秘境要「有真有假」。

## 一、三方混战（已完成，v0.54-1）

- 修士与妖兽分属两拨：`teamOf` 里没编派系的修士归 `@rogue`，妖兽鬼物归 `@wild`。
- 妖兽护领地：劫修、追兵、路人闯进它的察觉范围，它会扑上去；动了凶性的妖兽见人就咬。
- 追兵被妖兽咬住会先还手；劫修之间仍然一伙。
- 玩法上，你可以把追兵引进兽窝，坐收渔翁之利。

## 二、友（社交）

- **入口**：「缘 · 红颜」按钮改为「**友 · 友人**」，H 键打开友人录。红颜不删，成为友人录里的一页。
- **友人录分页**：同行 · 知交（好友以上、结拜、师徒）· 红颜 · 邀约。
- **同行**：最多 3 人（含红颜）。可下令跟随、原地等候、散去。
  - 邀人的方式：身边的友人当面邀；不在身边的好友（好感 ≥ 40）可**传音相邀**，按路程隔几日赶到，也可能有事推辞。
- **NPC 主动邀约**：好友不时传音给你。
  - 「同探秘境 / 古修洞府」：到约定地点会合，一起进去，宝物分账。
  - 「被围求援」：赶到时现场有一场混战，救下来好感大涨。
  - **有真有假**：心怀鬼胎的友人（人心篇的表里两张脸）约你去，可能是杀人夺宝的局：会合处有伏兵，或者开宝时翻脸。神识、阅历、读心可以看出破绽。
- 邀约在地图上标「约」，过期作废；爽约要掉好感。

## 三、真秘境（可以走进去的独立场景）

- **技术**：进秘境不刷新页面。世界暂停，换上秘境自己的地图（独立的碰撞、地面、墙、机关），出来时回到入口。
  - 战斗、法术、法宝、阵法、化形、元婴出窍照常可用，同行友人一起进去。
  - 秘境里不能存档；存档记的是入口位置。
- **三级**：

| 级 | 来源 | 规模 | 内容 |
|---|---|---|---|
| 小秘境 | 野外随机出现的前人洞府 / 古修遗府 / 地下石窟（替换现在只能点对话框的遗府） | 3~6 间石室 | 守护傀儡 / 残魂、一道禁制门（破禁之局）、宝箱、灵草 |
| 中秘境 | 八处险地（太岳山脉深处、北寒雪原、极西荒漠、草原深处、阴阳窟、大晋西漠、外海妖域、坠魔谷外围）+ 宗门禁地 | 两三片区域，十余间 | 妖兽群、首领、机关禁制、别家修士同在其中争宝 |
| 大秘境 | 原著名地：血色禁地、虚天殿、昆吾山、坠魔谷深处、古传送阵 | 多层 | 按原著年份定期开启、限境界；七派弟子 / 各路元婴同场争夺；首领与原著宝物 |

- **有真有假**：坊市、酒楼、友人口中的秘境消息有真有假。假的到了是空山，或者是劫修设的局、杀阵（与阵法禁制、骗局池打通）。
- **美术**：先用现有素材（地面材质、石柱、祭坛、灵晶、白骨、棺椁、火盆……）加代码绘制的水墨墙体先做出来。之后另写一份秘境美术需求（各主题的地面、墙、门、机关）交给生图 Agent。

## 四、活宗门 · 活 NPC

- 补原著宗门：乱星海星宫与各岛势力、大晋太一门 / 天魔宗 / 叶家等。散修比例调高。
- 把名册上的人「放到地图上」：
  - 宗门巡山弟子；
  - 坊市摆摊与交易；
  - 野外散修结伴猎妖；
  - 秘境开启时人群涌入；
  - NPC 当着你的面斗法、抢宝、求救。
- 注意性能：远处仍是粗略模拟，只把神识范围内的人做细。
