# v0.71 · 宗门面板（宗主大殿）

把散在一层又一层对话树里的宗主事务，收进一个正经的面板。入口三处：任务栏下的「开宗立派 / 本宗」牌子、自家山门里的「宗主大殿」、手机「≡ 菜单 → 宗门」。逻辑一行没搬走——面板调的都是 `world/mysect.ts`、`world/sectwar.ts` 的公开方法，对话树改调同一批方法，规则仍然只有一份。

### 收徒规矩（分段按钮，不再"点击切换"）

山门 **大开 / 紧闭**、门槛 **伪 / 四 / 三 / 双 / 天灵根**、收录 **执事自行收录 / 宗主亲自过目**，各是一排分段按钮，点哪档是哪档；底下一条速率提示：`按现在的名望与藏经阁，每月约来 2.2 人（一年约 26 人）· 门人 3/200 · 待见 0 人`。公式与 `mysect.month()` 里同一份（`recruitRate()`）。

### 宗门战事（据点 · 守御 · 调兵 · 宣战，一页办完）

- **三块牌子**：据点（上限随规模，月入灵石）/ 可调之兵（在外镇守几人）/ 本宗战事（几场、胜几负几）；下面是本宗据点的镇守人数条。
- **守御之策**：逐波增援 · 全宗回援 · 只凭镇守，三颗按钮 + 各自的说明。
- **进行中的战事**：标题、争哪处、第几阵、谁主攻、各自折损、停战原因；「调兵 / 看战报」打开 `sectwar.myWarNode()`——百人会战、破阵、亲征、求和、发落仍在那一棵对话里（那套流程太长，不抄第二遍）。
- **据点**（本图可镇守的城镇，本宗的排前面）：本宗据点可 **增派 5 / 撤回 5 / 弃守**；无主之地可 **进驻 6 / 12 / 20**；别派据点 **强占 = 宣战**（停战期与门人不足十二会被挡住，理由写在按钮旁）。
- **宣战**：按与本宗的紧张度排前五派，两下确认（第一次点亮「确定宣战」，第二次真的开打）→ 直接进战报。门人不足十二、停战期五年内、已在战中都会被拦下并写明理由。
- 「天下共讨」预警：已并道统一派时提示再灭一派会招来联手，两派则红条常驻。

## 二、两页签 · 天下宗门（宗门展示）

`本图 25 派` 的一览表，分两页：**名录 / 风声**。

- **名录**：筛选 **全部 / 大宗门 / 中宗门 / 小宗门 / 只看交战**，左名录右详情；已除名的宗门列在名录上方一行。

- 名录：道统色点 + 派名 +（本宗）+（⚔ 交战中）+ 规模 · 门人数 · 与我的**声望**。
- 详情：规模 / 道统 / 门人（含上限）· **两派之间**的紧张度条与关系词（满 100 开战）· **你与它门下的声望**（含敌视 / 围剿 / 长老出手三个阈值，和熟人脉录同一份数据）· 世仇缘由 · 同盟 · 据点（含镇守人数）· 宗法（阵名与攻守加成）· 秘传法术 · 恩怨（它最不对付的三家）· 若在战事中则附战报块。
- 动作：**在地图上指路**（跨图会说明在哪个地域）、**向它宣战**（两下确认）、交战中则「调兵 · 看战报」。
- **风声**（独立一页）：本图还没开战、却已绷到 55 以上的每一对，按紧张度从高到低排列。每对给出：两家之名、关系词与紧张度、道统、世仇缘由、是否正魔之争、双方门人数、紧张度条，以及「看甲 / 看乙」两颗按钮（点了跳回名录并选中该派）。原先只有玉符对话里才有这份情报。

## 二之二、三处宗门信息的重新分工（去重）

同一件事原来散在三个地方，各有一份不全的名单。现在按「谁的问题」切开：

| 入口 | 回答什么问题 | 有什么 | 不做什么 |
|---|---|---|---|
| **宗主大殿 · 天下宗门** | 「这一派是个什么样的势力」 | 规模 · 道统 · 门人上限 · 据点 · 宗法 · 秘传 · 恩怨 · 交战 · 与我的声望 · 指路 / 宣战 / 调兵 | 不列人名册 |
| **人脉录 · 宗门** | 「我和这一派结了什么账」 | 声望条与阈值（敌视 / 围剿 / 长老出手）· 名册（管理层、原著人物、空缺、已故）· 死于你手几人 | 不再重复规模/据点/宗法（要看就开宗主大殿） |
| **玉符 · 天下大势** | 「眼下有什么仗、我该投谁」 | 正在打的仗、看战报、以门人应召 / 以散修投效、赶赴前线 | 名录、风声（最紧的几对）、已除名的宗门都已挪进天下宗门页，对话里不再重复 |

`{ kind: 'sect' }` 模态支持 `tab`（落在本宗 / 天下宗门），玉符的名录入口用它直接打开天下宗门页。

## 五、顺手修掉的「点了半天才反应」

面板开着时世界是暂停的，但主循环照样每帧把整个世界观重画一遍（满屏二三十个路人就是十几毫秒，手机上成倍）——点击只能排在那一帧后面。现在：

- `game.halted` 之外的 `game.uiHold`（GameView 的 `panel / dock` 状态）与 `game.modal` 一起触发**停画**：打开先补两帧当背景，之后不再 `renderer.render`；关掉面板自动恢复。
- 传送到别的地图（`onTravel` 的 paused）**不**走停画，过场不卡。
- `renderer.resize()`、`resetStill()` 调 `game.requestFrame()`，改窗口尺寸 / 换图 / 出错恢复后一定重画一帧。
- 宗门面板不再自己每 600ms 重渲染一次（面板开着时数据只因自己的动作而变）。

实测（node）：面板一次渲染 概览 0.79ms / 名册 3.49ms（200 门人）/ 库房 0.50ms；单次动作全部 <0.5ms；`update` 在面板打开时 0.007ms/帧。即逻辑不是瓶颈，瓶颈是那帧渲染。
