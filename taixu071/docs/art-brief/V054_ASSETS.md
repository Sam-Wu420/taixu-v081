## 2. 画风与参考图（`ref_v054/`）

**水墨淡彩**（与游戏现有的山水、建筑、妖兽一致）。线有粗细、有飞白，颜色像在宣纸上晕开。低饱和，暗部用淡墨表现。

**禁止：** 照片写实、3D 渲染塑料感、西式地牢游戏风（哥特拱门、火把铁环、骷髅王座）、赛博霓虹、卡通 Q 版。

## 3. A · 地面无缝砖（9 张）

- **视角**：正上方垂直俯视，没有透视、没有地平线，不能有任何「立起来」的东西。
- **尺寸**：1024 × 1024 px，**上下左右四边无缝**。
  - 自检：把同一张拼成 3×3，看不出接缝、看不出重复的「图案中心」。
- **比例**：一张砖在游戏里约等于 4 个人身高见方。石板一块约 0.6~1 个人宽，不要画成马赛克小砖。
- **明度**：地面要比摆件、人物低半档，饱和度低一档，是衬底，不要抢戏。
- **不要文字**：金线、刻纹只能是几何纹、云雷纹。
- **文件名**：`floor/floor_<主题id>.png`，例如 `floor/floor_tomb.png`。
- **另附**：每张一张 3×3 平铺自检图 `floor/floor_<id>_tile3x3.jpg`。

## 4. B · 墙的立面条（9 张）

游戏会把它**横向一段段平铺**，画在石室北边缘（参考图里那条深色带）。

- **视角**：正面平视的一段墙面，像站在石室里看向北墙。
- **尺寸**：1024 × 384 px（宽 : 高 ≈ 8 : 3）。**左右两边必须无缝**（横向拼两张看不出接缝），上下不用无缝。
- **构图**：
  - 最上沿是一道粗一点的墨线（墙顶与岩体的交界）。
  - 中间是墙面本体。
  - 最下沿约 8% 是墙脚的暗部和少许碎石、苔痕。
- **透明底**（PNG 32 位，见第 7 节「透」），整面都不透明即可。
- **文件名**：`wall/wall_<主题id>.png`；另附横向拼接自检图 `wall/wall_<id>_tile2x.jpg`。

## 5. C · 岩体顶面（9 张）

石室与甬道以外的部分，是从上往下看到的**山腹岩体顶面**：一大片暗色，不能抢戏，但要有质感。

- **视角**：正上方俯视。尺寸 512 × 512 px，四边无缝。
- **明度很低**（整体亮度约为地面的 40%），用淡墨的皴法和点苔表现岩石肌理。
  - 森林主题是盘结的树根与泥土，冰窟是厚冰层，海宫是珊瑚礁岩，沙城是夯土与沙。
- **文件名**：`rock/rock_<主题id>.png`。

- **程序会**：轻微流动、波光闪烁，并在池岸画描边。你只画液面本身，**不要画池岸**。

`manifest.json` 每张一条：

```json
{ "file": "prop/prop_tomb_coffin.png", "id": "prop_tomb_coffin", "bg": "alpha", "size": [520, 300], "person_px": 215, "anchor": [262, 290] }
{ "file": "floor/floor_tomb.png", "id": "floor_tomb", "bg": "opaque", "size": [1024, 1024], "seamless": "xy" }
{ "file": "wall/wall_tomb.png", "id": "wall_tomb", "bg": "alpha", "size": [1024, 384], "seamless": "x" }
{ "file": "item/gate_exit.png", "id": "gate_exit", "bg": "black", "size": [1024, 1024] }
```

| 字段 | 含义 |
|---|---|
| `bg` | `opaque` 不透明 · `alpha` 透明底 · `black` 黑底发光图 |
| `seamless` | `xy` 四边无缝 · `x` 仅左右无缝 |
| `anchor` | 落地点的**像素坐标**（不要写 0~1 的比例） |
| `person_px` | 图中一个成年人有多高（像素） |

## 13. 交付前自检（请用脚本逐张实测，写进 NOTES.md）

- [ ] **尺寸**：每张与本文规格一致。
- [ ] **无缝**：
  - 地面、岩体、液面：3×3 平铺看不出接缝，四边像素逐行比对差值接近 0；
  - 墙：左右边缘逐行比对差值接近 0。
- [ ] **透明底**：四角 64×64 区域内**没有任何**不透明像素（防棋盘格）；最外 2 px 的 alpha < 8；在深浅两种底上无白边。
- [ ] **黑底**：四角亮度为 0，主体没有被画布边缘切断。
- [ ] **文字**：全部图里没有任何文字、乱码字、像字的符号（几何纹、云雷纹可以）。
- [ ] **主题**：九种主题一眼能分出来；同一主题的地面、墙、岩体、摆件放在一起协调。
- [ ] **一致**：文件名、目录、manifest 与本文一致；NOTES.md 写的每个数字都与实际文件一致。
