# v0.62 · 灭宗大战（护宗大阵 · 百人会战 · 宗主不是奶妈）

针对「当宗主像当奶妈」「宗门战场面太小、没有护宗大阵、不能灭宗」的反馈，只改宗门两个模块：`src/world/mysect.ts`、`src/world/sectwar.ts`（另加一条兵力条 `src/ui/SectBattleHUD.tsx`）。旧存档直接可用（新字段自动补上）。

**一、宗主不是奶妈（mysect.ts）**
- **人人都有进项**：打理产业拿全额，守山三成、修炼两成、历练一成；各境界进项上调（`INCOME`），越忠心越肯出力。默认配置下宗门自给自足，不必宗主倒贴
- **宗主抽成可调**（10%–50%，默认三成）：门人进项、历练所得、据点 / 分舵进项、战利品都按抽成径入宗主供奉；抽到五成门人渐生怨言
- **拨下去的灵石不会一月见底**：冲关丹药钱大降（筑基 800 · 结丹 8000 · 结婴 60000），败一次下回成算添几分；每月冲关花销不超过库房盈余（保底线之上）的 5%（可调 2% / 5% / 10% / 25% / 不限），先尽着身份高、灵根好的；可设保底线、冲关资格；库房里能看到累计冲关次数、成功次数与花销
- **拨款 / 支取**：一千 / 一万 / 十万 / 百万 / 一半 / 全部
- **回报**：宗门气运（门人修行反哺宗主修为，大殿里汲取）· 破境谢师礼（筑基 300 · 结丹 4000 · 元婴 40000）· 丹房每月有机会献丹 · **亲卫随行**（点 4 / 6 / 8 名门人在野外跟着你打，战死是真的死）
- **护宗大阵**：阵力上限 400 / 1200 / 3500 / 9000 / 24000（随等级），灵石充能（2 灵石一点，可自动充能）；三种阵型——金光镇岳（守）· 诛邪万剑（杀）· 迷天幻雾（困）

**二、灭宗大战（sectwar.ts）**
- **百人会战**：一次遣 30 / 50 / 80 / 120 人乃至全部可调之兵，守方照着来敌人数迎战；别派出兵也从「一成四、上限五十」改为「三成、二十到一百二十」
- **实战**：出兵时可选「宗主亲征」——御剑直抵前线立时开打；同屏敌二十、我十六，后备打完一批补一批，没上场的在两翼按战力互有折损；屏幕上方有兵力条；敌军折损过七成半即溃
- **倾巢而出 = 灭宗大战**：一方倾巢，另一方也只能尽出（全宗一个不留，连掌门太上）。野战得胜则对方据点尽失、兵临山门；败则攻守易势
- **护宗大阵**：打到山门须先破阵——宗主亲自轰击（不折人）/ 遣弟子强攻（每次折一批）/ 亲征破阵（杀尽守阵弟子一战可破）。别派攻你山门同理，连冲五次不破自会退兵
- **发落**：山门告破或对方乞和之后由你决定——**灭其道统**（除名、搜刮库藏与秘卷、山门改分舵）· **收编残部**（残部半数来投）· **纳为附庸**（月供径入宗主供奉、出兵助阵）· **赔款罢兵**
- 自家山门被破：宗主尚在道统不绝，但阵基降一级、门人星散三成半、据点尽失
