## 一、三界总体定位与防膨胀设计原则

### 1.1 为什么灵界/仙界不能做成“人界换皮”

人界（`human`：南荒 / 沧溟海 / 中州）的核心心流是**“凡尘苟道 → 宗门求存 → 结丹结婴 → 触摸化神天花板”**。如果灵界与仙界只是把怪物血量乘 100、把下品灵石改名成“超级灵石”、然后继续打野怪挖草药，玩家在化神期之后会迅速产生疲劳。

因此，三界在**核心焦虑、突破方式、战争定位、经济体系**上必须完成四重结构性跃迁：

| 维度 | 人界（小千世界，已实装） | 灵界（中千世界） | 仙界（大千世界） |
|---|---|---|---|
| **境界跨度** | `0..5`：凡人 → 化神初期 | `5..8`：化神中期 → 大乘后期 | `9..12`：真仙 → 大罗巅峰 |
| **主要生存焦虑** | **寿元大限**（70 → 2000 年）与仇家追杀 | **周期性天劫**（三九/六九/九九）+ **异族叩关** | **天人五衰（衰劫）** + **仙宫《斩仙榜》通缉** + 灰界蚀道 |
| **破境核心机制** | 攒修为 + 丹药 + 少数瓶颈物品 | **法则初悟 + 灵躯/法相重塑 + 抗过天劫** | **大道实证（法则晶丝）+ 斩三尸 + 五气朝元** |
| **战争阶级地位** | 炼气战兵 → 筑基阵眼 → 结丹统帅 → 元婴/化神老祖 | **结丹/元婴成炮灰** · 化神作阵眼 · 炼虚/合体统帅 · 大乘老祖 | **大乘成炮灰** · 真仙/玄仙阵眼 · 金仙/太乙统帅 · 大罗老祖 |
| **问道残卷定位** | 滴露催熟灵草 + 观招偷学法术 | 孕育**玄天之宝**的核心催化器 | 觉醒为**时间法则载体**（百倍洞天 / 时光回溯 / 终局钥匙） |
| **流通货币** | 下品灵石 | **灵晶**（中/上品灵石本位） | **仙元石**（极品仙晶本位） |

### 1.2 数值防崩溃设计：面板收敛 + 位阶法则压制

人界从凡人（`HP 60, ATK 6`）到化神初期（`HP 42000, ATK 3200`），每大境界约膨胀 `4–5 倍`。若灵界与仙界继续按 `×4.5` 指数暴涨，到 `大罗(12)` 血量将超过 `10^10`，既不美观也易产生浮点精度与 UI 溢出。

**解决方案：采用「温和平滑基础面板 + 界域位阶绝对压制」双轨制：**
1. **平滑基础成长**：自 `化神中期(5.1)` 起，每大境界基础气血/攻击倍率收束至 **`1.8x – 2.2x`**（大罗巅峰基础气血约 `220万`–`350万` 区间，清晰可读）。
2. **高阶对低阶的「位阶压制」公式（战斗结算层）**：
   - 设攻击方真实 `realm = R_a`，受击方 `realm = R_d`，当 `R_a > R_d` 且跨界或跨大境时：
   - **灵压真伤增幅**：每高 1 个大境界，造成伤害额外 `× (1 + 0.35 * ΔR)`（跨越界域门槛如 仙界→灵界 / 灵界→人界 时，触发**界域法则碾压**，额外附加忽视护盾的“法则震荡伤害”）。
   - **护体法则减伤**：高界受低界攻击时，受击伤害乘以 `max(0.05, 0.58 ^ ΔR)`；同界同阶依然保留精彩走位博弈，跨大境/跨界则完美还原《凡人》式的不可逾越鸿沟。

### 1.3 三界经济硬隔离（防止高界资源倒灌）

依托 `src/data/worldHierarchy.ts` 的 `PlaneTag = 'mortal' | 'spirit' | 'immortal'`：
- **人界坊市**：仅收**下品灵石**（`mat_lingshi`）。高界玩家回人界时，极品灵晶/仙元石无法在普通店铺直接消费（店小二不识或找不开），仅可在少数高阶拍卖行按每日限额换取人界杂物。
- **灵界坊市**：以**灵晶**（`mat_lingjing`）结算。人界带上去的百万下品灵石，在灵界天渊钱庄仅能按 **`1000 : 1`** 极低汇率且受周期限额兑换，彻底杜绝“在人界刷灵石买空灵界”。
- **仙界坊市**：以**仙元石**（`mat_xianyuan`）结算。灵界灵晶需在金源仙域换汇或靠仙脉开采、仙宫悬赏、斩仙战利品获取。

## 二、飞升通道与跨界逆返闭环

### 2.1 人界 → 灵界：双路线飞升设计

当玩家在人界满足 `hero.realm === 5 && hero.stage === 0`（化神初期）且修为圆满，开启「飞升传闻」线索链，提供**两条风格截然不同的飞升路线**：

#### 路线 A：上古空间节点偷渡（自由散修 / 冒险线）
1. **线索触发**：中州极北雪岭（或沧溟外海深渊、南荒陨魔山腹）每隔数十年出现一次**空间节点潮汐**。玩家须先集齐至少两项偷渡筹备：
   - **空间信标**：`破界符` / `定空珠` / `空间法宝`（需于人界大事件、名地遗府或宗门秘库获得）；
   - **护躯秘宝**：足够支撑空间罡风撕扯的护体灵盾（`Lingdun` 满阶）或防风披风/玄霜冰焰等护身灵火。
2. **偷渡玩法关卡（`mijing` 特殊生存战）**：
   - 进入节点后，触发一段 **45 秒「空间乱流突围战」**：镜头周围出现不断向中心挤压的紫色空间裂隙（持续真伤区域）与游荡的空间风刃、虚空魔影。
   - 玩家须一边控制走位、施展遁光（`Shift`）与护盾抵御罡风，一边击碎沿途 3 处「界壁灵锁」，在法力耗尽前冲入出口光柱。
3. **落点与开局**：随机坠落在**灵界蛮荒古境或无尽雷海边缘**（非安全区！可能直接遭遇三阶/四阶荒兽或巡逻异族），需要靠自己杀出重围、寻得人族聚落，自由无拘束。

#### 路线 B：古飞升台正统接引（宗门 / 名望线）
1. **前置条件**：
   - 在人界正/魔声望绝对值达标（`|ws.rep| >= 60`）或拥有**人界自建宗门（`mySect` 规模达中/大宗）**；
   - 修复中州/星罗殿古「飞升台」：消耗大量人界顶级材料（天地元气晶×5、空间灵石、阵法宗师修为），触发一次全人界可见的「接引天柱」奇观（宗门门人送别剧情）。
2. **落点与代价**：
   - 稳定传至**天渊圣域 · 天渊城接引殿**，直接获得人族户籍与基础洗灵池名额，避开荒野落单暴毙风险；
   - **代价**：按照灵界圣城规矩，凡经正统飞升台入界者，须签下**「千年守渊兵役契」**（每隔一段时间须响应天渊防线征召，不可无限拒战逃役，否则被天渊执法队除名通缉）。

### 2.2 初入灵界开篇闭环：『界域灵压』与『化灵池洗礼』

刚刚飞升至灵界时，人界积累的灵力偏于驳杂，立即挂上永久阶段减益直至完成洗礼：
- **`【界域灵压】`**：法力自动恢复 `-60%`、人界法器威能发挥 `65%`、神识探测半径暂时折半。
- **开篇任务链（3 步）**：
  1. **辨识新界**：打听灵界常识（结丹元婴皆战兵、化神才起步、灵晶货币），获取第一枚灵界身份玉牌；
  2. **化灵洗髓**：积攒灵晶或用人界带来的罕见灵药抵押，进入天渊城/圣地**「化灵池」**浸泡七日（期间触发一次小规模「灵压洗髓小天劫」）；
  3. **重炼本命物**：在灵界炼器坊将人界随身带来的核心法宝（如碧竹飞云剑、云雷双翼、两极磁光等）以灵界灵材**重炼升阶为「灵界灵宝」**，正式解除 `界域灵压` 并解封 `化神中期/后期` 修炼上限。

### 2.3 灵界 → 仙界：九重仙劫与真仙飞升

当玩家修至 **`大乘后期`（`realm = 8, stage = 2`）** 圆满，满足飞升条件：
1. **自行选址筹备**：大地图上择一灵脉充沛的险峻山峰或海岛，预先布设**护山/避雷大阵**（`ZhenfaSys`），并可邀请灵界好友（`FriendsSys`）或自家宗门炼虚/合体长老前来护法。
2. **四波九重仙劫（`Tianxiang` + `Combat` 联动）**：
   - **第一至三重（阴风煞雷劫）**：大范围毒风、天火流星与追踪落雷；阵眼承受一部分雷威。
   - **第四至六重（紫霄太清雷）**：高爆发单体/区域神雷，考验玩家身法、护盾与替劫木偶/符箓切换。
   - **第七至八重（因果心魔幻劫）**：`Xinmo` 系统唤出主角在人界与灵界最难忘的宿敌/执念幻象围攻。
   - **第九重（飞升仙光洗礼）**：顶过最后一击后，天空裂开金色仙门，飞升之光灌注全身，化去全部凡俗气息，成就**「伪仙躯 → 真仙初期」**，传送至仙界「北寒仙域」飞升台。

### 2.4 高成本逆返下界（对接 `worldHierarchy.ts`）

严格遵循 `src/data/worldHierarchy.ts` 中已预留的数值接口：

| 参数 | 灵界 → 人界（`spirit.returnCost`） | 仙界 → 灵界（`immortal.returnCost`） |
|---|---|---|
| **寿元损耗** | `0`（不损寿元） | `0`（不损寿元） |
| **法力/仙元消耗** | 当前法力的 **`80%`** | 当前仙元的 **`90%`** |
| **跨界冷却** | **`3600` 日**（10 年，记入 `ws.worlds[world].returnCooldownUntil`） | **`18000` 日**（50 年） |
| **下界压制公式** | `worldLawSuppression(realm, 'human') = max(0.15, 0.55^(realm - 5))` | `worldLawSuppression(realm, 'spirit') = max(0.15, 0.55^(realm - 8))` |

**逆返期间特殊规则（玩法闭环）：**
1. **核心目的**：
   - **回人界**：① 拯救处于灭宗边缘的人界自建宗门（`mySect`）；② 将人界达到`化神初期`的亲传弟子/道侣**接引飞升**至灵界；③ 补齐人界未尽的碑林传承、名胜探索或遗留掉落实物。
   - **回灵界**：① 为灵界宗门震慑异族大乘；② 采集唯有灵界特定绝地才有的玄天灵根幼苗；③ 护送灵界故人渡飞升仙劫。
2. **天道排斥值（防滥用护栏）**：
   - 在下界期间，每次动用高界神通或跨阶击杀下界修士都会快速累加 **`排斥值`（0–100%）**。
   - `排斥值 >= 70%` 时天空提前凝结灭世黑云（`Tianxiang` 警告）；达到 `100%` 时**空间排斥强制触发，瞬间被界壁弹回上界**并重置双倍冷却。

## 三、灵界（中千世界）详细玩法设计

### 3.1 世界地理与灵界大地图（`lingjie`，`2400 × 1600` 原生大域）

灵界直接构建为一张超大型原生大地图 `lingjie`（`2400 × 1600` 宏观单位 × `WORLD_SCALE=300`），三大区域间隔千里（东境 `天渊圣域`、西境 `蛮荒古境` 隔千里魔渊荒原、北境 `无尽雷海与广寒碎域` 隔广阔北海与雷暴海域），既可御遁光跨山海横渡，也可经域内三座大型传送阵瞬息直达：

#### 1. 东境 · 天渊圣域（人族/妖族联合主疆域，`ling_tianyuan` 坊市区）
- **视觉地貌**：青翠灵山、悬浮小灵岛、纵横交错的巨型灵脉金线与城墙防线（`天渊城` 占据中部要冲，东侧为人族十大圣宗与百城联盟，西侧城墙之外便是暗褐色的 `魔渊前沿战壕`）。
- **主要城池与圣地**：
  - **天渊圣城**：灵界人妖两族最高议会所在，内设「天渊战功殿」「天元拍卖行」「化灵洗髓池」「飞升接引殿」。
  - **核心圣宗（供拜入或结盟）**：`太初圣宫`（正道剑/阵）、`妖皇殿`（万妖联盟）、`青冥鬼宗`（灵界鬼道大宗）、`雷音古刹`（佛门苦修）、`天工灵阁`（傀儡/战舟/玄天仿制品）。
- **核心玩法**：日常接取战线指令、参与拍卖与炼器重铸、处理人界下宗传讯。

#### 2. 西境 · 蛮荒古境（百族腹地与凶兽禁区，`ling_manhuang` 坊市区）
- **视觉地貌**：暗红与深紫相间的远古巨林、血沼、百丈巨兽白骨山脊（着色器增强古林阴翳与红雾氛围）。
- **异族势力分布**：
  - **角蚩族**（善使战兽与血脉图腾，极强肉身战阵）；
  - **夜影族**（隐匿暗杀、空间潜行，最容易在神识外围突袭玩家）；
  - **灵木族**（掌控巨树生机与毒瘴，出产顶级万年灵药与养魂神木）；
  - **海王族**（沿南部毒海盘踞）。
- **核心玩法**：深入异族腹地猎杀采集顶级素材、潜入敌后破坏跨界传送阵、探索太古真灵遗府。人族在蛮荒古境无安全区保护，易触发高烈度追杀。

#### 3. 北境 · 无尽雷海与广寒碎域（法则极地，`ling_leihai` 坊市区）
- **视觉地貌**：北部为碎裂漂浮于虚空深渊之上的万里寒冰大陆（**广寒碎域**）；南部为永不停歇落雷的紫黑色狂暴海域（**无尽雷海**）。
- **核心玩法**：
  - **雷海淬体**：在雷暴眼区域持续承受天雷洗礼，以肉身与神雷法宝吸收**伏魔金雷本源**；
  - **广寒冰狱秘境**：定期开启的冰封古境，产出太阴寒水、冰魄法则石、以及突破合体期的关键主材；
  - **真灵洗礼池**：寻找龙凤/鲲鹏真灵残血，为玩家或灵宠激发真灵血脉天赋（直接赋予额外变身形态或主动神通）。

### 3.3 灵界四大核心玩法详设

#### 核心玩法 1：定期天劫生存体系（打破无限闭关）

灵界修士逆天而行，自突破至**炼虚期**起，角色状态中维护 **`nextTribulationDay`（下一次大/小天劫日）**，默认间隔 **300 年（108,000 游戏日）**；但频繁吞服霸道丹药、大肆杀戮累积因果、或强行催动玄天之宝会**缩短倒计时**。

1. **天劫周期与预警阶段**：
   - **提前 10 年**：主角神识隐隐不安，HUD 日期旁出现淡淡雷纹提示（可提前筹备防具/寻址/购买替劫傀儡）；
   - **提前 1 年**：头顶天象逐渐泛起铅灰劫气，不可再进行跨图长途大闭关；
   - **临劫日**：若玩家正在城池内，天渊圣城护城禁制会强制将渡劫者“请出城外荒野”，避免牵连城池。
2. **三九 / 六九 / 九九重劫实战流程**：
   - 玩家可在倒计时最后几日主动选择一处灵脉或布下`聚灵防雷阵`（阵法等级越高，帮主角分摊 `15%–45%` 天雷伤害）。
   - 战斗开启后，天空出现全屏乌云压顶与闪电链预警圈：
     - **炼虚期（三九小天劫）**：3 轮共 27 道落雷，夹杂阴风侵蚀；
     - **合体期（六九重劫）**：6 轮天雷 + 心魔幻相入场干扰；
     - **大乘期（九九灭世劫）**：9 轮复合劫（紫霄神雷 + 混沌天火 + 本命心魔）。
   - **替劫保命与邪道引劫**：
     - 携带`替劫木偶`、`引雷针`或`九幽辟邪丹`可在濒死雷击瞬间触发免死一次；
     - **引劫祸水东引**：若玩家故意飞到某敌对大宗山门或强敌领地旁引动天劫，天道气息会同时将周围高阶敌修锁定为“协防扰劫者”，天雷无差别轰击双方（高风险高收益奇策！）。
3. **渡劫收益**：每次成功渡过定期天劫，神魂与肉身受劫雷淬炼，**法则亲和永久 `+8%`、寿元略增、法力纯度提升**，彻底摆脱“天劫只是惩罚”的枯燥感。

#### 核心玩法 2：天渊百族战线与战功军衔（`v0.73` 兵阶落地）

直接接入 `src/data/worldHierarchy.ts` 中预设的 `WAR_BANDS.spirit` 兵阶与 `src/world/sectwar.ts` 战阵框架：

1. **战阶权限与代入感**：
   - 玩家以`化神期`刚入灵界时，在天渊军团里只是一名**「阵眼队正」**，率领由 **60–100 名结丹/元婴战兵** 组成的百人战阵抵挡异族前沿锋矢阵。
   - 晋升`炼虚/合体`后，解锁**「战区统帅」**权限：可在军阵调度界面（复用 `SectBattleHUD`）同时指派多支元婴/化神战阵协同推进、呼叫天渊灵舟炮火齐射、建立前沿大型灵脉大营。
   - 晋升`大乘`后，成为**「镇族圣祖」**，出征时携带圣域气运光环，敌方元婴/结丹散兵靠近即溃散。
2. **四类高回报战线任务**：
   - **拔除斥候营（巡猎）**：潜入魔渊荒原击杀夜影族潜行阵眼，截获异族兵力布防图；
   - **灵晶车队护送（后勤）**：保护大型押运灵舟从天渊城穿越埋伏区抵达前沿大营（复用 `v0.73` 实时截击车队逻辑）；
   - **摧毁跨界传送祭坛（攻坚）**：限破禁盘+战阵掩护强拆敌方召唤援军的虚空祭坛；
   - **天渊百日兽潮防卫战（大型周期事件）**：每隔数十年爆发一次全线总攻，玩家需在多条防线间驰援救火，斩获敌方统帅首级按贡献分润战功与顶级战利品。
3. **军衔与战功殿专属兑换**：
   - 从「甲士 → 校尉 → 统领 → 镇渊使 → 人族供奉」，逐级解锁灵界极品功法、法则感悟秘境门票、`玄天残片`线索与`化灵池`免费使用权。

#### 核心玩法 3：炼虚「灵域（Domain）」与「灵域角力」

进入**炼虚期**，玩家解锁主动战斗核心机制——**【展开灵域】**：
1. **灵域凝聚**：在角色修炼面板，根据主修心法与参悟的主属性法则，凝炼出专属灵域形态：
   - **剑意凌霄域**（剑/金系）：域内己方飞剑攻速 `+35%`，敌方每移动 100px 自动承受一次剑气斩击；
   - **金雷炼狱域**（雷/风系）：持续降下追踪金雷，克制鬼魔、破盾速率翻倍；
   - **玄霜冻土域**（冰/水系）：域内敌方与弹道速度降低 `40%`，累积“冰封”层数后碎冰爆发；
   - **万灵枯荣域**（木/土/毒系）：持续吸取敌方生机反哺自身与战阵护盾，同时叠加剧毒；
   - **虚空颠倒域**（空间/时间系，罕见）：域内敌人闪烁/瞬移技能失效，敌方弹道轨迹概率发生折射偏转。
2. **「灵域角力（Domain Clash）」机制**：
   - 当主角与同为炼虚以上 Boss 同时展开灵域时，屏幕上呈现**双色渐变水墨领域交锋线**！
   - 双方按 **`(法则深度 × 神识强度) + 持续输出占比`** 动态拉锯交锋线位置：占优一方逐步吞噬对方领域；若完全碾压压碎对方灵域，敌方将陷入 `3 秒` 法则反噬眩晕并被剥除护盾！

#### 核心玩法 4：玄天之宝孕育与全界异象争夺

灵界最高战力象征「玄天之宝」（如**玄天斩灵剑、浑天玄鼎、阴阳乾坤图**）不直接掉落成品，而是围绕玩家随身的**问道残卷**设计长线大事件：
1. **第一阶段 · 寻胚**：在蛮荒禁地、百族拍卖或大乘遗府取得「玄天混沌残胚」；
2. **第二阶段 · 洞天聚灵孕育（百年长线）**：
   - 须在灵界夺取一处**上品灵脉洞天**，将残胚埋入灵眼；
   - 玩家可用每日累积的**问道残卷「墨露」**持续浇灌加速，亦可通过战斗斩杀高阶异族/魔修吸收精血煞气注入胚体（对应不同属性的玄天异宝）；
3. **第三阶段 · 异象降世与万族截杀**：
   - 当孕育度达到 `90%` 与 `100%` 成器瞬间，灵界天穹必现**「玄天异象」**（万里之内紫气东来或剑啸震天，全界传闻曝光坐标）；
   - 周边数个异族部族与隐世大乘老祖会立刻动身赶来**抢宝灭口**！玩家须依托洞天护山大阵+盟友助拳+战阵迎敌，守住最后三日方能彻底炼化认主。
   - **威能**：每件玄天之宝自带**一条改写战斗规则的灭世级主动法则技**（例如一剑斩断对方技能冷却与持续护盾、暂时封锁敌方灵域），但每次催动都会巨额消耗法力并略微引动下次天劫提前。

### 4.3 仙界四大核心玩法详设

#### 核心玩法 1：仙界大道法则树与「斩三尸」实战试炼

1. **六大至尊/主流大道树（`LawProgress`）**：
   - 玩家在仙界可主修 1 门**至尊法则**（`时间` / `空间` / `轮回`）或**常规大道**（`剑道` / `雷霆` / `五行`），辅修至多 2 门。
   - **提升途径**：绝不能靠挂机打坐上涨！必须通过**探索法则遗迹、抢夺仙脉结晶、观摩大罗斗法（问道残卷观招进阶版）、或击败斩仙榜强敌**获取「法则晶丝」。
   - **法则实战效果**：
     - `时间法则`：缩短全技能冷却、延迟自身负面/衰劫发作、解锁**时光回溯**；
     - `空间法则`：超远距无前摇瞬移、攻击无视普通距离与弹幕拦截、空间禁锢锁死逃敌；
     - `轮回法则`：击杀敌人抽取精魂化作替死/助战仙傀，高额复活容错；
     - `剑/雷/五行`：极致伤害穿透、无视常规防御与多段破阵连携。
2. **「斩三尸」专属 Boss 战（金仙晋阶必经）**：
   - 当试图破境金仙初期 / 中期 / 太乙圆满时，触发三次独立的心魔幻境对决：
     - **斩善尸（慈悲与羁绊之幻）**：敌人镜像复制主角防御与治疗/护盾流派，夹杂人界/灵界故人幻影劝阻；
     - **斩恶尸（杀戮与贪嗔之幻）**：镜像复制主角最高爆发功法与杀伐法宝，攻击欲望拉满、步步紧逼；
     - **斩执念尸（道心之问）**：根据玩家存档中的 `DaoxinSys`（天骄/凡人/天道）与江湖信义 `cred` 动态生成终极宿敌形态。
   - **核心奖励**：每成功斩落一尸，该化身便化为可消耗仙元召唤的**「三尸分身」**，在大型战役中助战（继承本体 60%–85% 招式，真正实现“一气化三清”式的巅峰斗法）。

#### 核心玩法 2：天人五衰（衰劫）与甲子大闭关

仙界不再因为“岁数到了寿元耗尽”而憋屈死亡，取而代之的是动态生存危机——**【天人五衰】**：
1. **五衰触发与症状表**：随着修为推进（玄仙起），每经历约 `500–2000` 年（或大闭关数个甲子），体内积累的“大道反噬”会依次引爆五衰之一：
   - **一衰·仙元滞涩**：施法法力消耗 `+50%`，自然回复冻结；
   - **二衰·仙躯朽坏**：最大气血上限暂时被锁减 `25%`，受击更易重伤；
   - **三衰·神识蒙尘**：神识外圈急剧收缩，无法锁定隐匿或远距敌人；
   - **四衰·宝光晦暗**：法宝/仙器威能衰减 `30%`；
   - **五衰·因果反扑**：每隔数日主动吸引附近敌意仙修或《斩仙榜》猎手寻踪而来。
2. **化衰 / 镇衰玩法闭环**：
   - 收集稀有仙药炼制**「定仙镇衰丹」**暂缓发作；
   - 占领高纯度**仙脉灵眼**布设聚仙大阵，以纯净仙灵气冲刷衰气；
   - 深入**灰界渊墟**猎杀异化仙兽提取「混沌净源」，以战养道、彻底渡过本次衰劫并使道果更加圆融（每次安然渡过五衰，全属性基础永久 `+5%`）。
3. **甲子大闭关系统**：在 `SecludePanel` 增加「仙界纪元闭关（10 年 / 60 年 / 300 年）」，闭关期间每十年滚动一次世界事件日志；一旦**衰劫将至、仙脉遭袭、或仙宫执法队破门而入**，立刻自动中断出关（复用现有 `seclude` 中断弹窗机制）。

#### 核心玩法 3：仙宫秩序、《斩仙榜》与仙域版图战

1. **大千战争编制（对接 `WAR_BANDS.immortal`）**：
   - **大乘期**飞升者与仙宗杂役充当百人仙阵的炮灰战兵；
   - **真仙 / 玄仙**出任阵眼队长，维系大型仙阵护盾；
   - **金仙 / 太乙**担任战区统帅，率领多支仙兵军团攻打敌对仙宫或中型仙脉；
   - **大罗老祖**一念降临战区，展开百里级大罗法则场，扭转整片战线胜负。
2. **仙宫律令与《斩仙榜》追缉系统**：
   - 玉皇仙宫在金源/北寒仙域维持“表面秩序”：当街屠城、劫掠仙宫灵矿船队、或在城池内强施空间/灰界禁术，会累计 **`仙宫恶名`**。
   - 恶名达标后登上**《斩仙榜》**（分铜榜、银榜、金榜、赤血必杀榜）：

#### 核心玩法 4：「问道残卷」终极揭秘与时间法则玩法

从人界青玄门起步、一直伴随主角观招偷学与滴露催熟的**「问道残卷」**，在仙界终于揭开最终面纱：
1. **残卷苏醒（主线转折）**：当主角第一次在仙界触及**时间法则**或踏入**岁月荒境**时，残卷自动共鸣显形，揭示其真正来历——乃是昔日执掌时间大道的无上存在留下的**「太初岁月天书」残页**（人界墨露实为稀释千万倍的时间本源之液）。
2. **三大逆天实用能力**：
   - **百倍岁月洞天**：消耗仙元凝聚高阶「岁月金露」，可在洞天内开辟时间加速药园，现场催熟十万年/百万年仙草，让神通丹药与仙宠培养速度产生质变；
   - **时光回溯（战斗/渡劫终极底牌）**：主动触发（冷却长，耗费残卷蓄能），将主角自身坐标、气血、仙元、护盾与部分技能冷却**回溯至 4 秒前状态**——用于硬吃大罗必杀技或强渡致命五衰绝境；
   - **跨界观招·演道**：即便身在金源仙域，也能在残卷内重演过去遇到过的所有强者招式（含人界、灵界、仙界宿敌），推演融合出属于自己的**自创仙阶神通（`myArts` 终极版）**。
3. **七页原章收集与双结局设计**：
   - 分散在**北寒极渊、金源秘库、灰界岁月荒境、斩仙榜魁首、以及太古仙宫遗址**共七页残卷原章。
   - 集齐七页并登临**大罗巅峰**后，面对残卷原主的时空遗局与仙界天道大劫，玩家可选择：
     - **结局 A · 超脱问道（完结里程碑）**：合七页为一卷，以时间法则斩断仙界因果羁绊，破界步入鸿蒙之外（记录进游戏最高荣誉殿堂并生成全生平史诗传记）；
     - **结局 B · 重塑三界（自由沙盒延续）**：炼化天书掌管三界时间节点，保留全部修为继续在仙界、灵界、人界自由纵横，大幅降低跨界逆返冷却、助推下界宗门成为三界第一道统。

### 6.2 性能与存档安全红线（基于人界后期压测教训）

1. **跨界切片封存（严防卡顿与 5MB `localStorage` 溢出）**：
   - 玩家飞升至灵界后，人界的 `sites`（常达 `3000–5500` 条）与 `npcs`（`1200–2000` 名）**禁止继续常驻实时循环与全量渲染图集**。

2. **缓存防抖动**：灵界/仙界同样沿用 `sites.ts` 的大上限平滑淘汰与 `markRecs` 增量缓存，严禁在循环内触发整表 `clear()`。
3. **数值与掉落安全**：灵界/仙界所有新奖励入口继续强制走「固定 `LootPlan` + 原子入袋 + `savedDrops` 按 `ACTIVE_WORLD + ACTIVE_MAP` 隔离保护」，秘境、渡劫替劫、玄天孕育中途读档不丢物品。
