### 1.2 现存主要问题（经代码只读排查确认）
1. **战阵脆如纸、伤害联动失衡**：
   - `applyFormationDamage` 无护盾与减伤上限，高阶（元婴/化神）可一招清光，同阶亦无拉锯相持；
   - `src/world/combat.ts:2052` 非 AOE 弹道仅在 `pr.life < dt * 2.5`（约前 0.04 秒）才判打阵，飞到敌阵早已失效；`chain` / `dash` / 部分 `heroacts` / `huaxing` 未接打阵，而 `field` 每 0.5 秒全额跳伤过猛。
2. **「假对等」与敌阵缺席**：
   - `src/world/war.ts`（朔漠之战、星罗殿逆星之战）仍为 6v5 散兵波次，完全未接入 `WarFormation`；
   - `src/world/sectwar.ts` 中 `maybeAttachFormation` 硬卡 `e.realm === 2 && avail >= 12` 且核心混洗优先占满 `FIELD_F = 5`，导致 `hold` 或核心先占满后敌方不出战阵，且敌阵初始刷在 `640–920px` 屏外。
3. **《凡人》风战损失控、越打宗门越空**：
   - `sectwar.ts:392` `casualties` 核心层只有存活或 `this.kill` 永久除名，普通 `clash` 直死率过高；
   - `sectwar.ts:911–930` `wings()` 每 `1.8s` 永久杀伤双方后备 `4%` 筑基（`this.kill`）与 `4.5%` 外门，一场仗打满 1 分钟后台可耗空 70%–80% 班底；
   - `roster.ts:535` 筑基每年仅补空缺 `4%`，补员远追不上死亡速率。
4. **界域兵阶与中小宗门分级偏差**：
   - `src/world/roster.ts` 大量偏小宗门仍标 `top = 4`（元婴遍地），且 `sectwar.ts` 多处硬编码 `e.realm === 2` 充当阵眼，尚未随界域（人界 / 灵界 / 仙界）动态抬升兵阶。
5. **战争后勤、地图行军与制式服装缺失**：
   - 缺少战前丹药/灵石筹备、伤兵依托大营/丹药康复的机制；
   - 开战后营帐瞬间凭空出现，大地图与野外看不到山门集结、行军纵队、押运车队与逐步筑营；
   - 宗门弟子仍走 `randomLook()` 随机挑款，仅覆盖 `L.robe` 颜色，缺乏统一门派服制；战阵士兵仅 1 套图集 5 帧且步态高度同步。
6. **UI 入口重叠严重**：
   - 右侧主界面入口（`src/ui/GameView.tsx`）达 17–19 项，人物（`友人录 H` / `人脉录 N` / `道侣`）、宗门与战事（`人脉录·江湖门派` / `宗主大殿·天下宗门` / `传音玉符·天下大势`）、传闻（`大事记 J` / `人脉录·天下事`）多处重复。

## 第二部分：已确认的核心重构设定

### 2.1 护盾耐久化战阵与伤害机制重构
1. **护阵灵盾（`shield` / `shieldMax`）**：
   - 战阵本质是「阵法护体」：护盾未破时，**绝不直接死兵**，呈现同阶拉锯相持；
   - **缓回护盾**：阵内炼气/低阶弟子持续吐纳维系阵纹，提供低速回盾（受门派丹药补给与阵眼灵力影响），同阶散攻无法磨穿则形成持久战；
   - **破盾窗口（`brokenT`）**：护盾被击碎后进入数秒破阵虚弱窗口，此时敌方攻击可直接造成阵内伤兵/死兵与阵眼震荡；窗口结束后残留兵力重聚微弱灵盾；
   - **高数境碾压**：跨两个大境界以上的大神通，伤害溢出护盾上限后**一击碎盾并直接震溃/秒杀整座战阵**（忠实原著高阶碾压，同阶决不秒杀）。
2. **全链路命中与招式对齐**：
   - 修复 `combat.ts` 直射/穿透弹道全程飞行判阵（同发弹道对同一战阵设 `hitFormations: Set<number>` 与短冷却防多段重复结算）；
   - 补全 `chain` / `dash` / `heroacts` / `huaxing` / `field`（按阵法面积比例与跳频折减）与敌我双方战阵对射的平衡。

### 2.2 忠实于真实弟子数据池出战（取消假对等）
- **严禁凭空造兵或强行镜像凑对等战阵**：双方能派多少支战阵、每支战阵多少人、阵眼是筑基还是结丹，**100% 源自双方真实 `roster` / `mySect` 可用存活池**（并扣除驻守据点与重伤休养人数）；
- 大宗压境可连续出动多支百人精锐大阵；连战消耗过甚或小宗门兵力枯竭时，只能出动残阵或十数名散兵游勇；
- 修复 `sectwar.ts` 优先让携带真实外门兵源的阵眼领队先行入场，并将接敌刷怪距离拉入同屏交锋范围（`~380–560px`）。

### 2.3 《凡人》风三段式战损核算
废除现行 `wings()` 每 `1.8s` 永久杀伤后台 4%–4.5% 与常规战高比例直接 `kill` 的机制，改为**「亡 / 重伤回营休养 / 溃散退回」三段账**：
1. **常规境界战 / 阵线拉锯战**：
   - 大头为**溃散退回（~35%–50%）**与**重伤休养（~35%–45%）**，**真死率严格控制（~10%–20%）**；
   - 筑基阵眼击溃优先触发「重创遁走 / 昏迷抬回大营」（进入 15–45 天休养状态），极少直接陨落；结丹 / 元婴在非绝境下**极难真死**（重创遁走保命）。
2. **绝境 / 灭宗决战**：
   - 仅当**山门护宗大阵被破、后路被断、被大营合围或魔道血祭围杀**时，真死比例大幅抬升至 **45%–70%**，出现真实高层陨落与道统震荡。
3. **后备两翼消耗调优**：
   - `wings()` 周期由 `1.8s` 拉长至 `10–15s`，且不再直接永久删 `Unit` 与外门，主要转为「重伤退回大营休养」与「前线士气消耗」。

### 2.4 高境界惜命、三界同构兵阶与中小宗门分级
1. **三界战力阶层严格映射（`worldWarTier(worldId, realm)`）**：
   - **人界（`human`）**：炼气 1–5 杂役（后勤） · 炼气 6–13 战兵 · 筑基阵眼 · 结丹统帅/大营主将 · 元婴/化神太上（非灭宗不出）；
   - **灵界（`spirit`）**：凡人至筑基全为杂役（**灵界筑基老老实实做杂役，不进战阵当炮灰**） · 结丹/元婴战兵 · 化神阵眼 · 炼虚/合体统帅 · 大乘老祖；
   - **仙界（`immortal`）**：凡人至**大乘皆为仙宗杂役与炮灰战兵** · 真仙/玄仙阵眼 · 金仙/太乙统帅 · 大罗道祖。
2. **中小宗门分级修正**：
   - 修正 `src/world/roster.ts` 的 `RAW_SECTS` `top` 值（剔除泛滥的元婴 `top = 4`），小宗门（如清微门、断刀坞、天枢堡、重岳剑门、清音门等）以**结丹掌门封顶**甚至仅筑基代理；
   - 无元婴老祖的中小宗门外交偏向**依附大宗、抱团联保、纳贡求存**；战斗与调度逻辑必须兼容无老祖、缺结丹、甚至无百人外门的宗门。

### 2.5 战争后勤与战前筹备（丹药 · 灵石 · 阵材）
1. **宗门战备物资库（玩家自建宗门 & NPC 宗门统一结构）**：
   - **疗伤/回气丹药储备**（主控前线伤兵康复与战阵休整速度）；
   - **军费灵石储备**（维持前线大营护阵运转、战阵充能与赏格）；
   - **符箓/阵材储备**（提升破除护宗大阵与前线固守效率）。
2. **丹房 & 药园日常囤积**：
   - `mysect.ts` 丹房新增「战备炼丹」产线，结合弟子采集/产业灵草稳定入库；
   - 玩家亦可用储物袋多余丹药/灵草/灵石向本宗或参战阵营换取宗门贡献/战功。
3. **战前备战期（15–30 天）**：
   - 正常宣战后不直接瞬战，先进入筹备动员期，调拨丹药军费、点齐各峰出征队伍；界面清晰展示双方「军需充足度」。
4. **后勤决定伤兵回流**：
   - 大营疗伤丹药充足时，重伤弟子 **7–15 天** 治好重返阵线；一旦丹药断供（打光或粮道被截），伤员积压无法出阵，有效兵力快速枯竭。

### 2.6 大一统阵线战争、地图实景行军与边界大营
将 `sectwar.ts`（宗门争锋 / 正魔大战）与 `war.ts`（朔漠之战 / 星罗殿逆星之战）统一为同一套**「阵营（Side）— 阵线（Frontline）— 营寨（Camp）— 行军（March）」**引擎：
1. **单宗与多宗联军同构**：
   - 阵营可由单宗门构成，也可由多派联军（南荒正道联盟 vs 魔门六宗、朔漠法士 vs 南荒联军、星罗殿 vs 叛星盟）按各参战宗门真实名册/战备按比例出兵，并支持局部正魔战事升级为**全盟总动员**。
2. **地图可见的「集结 → 出征 → 筑营」三步演进**：
   - **山门集结（3–7 天）**：宗门山门广场实际出现列队弟子、帅旗与军需箱笼；大地图宗门旁亮起集结旗标；
   - **出征行军与押运**：生成地图移动实体（`MarchEntity`），大地图实时可见行军纵队与运丹车队沿地形向边界移动；**玩家在野外赶路遇到时，实景地面可见行军队列/车队，可直接半路突袭截杀或护送同行**；
   - **抵达边界逐步筑营（1–3 天）**：从先遣帅旗哨栅逐步搭成含**中军帅帐、各宗分营营帐群、伤兵药帐、临时护营小阵**的前线大营；旧 `war.ts` 的领军令、邀道友、战功兑换直接落进真实帅帐场景。
3. **连片地盘与边界战事循环**：
   - **邻接扩张**：正常只夺取贴近山门或己方已有据点的相邻节点；仅「高阶奇袭/海岛飞地/宗门密道/同盟分封」4 类特殊飞地例外，且伴随高驻军与低补给代价；
   - **战时动态事件**：护送/截断后方运丹补给线、敌后拔点袭扰、阵前斗将、久战竭泽后的停战议和。

### 2.7 战阵多样化、无阵松散阵型与《全战》级士兵表现 + 门派制式服制
1. **战阵类型与无阵退化**：
   - 在现有 `square / crane / circle / arrow` 基础上扩展战术分工（如前排护阵/剑修压阵、后排法术齐射）；
   - 当无合适阵眼或可用战兵不足成阵阈值时，自动以**松散阵型（Skirmish）**散开游斗，不再硬拉死板矩形。
2. **零性能损耗的《全战》士兵鲜活感与战损/溃退表现**：
   - **同宗 4–6 套差异化预烘外观**：保留同一宗门制式服制，在身高、体格、发冠/发饰微调上各异，杜绝复制人；
   - **扩充帧库（14–16 帧/套）+ 独立相位与微步频**：包含呼吸戒备 `idle`、6 帧 `walk`、错峰抬手施法波 `cast`、受击微仰 `hit` 与**倒地横尸帧 `dead`（躺地残留 6–10 秒后缓缓淡出刷掉，不再凭空蒸发）**；配合站位轻微随机扰动（±4~7px）、固定环形尸体槽位（防性能拖慢）与局部受击缺口补位，全部仍走 `drawImage` / WebGL 批量提交，维持高帧率；
   - **修仙者定向撤退（杜绝原地乱跑）**：战阵溃散后，活着的败兵不再无头苍蝇般向四周地上乱窜，而是**统一朝向己方大营 / 后方山门方向退却**——炼气战兵催动轻身御风符离地低空掠行（或成股退避），筑基/结丹统领架起本命剑光/各系遁光升空破空遁走，飞出视野后消散归营。
3. **宗门制式服制体系（`SECT_UNIFORM`）**：
   - 废除名册弟子 `randomLook()` 随机挑版型做法，按宗门固定**领型、袖型、下裳、外罩、纹样、主副配色**：
     - 同一宗门外门（素简劲装/基础道袍）、内门/筑基（加半臂/护腕/金银镶边）、长老/掌门（广袖/披风/披帛礼服）层级分明；
     - **原著特写具名角色**保留专属定妆（如红绡红衣等）；
     - **自建宗门可定制制式**：宗主开宗时可从衣橱款式库选定本宗道袍版型与配色，门人统一着装出征。
4. **宗门大殿/城镇背景 NPC 视觉分级简绘与动作降频（同样条件下比主角简略，兼顾观感与帧率）**：
   - **根因诊断**（核实 `src/world/npc.ts`、`src/world/alive.ts`、`src/gfx/charAtlas.ts`、`src/gfx/character.ts`）：
     1. 宗门山门一次激活多达 34 个同屏 NPC，`pickAlive()` 给大多数门人分配 `sword / spar / chop / stretch` 等短周期循环动作（每 `0.7–1.2s` 切换 `cast ↔ idle`）；
     2. `npc.ts:1347` 的 `eligible` 条件写死了 `!(a.life && a.wait > 0)` 与 `!a.bubble`，**只要 NPC 在做日常动作或冒气泡，就全部绕过 `charFrames` 与 WebGL 批处理，被迫每帧跑全量实时骨骼矢量 `drawCharacter` + 弹簧/发丝物理 `st.update(dt)`**；
     3. `character.ts:590` 原本预留了 `opts.detail` 降档参数，但**全项目没有任何调用方传入 `detail`**，导致路人哪怕在近景也和主角一样逐指画 5 根手指、渐变衣褶、发丝高光与物理飘带；且每人随机 `randomLook` 打爆了 `768` 格 LRU 缓存。
   - **两层治理方案（视觉简略 + 缓存合批 + 动作节流）**：
     - **同样条件下「普通 NPC 比主角简略」的视觉分级**：
       - **主角 + 特殊 NPC**（`canon` 原著具名、`bond` 道侣/师徒/结义、`focus` 交互焦点、`duel` 单挑对象）：保持 `detail = 1` **全量精细绘制**（五指 3D 骨架 IK、布料/发丝物理摆动、工笔渐变明暗、衣褶/发丝高光、腰佩流苏/镶边纹样/五官神韵）；
       - **普通宗门弟子 / 路人**（同样缩放、同屏状态下）：自动传入 `detail >= 2.5` 并新增**「简略工笔档」**——**保留**清晰身形剪影、宗门制式服色、发冠、基本眉眼与站走坐施法姿态，观感统一不违和；**省去**五指逐节骨架与手部 IK（改简练袖口/手势块面）、省去多层线性渐变明暗（改爽利二阶平涂）、省去衣褶/靴缝/腰带高光/头饰细纹/发丝高光/睫毛耳饰等细笔，并关闭飘带/发丝物理模拟；
     - **普通 NPC 彻底走「分区块双层预烘图集」（身体共用 + 头面独立）**：
       - **身体/服饰图集（Body Atlas）**：键值为 `(uniformKey, buildBucket, dir16, poseFrame)`（不含头面，并附带颈部锚点 `(hx, hy)` 与前后层序）；因为宗门弟子大多穿制式服饰，**同宗 30–100 名弟子直接共享同一套身体动画帧**，从根本上消灭衣服按人头重复烘焙的问题；
       - **头面/五官图集（Head Atlas）**：键值为 `(headKey, dir16)`（含男女老少五官、胡须、发型发冠，左右对称视角可镜像复用至 9 个小图块），**完全不随站/走/打坐/施法动作重复烘焙**；每位 NPC 保留自己鲜明独特的长相特征，组合时只需「身体帧 + 颈锚点叠加头面帧」2 次极速图集提交；
       - **外出行走/散修差异化兼容**：穿杂色衣袍的散修仍沿用少量共享衣版模板 + 独立头面图集，确保任何场景彻底消灭 768 格 LRU 抖动与每帧现烘卡顿；

## 第三部分：闭环审视——哪里还没有形成闭环？

逐条核对玩法、数值、时间流、玩家角色与技术实现后，目前仍有 **8 处关键断点尚未形成闭环**，必须在动工前补齐设计：

### 闭环缺口 1：NPC 宗门没有「对应后勤账本」（单边消耗不闭环）
- **现状断点**：`mysect.ts` 里玩家宗门有 `stones`、药园/产业和丹房，但 **NPC 宗门在 `roster.ts` / `sectwar.ts` 里目前没有库房灵石、没有丹药储备、也没有据点税收产出**。如果只要求玩家囤丹药、走补给线，而 NPC 无限免费发兵免费回血，玩家去截敌军运丹车队就只是一次性脚本事件，无法真正拖垮强敌。
- **补全方案**：为每个在世宗门建立轻量后勤账本 `{ stones, pills, materials, dailyHerbIncome }`（按宗门规模与所占药园/城镇据点数闭式日产）。如此一来，「截断敌方补给线 → 敌营丹药库存清零 → 敌方重伤员无法回流、战阵护盾回得极慢 → 强宗也会被拖垮停战」才真正形成可推演、可感知的战略闭环。

### 闭环缺口 2：玩家「非宗主时期（三界各阶通用）」的阵线参与与「眼下机缘」任务断点
- **现状断点**：现有规划大量聚焦「元婴建宗后当宗主调度全局」，但玩家流程前 80% 是**散修**或**宗门普通弟子**（不仅限人界的炼气/筑基/结丹，**灵界与仙界对应阶层亦然**）。如果非宗主进战场还只是单打独斗，且统帅部军令无法在日常指引里追踪，就很难融入阵线体验。
- **补全方案**：按 `worldWarTier(worldId, realm)` 全界域拉通四阶身份闭环，并将前线军令直通**「眼下机缘」**：
  1. **底层炮灰战兵阶**（人界炼气 / 灵界结丹元婴 / 仙界大乘）：山门点兵集结时，编入中层统领的战阵内随军行军、享护阵灵盾庇护、在阵中点杀敌锋/护送丹药；
  2. **中层阵眼队长阶**（人界筑基 / 灵界化神 / 仙界真仙玄仙）：可在前线帅帐领将印，**亲自统率 1 支由本宗战兵池拨出的 50–100 人战阵**（自选方/圆/鹤翼/锋矢阵型），领押运或奇袭军令；
  3. **高层统帅阶**（人界结丹 / 灵界炼虚合体 / 仙界金仙太乙）：可任偏师统帅或前线大营主事，调动同盟友军战阵协同推进、主持阵前斗将与局部议和；
  4. **散修雇佣兵**：不入宗门也能在交锋大营接「护送运丹队 / 敌后劫粮 / 斩将夺旗」高额悬赏换战功与灵石；
  5. **统帅部任务接入「眼下机缘」（`game.chances()`）**：凡在前线帅帐接取或由统帅部强制下发的军令（护送运丹、敌后截粮、拔点奇袭、阵前破阵），全部实时写入**「眼下机缘」**与大地图指路，写明目标方位、距离与剩余时限，形成「领命 → 机缘追踪 → 地图指路 → 执行 → 回营领功」完整闭环。

### 闭环缺口 3：统一「4 分钟 = 1 游戏日」后的节奏重校与闭关/快进断点
- **现状断点**：统一 `1 游戏日 = 240 秒` 后，若仅靠平时野外走动，1 小时才过 15 天——原本按几年算的开局太平期、大战触发周期、甚至几天的行军/筑营都会显得过长；而若直接快进闭关，现行 `seclude()` 既不联动推进全服行军与宗门账本，也不会在宗门告急/大战召集时弹窗询问玩家是否出关。
- **补全方案**：
  - 将行军（`2–6 天`）、筑营（`1–2 天`）、原地打坐（`2 秒 = 1 天` 配合防频闪柔和光影）及各大系统触发周期按新时间轴重新标定，闭关界面增设短周期快捷档与自定义天数输入，并在山门/大营提供「**随军开拔**」快捷跳日；
  - 将 `seclude()` 升级为**可中断步进闭关**：同步闭式推进全服行军/营寨/宗门，遇到重要军情、宗门危机、好友求救或原著大事时立即弹窗询问「**破关而出 / 继续苦修**」；
  - 闭关/打坐以外的行军坐标采用 `pos(day)` 连续插值，保证大地图与野外遭遇战在任何流速下都严丝合缝。

### 闭环缺口 4：战利品归属、真实 NPC 战功自我成长与「孤立飞地」惩罚
- **现状断点**：
  1. 联军打下据点或野外缴获物资后，个人与宗门的分配边界不清；且参战真实 NPC 拿了战功如果不能自己兑换丹药/功法去修炼，就只是玩家的背景板，无法形成「大战磨砺出一批真仙/结丹」的活世界生态；
  2. 4 类特殊飞地与「断补给线」虽然提出，但孤立飞地**与己方主地盘之间彻底不连通时**的具体规则尚未闭环。
- **补全方案**：
  - **战利品归宗门 + 个人战功自成长双线分离**：
    - 攻克据点与战利品物资（灵石、丹药、材料）**全部归参战宗门库房/战备库**（多宗联军按邻接优先 + 参战权重分配据点归属；单派撤军只收走其专属营帐与兵池，只要主力未散大营仍存）；
    - 参战的**真实 NPC（含实名弟子、筑基/结丹统领）根据个人斩敌与战功账本，战时/战后自动在大营军需处兑换修为丹药、疗伤丹与法器功法**，切实加速自身修炼与破境成算；
  - 明确**「飞地孤岛状态（Isolated）」**：凡与本宗山门/连片据点无陆/海路连通的飞地，维护费 `×2`、无法自动接收大营重伤康复补兵，若周边敌对且断补给超过 30 天则士气归零触发守军溃散或被围剿殆尽。

### 闭环缺口 5：大世界碰撞遭遇 ↔ 战线状态回写与跨图休眠断点
- **现状断点**：玩家如果在野外直接截击了敌方行军纵队或运丹车队，或者打一半撤退脱离，必须和地图实体、大营库房账本双向同步——不能「野外打赢了劫了丹药，大地图那支队伍还在继续往前走」或「打到一半跑了，战阵死伤和破盾却没入账」；同时，玩家在天南时，乱星海和太晋也在推进，不能在后台实例化大量 3D/2D 渲染对象。
- **补全方案**：
  - 明确**「当前图实时具象 + 异图纯数据推演」**规则：仅 `ACTIVE_MAP` 的近距行军队/大营生成可交互 `Enemy`/`Npc`/`Building` 实体，异图仅更新坐标与库存；
  - 野外遭遇战胜利/撤退立即回写对应 `MarchEntity` 的兵力、携带丹药灵石与位置进度（劫毁车队后玩家实得部分战利品，其余毁于战火，敌方大营不再收到该批补给）。

### 闭环缺口 6：取消「斩首阵眼秒炸阵」、战阵演出的攻防边界与图集显存控制
- **现状断点**：
  1. **旧版「斩首阵眼」破坏大战演出**：现行 `tickFormation` 一旦阵眼 `leader` 死亡便整座战阵瞬间清零溃散，导致无论玩家还是 AI 只要一上来集火斩首阵眼，大战演出几秒就草草收场；且战阵士兵死亡直接减数消失、缺少倒地留尸的惨烈演出；
  2. **多变体 + 多帧图集内存风险**：若 40+ 宗门全数预烘 `6 变体 × 16 帧`，离屏 Canvas 会突破百兆，低配设备容易卡顿或崩溃。
- **补全方案**：
  - **暂不做「斩首阵眼秒炸阵」，回归正面破阵演出**：
    - 取消「阵眼一死全阵瞬间蒸发」逻辑；即使阵眼统领重伤退场，战阵仍依托护阵灵盾与副手/余部继续维持阵脚（仅小幅降速与降低齐射频率），必须先**正面轰碎护阵灵盾**、持续削减战阵有效兵力或跨两境神通一击碎盾溢伤，才会真正击溃整座战阵；
    - 补齐战阵士兵**阵亡倒地横尸动画**（环形定长尸体池，每具倒地停留 `6–10s` 后淡出回收），避免瞬间消失的出戏感；
  - 离屏变体图集实行 **LRU 缓存上限（如最多常驻 8 个活跃参战宗门 × 4 变体 × 16 帧）**，按需烘焙与淘汰，确保内存可控在 ~20–30MB 以内。

### 闭环缺口 7：三界统一门槛与既有「原著特写外观 / 玩家衣橱」兼容
- **现状断点**：
  1. 目前 `sectwar.ts`（如第 844 行 `if (e.realm !== 2) return`）、`war.ts`、`roster.ts` 仍有不少直接拿固定数字 `2 / 3 / 4` 判断阵眼和长老的代码，一旦进入灵界/仙界或遇到无元婴小宗门就会失效；
  2. `npc.ts` 里大量原著人物（如红绡穿红衣、玄煞等）已有专属 `robe` 与人设，不能在统一宗门服制时把原著特色人物刷成千篇一律的小兵制服。
- **补全方案**：
  - 统一抽离 `worldWarTier(worldId, realm)` 替代所有分散境界魔数；
  - 确立服制优先级：`玩家衣橱 / 原著特写定妆` > `宗门高阶礼服（带宗门主色与徽记纹样）` > `宗门制式内/外门法衣（SECT_UNIFORM）`；同时允许玩家在加入宗门时自动获得一套该宗制式法袍进衣橱。

### 闭环缺口 8：战后「休养生息与止戈防死循环」+ 老存档兼容迁移
- **现状断点**：
  1. 目前两派打停战后，若只设 5 年互不侵犯，但未设计**重伤兵源保护与周边趁火打劫抑制**，刚停战残血的小宗门下一刻立刻会被邻近第三家满血宗门直接宣战灭门；
  2. 老存档没有 `warSupply`（战备丹药/军费）、`MarchEntity`、`SECT_UNIFORM` 字段与统一战区状态，直接升级会缺字段报错或“零丹药开战瞬间崩溃”。
- **补全方案**：
  - 战后（非灭宗）触发「**战后整编期**」：大营有序撤回，未死伤兵加速归队，且刚签停战或元气大伤但已纳贡求存的宗门获得一定外交保护/同盟庇护权重；
  - 编写幂等 `migrateWarState(ws)`：把老存档里尚在进行中的 `war.ts`（`mulan` / `xing`）与 `sectwar.ts`（`wars` / `mySect`）平滑转为统一战区，并按宗门规模自动预置初始战备丹药与灵石，确保无缝读档继续游玩。

### 闭环缺口 9：打坐高速流转惊醒、叛宗/自立清理、炼丹批量化与因果人物豁免
- **现状断点**：
  1. **打坐 `2 秒 = 1 天` 在野外的安全闭环**：打坐期间天数高速推进，野外敌袭/仇家追杀/护宗大阵告急随时可能触发；现行只在被击中后才调用 `g.stand()`，很容易在入定时挨第一下重击；
  2. **叛宗 / 转投 / 自立门户后的军令悬空**：若玩家身为某派弟子接了统帅部军令写入「眼下机缘」，随后退宗、叛宗或自立 `mysect`，旧军令与旧营归属若不及时清理会成死任务；
  3. **手点炼丹跟不上军需规模**：`src/data/recipes.ts` 炼一炉疗伤丹需 2 天仅出 2 颗，若无批量炼丹与药草直接捐献宗门丹房代炼，玩家手头攒丹极累；
  4. **重要因果人物（红颜 / 道侣 / 师徒 / 结义 / 剧情线 NPC）误杀**：若 `wings()` 或野战随机把玩家正在攻略/交互的关键 NPC 抹死，剧情线直接断死。
- **补全方案**：
  - **打坐惊醒机制**：野外被敌方进入警戒锁定、追兵现身或本宗/所在阵营发来紧急战报时，自动 `g.stand()` 退出打坐并弹提示（而非等挨打后才起身）；
  - **退宗/自立清理**：退出或切换所属宗门时，自动结算或注销原宗门名下的前线军令与营地身份；
  - **批量炼丹 + 捐草代炼**：丹炉支持批量开炉（`×1 / ×5 / ×10`），同时允许在山门/帅帐直接捐献金心草、黄精、赤灵芝等灵草由宗门丹房直接折算入战备丹药库；
  - **因果人物保护**：凡有 `canon` / `beauty` / `bond` / 活跃剧情线关联的 NPC 在常规阵线战中只触发「重伤遁走休养」，绝不后台随机阵亡；仅灭宗破门且玩家在场时才进入真实存亡抉择。
