# 坑：常见错误、症状与解法

每条格式：**症状** → 原因 → 怎么办。大多数坑 `tools/mod-try.ts` 都能抓到，写完先跑它。

---

## 一、加载阶段

### 1. 模组面板显示「没能加载：物品 id「xxx」须以「mymod_」开头」
**原因**：内容 id 没带前缀，或用了大写、连字符。
**怎么办**：所有法术、物品、敌人的 id 都写成 `模组id_名字`，只用 `[a-z0-9_]`。

### 2. 「模组 id 只能用小写字母和数字」
**原因**：`manifest.id` 里有 `-`、`_` 或大写，或者长度不在 3–24。
**怎么办**：本游戏的模组 id **没有分隔符**，如 `qingming`、`leiyin2`。（通用平台「合众」允许 `-`，本游戏不允许，别混。）

### 3. 「入口文件没有默认导出 setup(api) 函数」
**原因**：写成了 `export function setup`、`module.exports = …`，或忘了 `default`。
**怎么办**：`export default function setup(api) { … }`。

### 4. 「法术「xxx」缺少字段 evo」之类
**原因**：漏了必填字段。法术最容易漏 `evo`（必须是三条字符串）、`color`、`range`。
**怎么办**：照 content.md 的必填表补齐。`power: 0` 的辅助法术也要写 `range: 0`。

### 5. 「法术 xxx 已存在」
**原因**：
- 两个模组用了同一个 id（前缀能避免这种情况）；
- 同一个模组里重复注册；
- 手动注册了卷轴 `scroll_art_xxx`（系统已经自动生成了）。

**怎么办**：去掉重复的。卷轴不要手动注册。

### 6. 「缺少依赖模组」
**原因**：`deps` 里的模组没装，或没启用。
**怎么办**：在模组介绍里写清楚依赖什么，让玩家一起装。能不依赖就不依赖。

### 7. setup 里调了 `g.xxx`，报 `g is not defined`
**原因**：setup 运行时还没有游戏，`g` 只在事件回调里有。
**怎么办**：开局要做的事放进 `api.on('start', (g) => …)`。

### 8. 在 `api.on('start')` 里注册内容，读档后物品变「?」
**原因**：内容必须在建世界、读档**之前**注册。`start` 已经太晚了：读档时这些 id 还不存在，而且每次 start 都会重复注册，触发「已存在」错误。
**怎么办**：`api.content.*` 一律写在 setup 顶层。

## 二、法术

### 9. 法术施放了，但什么都没发生
**原因**：
- `cast` 写了不存在的值（不报错，直接返回）；
- 或者 `range` 太小、`speed` 是 0。

**怎么办**：`cast` 只用 content.md 表里的值。mod-try 会提醒「没打中木桩」。

### 10. 法术太强 / 太弱
**原因**：`power` 是乘以攻击力的倍率，熟练度最高还会 ×1.8；多发法术是每发都算。
**怎么办**：对照 content.md 的平衡表。`power × count` 不要超过同阶上限太多。控制类法术的威力要降。

### 11. `evo` 写了「多出一道剑气」，但圆满了也没多
**原因**：`evo` 只是文字。
**怎么办**：真要随熟练度多发，写 `lvCount: [1, 1, 2, 3]`。范围、伤害、控制几率会按熟练度自动成长。

### 12. 卷轴在坊市和掉落里一直刷不到
**原因**：卷轴池要求 `realm` ≤ 主角境界 + 1，而且 `tier` 越高越稀有。天阶卷轴本来就罕见。
**怎么办**：重要的法术用剧情送（`g.giveItem('scroll_art_xxx')` 或 `g.learnArt`）。

### 13. `g.learnArt` 之后快捷栏里没有
**原因**：快捷栏满了。
**怎么办**：提示文字别说「已放进快捷栏」，改成「按 K 打开法术书放进快捷栏」。

## 三、妖兽

### 14. 妖兽从来没刷出来
**原因**：
- `lv` 太高，当地妖气不够；
- `zone` 太窄（比如 `'sea'` 却不会飞，海上只刷能飞的或海兽）；
- `regions` 写错；
- `behave: 'flee'` 的妖兽出现率本来就低。

**怎么办**：放宽条件。mod-try 会在南荒随机抽 600 次报告结果。想**保证**玩家遇到，用剧情 `g.spawnEnemy`。

### 15. 妖兽没有外观 / 报「要写 look」
**原因**：`kind` 不是 `human`，却没写 `look`，或者 `look.body` 拼错。
**怎么办**：`body` 只用 content.md 里的 32 种，并补上 `color`、`size`。

### 16. 打死后掉出一个名叫「xxx」、图标是「?」的东西
**原因**：`drops` 里的物品 id 不存在（拼错，或者忘了注册）。
**怎么办**：mod-try 会直接报 ✗。改成正确的 id。

### 17. 妖兽血厚到打不动 / 一碰就死
**原因**：`hp`、`atk`、`def` 是倍率，真实值由 `lv` 对应的境界决定。把 `hp` 写成 500 这种绝对值，就是 500 倍。
**怎么办**：倍率写在 0.5–2 之间，首领 3–6。

### 18. 自定义招式写了，妖兽却不放 / 一放就秒人
**原因**：`range` 太小（玩家站远了就不放）、`cd` 太长；或想写「瞬发秒杀」——`tele` 会被夹到 ≥ 0.3 秒，`pow` 夹到 ≤ 6。
**怎么办**：`range` 给 400–600；数值抄 `src/world/foeskills.ts` 相近招式。`manifest.api` 要写 `2`。

### 18b. patch 了 `melee: { power: 2 }`，妖兽的近战射程没了
**原因**：patch 是浅合并，对象字段整个替换。
**怎么办**：把原来的 `melee` 抄全再改：`{ ...原值, power: 2 }`（在 `src/data/enemies.ts` 里查原值）。

## 四、事件与运行

### 19. 开局对话每次读档都弹
**原因**：`start` 在新开局**和每次读档**时都会触发。
**怎么办**：
```js
api.on('start', (g) => { if (api.store.get('met')) return; api.store.set('met', true); g.dialog({…}); });
```

### 20. 对话没出来 / 被盖住
**原因**：模组对话会等别的对话、面板关掉再弹。新开局的剧情很长，你的对话会排在后面。这是设计如此。
**怎么办**：不用处理。别想办法抢先弹出。

### 21. 想在选项后接着说下一段
**怎么办**（v3）：选项写 `next: { speaker, text, options }`，或让 `act` 返回下一段。别在 `act` 里再调 `g.dialog()`：那样会排到当前对话关掉之后，夹在别的对话中间。`manifest.api` 写 `3`。

### 22. 「模组「xxx」出错太多，已暂停运行」
**原因**：回调累计抛错 20 次，模组的所有回调都被停了（本次运行）。
**怎么办**：
- 看控制台前 3 条错误；
- 常见的是读了 `undefined` 的属性（比如 `api.store.get('x').length`），或 `giveItem` 了不存在的物品。
- 先判断再用；`??` 给默认值；有风险的代码包一层 `try/catch`。

### 23. 卡顿
**原因**：在 `tick` 里做了重活：循环几千次、拼大字符串，或每帧 `g.toast`。
**怎么办**：`tick` 里只做计数和判断；周期性的事放进 `day`，或自己累计 `dt`，满 1 秒再做。

### 24. `day` 回调的天数是小数
**原因**：时间按约半天的粒度结算。
**怎么办**：自己累加，满 1 天再触发：
```js
api.on('day', (g, d) => { const t = (api.store.get('acc') ?? 0) + d; if (t >= 3) { api.store.set('acc', 0); /* 每 3 天一次 */ } else api.store.set('acc', t); });
```

### 25. `kill` 没触发
**原因**：只有**玩家**的击杀会触发。同行友人、NPC 打死的不算；切磋认输（不致死）也不算。
**怎么办**：在任务说明里写「亲手斩杀」。

## 五、存档与数据

### 26. 存了东西，读档后不见了 / 变了样
**原因**：`store` 里存了函数、`Map`、`Set`、`Date`、类实例，转 JSON 时会丢失或变形。
**怎么办**：只存基本类型、数组和普通对象。日期存数字（`g.day`）。

### 27. 存档越来越大，最后存不进去
**原因**：存档放在 localStorage，总共约 5MB，所有存档槽共用。模组往 `store` 里不停追加数据（比如记录每一次击杀）。
**怎么办**：只存汇总（计数、标志），不存流水。mod-try 会在超过 64KB 时提醒。

### 28. 玩家卸载模组后，存档会怎样
**现状**：
- 不会崩。模组的物品显示成「?」；
- 学会的模组法术从法术书和快捷栏里消失，`store` 数据保留；
- 重新装回来，就全部恢复。

**怎么办**：在模组介绍里写一句「卸载后，本模组的物品和法术会失效」。

### 29. 改了物品 id，老存档里的物品成了「?」
**原因**：存档里存的是 id。
**怎么办**：**发布后不要改 id**。要改名，改 `name`。

## 六、打包与发布

### 30. 打包报「入口 import 了别的文件」或 esbuild 错误
**原因**：import 的路径不对，或 import 了 npm 包。
**怎么办**：只 import 同文件夹里的相对路径文件（`./data.js`）。模组里不能装 npm 包。

### 31. 模组包太大（上限 20MB）
**原因**：放了未压缩的大图或长音频。
**怎么办**：图片转成 webp 并控制尺寸（图标 128×128 足够），音频用 ogg 或 mp3，控制时长。超过 4MB 时 mod-try 会提醒。

### 32. 平台拒收：「版本 x.y.z 已经发布过」「新版本号要比当前的高」
**原因**：没升版本号。
**怎么办**：升版本号。修 bug 升第三位，加内容升第二位，不兼容的改动升第一位。

### 33. 平台拒收：「模组 id 已被某人占用」
**原因**：id 归第一个发布者。
**怎么办**：换一个 id。

### 34. 玩家说「装了没反应」
**原因**：模组在游戏**启动时**加载，装完、启用后必须「重新载入」。
**怎么办**：在介绍里写一句。

## 七、地点、人物、界面（v3）

### 35. 新地点不见了 / 跑到海里
**原因**：`x`、`y` 写成了世界像素（几十万），或者写反了地图。
**怎么办**：写**地图坐标**（南荒 0–1000 × 0–700）。参照原版：青玄门 (808, 538)、嘉禾城 (749, 486)、青霞谷 (838, 464)。落在水里会被挪到岸上，但离开太远就不是你想要的地方了。mod-try 会提示「不在当前地图」。

### 36. 「NPC 的住处不是已有地点」
**原因**：先注册了 NPC，后注册地点。
**怎么办**：`locations` 写在 `npcs` 前面。

### 37. 险地 / 秘地点「进入」只有一个「离开」
**原因**：没给它写 `townAction`，或 `where` 没写它的 id。`where` 缺省 `'all'` 只对城池、城镇、海岛有效。
**怎么办**：`where: ['你的地点id']`。

### 38. NPC 的专属开场每次都一样
**原因**：`talk` 没看进度。
**怎么办**：进度存 `api.store`，`talk` 里按进度返回不同的对话；全办完了返回 `null`，就走寻常交谈。

### 39. 快捷键报「已被游戏占用」
**原因**：26 个字母默认都被游戏占了。
**怎么办**：用 `7 8 9 0` 或 `F2 F4 F6–F10`；或者给个右下角按钮。

### 40. 换了图的妖兽脚底悬空 / 陷进地里 / 太小
**原因**：图片四周留了透明边，或 `height` 不对。
**怎么办**：把透明边裁掉，脚底贴着画面底边；`height` 按主角约 108 来定（狼约 74，熊约 130）。

### 41. `draw` 让游戏变卡
**原因**：每帧画几百笔，或者全图都画。
**怎么办**：先判断离主角多远，看不见就 `return`；一帧最多 400 笔（多了不画）。

### 42. 鬼物（`kind: 'ghost'`）从来不在野外出现
**原因**：游戏的野外刷怪本来就不刷鬼物（原版鬼物都在固定地点、剧情里）。
**怎么办**：用 `g.spawnEnemy` 在剧情里放出来（例如秘地里的「深入谷中」）。

### 43. 想用 `api.unsafe`
**先想想**：玩家启用时要看警告、每次更新都要重新确认，游戏更新最容易坏。90% 的需求正规接口都能做；真缺能力，按 extend-api.md 扩展接口。

### 44. `api.data.patch` 改了，游戏里没变化
**原因**：有的数据在建世界时就用掉了（地点、NPC 住处），或者改的是 `api.data.get` 拿到的**拷贝**。
**怎么办**：在 setup 顶层改（建世界之前）；别去改 `get` 的返回值。

### 45. 钩子里写了很重的计算，游戏卡了
**原因**：`damage` `sfx` `music` 这些钩子一秒会触发很多次。
**怎么办**：钩子里只做判断和改数；要算的东西提前算好。

### 46. 删了原版物品，旧存档里那件东西变成「?」
**不会**：`api.data.remove('items', …)` 只是撤出坊市和掉落，按 id 仍查得到。真正换掉一件物品的效果，用 `patch` 或 `itemUse`。

## 八、写代码的习惯

- **先读示例**：`mods/qingming/index.js` 覆盖了全部用法，照它的结构写。
- **常量放顶上**：数值、文字集中在文件开头，方便调平衡。
- **一个功能一组**：先注册内容，再配图标，最后挂事件，按这个顺序写。
- **文字用游戏的口吻**：古风，不要出现「获得道具」「点击」之类的现代词；称谓、境界名对齐原作（炼气、筑基、结丹、元婴、化神；灵石、妖丹、法器、法宝）。
- **防御式编程**：`api.store.get('x') ?? 默认值`；给东西前想清楚 id 是否存在；`takeItem` 要检查返回值。
- **不碰游戏内部**：只用 `api` 和 `g`。用了 `window.__game` 之类的写法，游戏一更新就会坏。
- **每改一次就跑一次 mod-try**。
